Lua elseif

Com if e else, o programa escolhe entre dois caminhos. Mas a vida tem mais opções: a nota da prova vira conceito A, B, C ou D; o semáforo está verde, amarelo ou vermelho; o frete é grátis, barato, caro ou não tem entrega. Para escolher entre três ou mais caminhos, o Lua tem o elseif, uma palavra só, que quer dizer "senão, se".

Você vai aprender
  • Como escrever if … elseif … elseif … else … end.
  • Como o Lua testa as condições: de cima para baixo, e para na primeira verdadeira.
  • Por que a ordem das condições muda o resultado.
  • O elseif sem else: quando pode não rodar nenhum bloco.
  • O erro mais comum desta aula: escrever else if, separado, e o end que fica faltando.
  • Os nomes de outras linguagens que o Lua não conhece: elif, elsif.

Todos os programas desta aula rodaram no Lua 5.5 da máquina da Ana (usuária ana, computador notebook), com lua arquivo.lua. Você pode rodar cada um no editor do guia.

A ideia: a fila de perguntas da professora

A professora da Ana transforma a nota da prova num conceito. Ela faz as perguntas nesta ordem e para na primeira resposta "sim":

  1. A nota é 9 ou mais? Se sim: A. (E não pergunta mais nada.)
  2. Senão: a nota é 7 ou mais? Se sim: B.
  3. Senão: a nota é 5 ou mais? Se sim: C.
  4. Senão (nenhuma das anteriores): D.

Repare que a segunda pergunta não precisa dizer "7 ou mais e menos de 9": se a nota fosse 9 ou mais, a professora já teria parado na primeira. Cada pergunta só é feita para quem "sobrou" das anteriores. É exatamente assim que o elseif funciona.

1. O primeiro elseif: de nota para conceito

local nota = 8.5
if nota >= 9 then
  print("Conceito A")
elseif nota >= 7 then
  print("Conceito B")
elseif nota >= 5 then
  print("Conceito C")
else
  print("Conceito D")
end
if nota >= 9 then
A primeira pergunta, como em todo if.
elseif nota >= 7 then
"Senão, se a nota for 7 ou mais, então…". Só é testada se a de cima deu falso. Ao contrário do else, o elseif tem condição e tem then. É uma palavra só, sem espaço: elseif.
elseif nota >= 5 then
Mais uma pergunta, para quem sobrou das duas de cima. Pode haver quantos elseif você quiser.
else
Opcional. "Em todos os outros casos": roda se nenhuma condição acima deu verdadeiro. Se existir, vem por último.
end
Um end só, no fim, fecha a escada inteira. Os elseif e o else não levam end próprio.
$ lua conceito.lua
Conceito B

2. A ordem das perguntas importa

Como o Lua para na primeira condição verdadeira, trocar a ordem pode estragar tudo. Veja as mesmas perguntas, de baixo para cima:

local nota = 9.5
if nota >= 5 then
  print("Conceito C")
elseif nota >= 7 then
  print("Conceito B")
elseif nota >= 9 then
  print("Conceito A")
else
  print("Conceito D")
end

$ lua ordem.lua
Conceito C

Uma nota 9.5 virou C! A primeira pergunta, 9.5 >= 5, é verdadeira, e o Lua parou ali. As perguntas do B e do A nunca vão ser feitas para ninguém que tirou 5 ou mais: esses blocos ficaram inalcançáveis. E o Lua não avisa nada, porque para ele o programa está certo.

Regra prática para faixas

Com >=, comece pela faixa mais alta e desça. Com < (ou <=), comece pela mais baixa e suba (if nota < 5 then … elseif nota < 7 then …). Em qualquer caso, a pergunta mais "exigente" vem antes.

3. elseif sem else: o semáforo

O else do fim é opcional. Sem ele, se nenhuma condição for verdadeira, nenhum bloco roda:

local cor = "amarelo"
if cor == "verde" then
  print("Pode passar.")
elseif cor == "amarelo" then
  print("Atenção: vai fechar.")
elseif cor == "vermelho" then
  print("Pare!")
end
print("(cor: " .. cor .. ")")

$ lua semaforo.lua
Atenção: vai fechar.
(cor: amarelo)

E com uma cor que não está na lista, como "azul":

$ lua semaforo.lua
(cor: azul)

Nenhuma das três perguntas deu verdadeiro, e sem else o Lua simplesmente seguiu em frente. Às vezes é isso que você quer. Mas, quando um valor estranho é sinal de problema (um semáforo azul!), um else com um aviso (print("Cor desconhecida: " .. cor)) ajuda a descobrir o engano.

FormaQuantos blocos rodam
if … end0 ou 1
if … else … endsempre 1
if … elseif … elseif … end0 ou 1
if … elseif … elseif … else … endsempre 1

Missão: este semáforo esqueceu o vermelho. Com cor = "vermelho", ele não mostra nada além da cor. Acrescente um elseif para o vermelho, que mostre Pare!.

local cor = "vermelho"
if cor == "verde" then
  print("Pode passar.")
elseif cor == "amarelo" then
  print("Atenção: vai fechar.")
end
print("(cor: " .. cor .. ")")

local cor = "vermelho"

  print("Pode passar.")
elseif cor == "amarelo" then
  print("Atenção: vai fechar.")

end

4. Uma escada comprida: o dia da semana

Pode haver muitos elseif. Este programa transforma o número do dia (1 a 7) no nome, guardando o resultado numa variável criada antes (como em if e else):

local dia = 3
local nome
if dia == 1 then
  nome = "domingo"
elseif dia == 2 then
  nome = "segunda-feira"
elseif dia == 3 then
  nome = "terça-feira"
elseif dia == 4 then
  nome = "quarta-feira"
elseif dia == 5 then
  nome = "quinta-feira"
elseif dia == 6 then
  nome = "sexta-feira"
elseif dia == 7 then
  nome = "sábado"
else
  nome = "dia inválido"
end
print("O dia " .. dia .. " é " .. nome)

$ lua dia.lua
O dia 3 é terça-feira

Funciona, mas é comprido. Muitas linguagens têm um comando próprio para isso (o switch ou case). O Lua não tem: a escada de elseif é o jeito normal. Quando os casos são só "este valor vira aquele", existe uma forma bem mais curta, com uma tabela: local dias = {"domingo", "segunda-feira", …} e depois dias[dia]. Você vai ver isso em Tabelas como Listas.

Formas diferentes de fazer a mesma coisa

Antes do elseif, dá para fazer a mesma escolha pondo um if/else dentro do else de outro (veja Condições Aninhadas):

local nota = 8.5
if nota >= 9 then
  print("Conceito A")
else
  if nota >= 7 then
    print("Conceito B")
  else
    print("Conceito C")
  end
end

$ lua aninhado.lua
Conceito B

O resultado é o mesmo do elseif. A diferença está na forma: aqui há dois ifs, cada um com o seu end, e o de dentro fica mais para a direita. Com quatro ou cinco faixas, o código vira uma escada que entra cada vez mais para dentro, com uma pilha de ends no fim. O elseif deixa tudo no mesmo nível, com um end só.

SituaçãoQual usar
Escolher um entre três ou mais caminhosif … elseif … else … end
Faixas de valores (notas, idades, preços)elseif com >=, da faixa mais alta para a mais baixa
Garantir que sempre alguma coisa aconteceTermine com else
Uma pergunta que só faz sentido depois de outra (tem cadastro? então, a senha está certa?)if dentro de if (aula Condições Aninhadas)
Muitos casos do tipo "valor → nome"Uma tabela (aula Tabelas como Listas)

Quando dá errado

Escreveu else if, separado

É o erro mais comum desta aula. Muita gente escreve else if com espaço, como se fala:

local nota = 8.5
if nota >= 9 then
  print("Conceito A")
else if nota >= 7 then
  print("Conceito B")
else
  print("Conceito C")
end

$ lua elseif_espaco.lua
lua: elseif_espaco.lua:9: 'end' expected (to close 'if' at line 2) near <eof>

O arquivo tem 8 linhas, e o Lua reclama de um end que falta para fechar o if da linha 2. Por quê? Com o espaço, else if não é uma palavra: é um else seguido de um if novo, que começa um segundo if dentro do else do primeiro. Para o Lua, o programa é este:

if nota >= 9 then            -- if da linha 2 (o de fora)
  print("Conceito A")
else
  if nota >= 7 then          -- if da linha 4 (um if novo, dentro do else)
    print("Conceito B")
  else
    print("Conceito C")
  end                        -- este end fecha o if de dentro
                             -- e o if de fora? ficou sem end!

O único end fechou o if de dentro; o de fora ficou aberto até o fim do arquivo. Como consertar: junte as duas palavras: elseif nota >= 7 then. (Pôr um segundo end no fim também faz o programa funcionar, mas aí você escreveu, sem querer, o if aninhado da seção Formas diferentes: com mais faixas, a pilha de ends cresce.)

Missão: este programa dá o erro do else if. Conserte usando elseif (uma palavra só), sem acrescentar end, até aparecer Conceito B.

local nota = 8.5
if nota >= 9 then
  print("Conceito A")

  print("Conceito B")

end

end
Esqueceu o then do elseif

A mesma mensagem do if sem then, e de novo apontando a linha seguinte (5) à que tem o problema (4). Lembre: o else não leva then, mas o elseif leva, porque tem condição.

Usou elif ou elsif (de outras linguagens) 
local nota = 8.5
if nota >= 9 then
  print("Conceito A")
elif nota >= 7 then
  print("Conceito B")
end

$ lua elif.lua
lua: elif.lua:4: syntax error near 'nota'

O Python escreve elif; o Ruby e o Perl, elsif. O Lua não conhece nenhum dos dois: para ele, elif é um nome qualquer, e um nome seguido de outro nome (elif nota) não forma um comando. Com elsif sai a mesma mensagem (elsif.lua:4: syntax error near 'nota'). Como consertar: no Lua é elseif, com o e do meio.

Pôs um elseif depois do else 
local nota = 8.5
if nota >= 9 then
  print("Conceito A")
else
  print("Conceito D")
elseif nota >= 7 then
  print("Conceito B")
end

$ lua depoiselse.lua
lua: depoiselse.lua:6: 'end' expected (to close 'if' at line 2) near 'elseif'

Depois do else ("todos os outros casos"), não sobra caso nenhum para perguntar; por isso a única coisa que o Lua aceita ali é o end. Como consertar: o else é sempre o último; mova o elseif para cima dele.

Pôs um end antes do elseif 
local nota = 8.5
if nota >= 9 then
  print("Conceito A")
end
elseif nota >= 7 then
  print("Conceito B")
end

$ lua endmeio.lua
lua: endmeio.lua:5: <eof> expected near 'elseif'

O end da linha 4 fechou o if, e o elseif da linha 5 ficou sem dono. Como consertar: apague o end do meio. Na escada inteira há um end só, no fim.

Missão final: o frete da padaria

Missão: a padaria do bairro agora entrega em casa. A regra do frete: até 5 km, grátis; até 20 km, R$ 10; até 50 km, R$ 25; mais longe, não entrega. No lugar do comentário, escreva a escada com elseif. Para distancia = 12, tem de aparecer Frete: R$ 10. Depois teste 3, 20, 49 e 80.

local distancia = 12
print("Distância: " .. distancia .. " km")
-- escreva o if/elseif aqui


local distancia = 12
print("Distância: " .. distancia .. " km")
if distancia <= 5 then
  print("Frete: grátis")
elseif distancia <= 20 then
  print("Frete: R$ 10")
elseif distancia <= 50 then
  print("Frete: R$ 25")
else
  print("Desculpe, não entregamos tão longe.")
end

Aqui as condições usam <=, então a escada começa pela faixa mais baixa (até 5 km) e sobe. Se você começasse pelo distancia <= 50, todo mundo até 50 km pagaria R$ 25.

Resumo

  • elseif ("senão, se") acrescenta mais perguntas a um if: if … then … elseif … then … else … end.
  • O Lua testa de cima para baixo e roda só o bloco da primeira condição verdadeira. Por isso a ordem importa: com >=, da faixa mais alta para a mais baixa.
  • O else do fim é opcional (sem ele, pode não rodar nada) e é sempre o último.
  • É elseif, uma palavra só. else if separado abre um if novo e pede mais um end (o erro 'end' expected … near <eof>). elif e elsif não existem no Lua.
  • A escada inteira tem um end só, no fim.
  • Próxima aula: if dentro de if, em Condições Aninhadas.
