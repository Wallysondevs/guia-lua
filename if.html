Lua if … then

Até agora, os seus programas rodaram todas as linhas, de cima para baixo, sempre do mesmo jeito. Mas um programa de verdade precisa decidir: mostrar o aviso só se o estoque estiver baixo, liberar a entrada só se a senha estiver certa, dar o desconto só se a compra passar de um valor. Para isso existe o if, que em inglês quer dizer "se". Ele roda um pedaço do programa só quando uma condição é verdadeira.

Você vai aprender
  • Como se escreve um if no Lua: a condição, o then ("então") e o end ("fim").
  • O que acontece quando a condição é verdadeira e quando é falsa.
  • Como pôr várias linhas dentro do if, e por que indentar com 2 espaços.
  • Uma regra do Lua que pega muita gente: só false e nil são falsos; o 0 e o texto vazio "" contam como verdadeiro.
  • Como testar se uma variável tem valor (if apelido then).
  • Os erros reais mais comuns: o then esquecido, o end que falta (ou sobra), = no lugar de ==, != no lugar de ~=, e comparar texto com número.

Todos os programas desta aula rodaram no Lua 5.5 da máquina da Ana (usuária ana, computador notebook), salvos na pasta pessoal dela e executados com lua arquivo.lua (veja Rodando um Programa). Você pode rodar cada um no editor do guia.

A ideia: "se chover, leve o guarda-chuva"

Antes de sair de casa, a mãe da Ana sempre diz: "Se estiver chovendo, então leve o guarda-chuva." Repare como essa frase funciona:

  1. Ela tem uma pergunta que só pode ter duas respostas: está chovendo? Sim ou não.
  2. Ela tem uma ação: levar o guarda-chuva.
  3. A ação só acontece se a resposta for sim. Se for não, a Ana simplesmente sai de casa, sem guarda-chuva, e o dia continua normal.

O if do Lua é essa mesma frase, escrita de um jeito que o computador entende:

local chovendo = true
if chovendo then
  print("Leve o guarda-chuva.")
end

Leia em voz alta: "se chovendo, então mostre Leve o guarda-chuva, fim". O Lua usa palavras inteiras (if, then, end) em vez de símbolos. Isso deixa o código parecido com uma frase.

A pergunta do if se chama condição. Ela é qualquer coisa que dê true (verdadeiro) ou false (falso): uma variável booleana, como chovendo, ou uma comparação, como idade >= 18 (veja Booleanos e Comparações).

1. O primeiro if: pode votar?

No Brasil, quem tem 18 anos ou mais é obrigado a votar. Um programa que confere a idade da Ana:

local idade = 20
if idade >= 18 then
  print("A Ana pode votar.")
end
print("Fim do programa.")
local idade = 20
Uma variável comum, criada antes do if (veja local × Global).
if
A palavra-chave que começa a decisão: "se".
idade >= 18
A condição: "a idade é maior ou igual a 18?". Com idade valendo 20, ela dá true. No Lua, a condição não precisa de parênteses (pode ter, se você quiser: if (idade >= 18) then também funciona).
then
"Então". Fecha a condição e avisa: "daqui para baixo vem o que fazer se ela for verdadeira". É obrigatório.
print("A Ana pode votar.")
O bloco do if (o "corpo"): as linhas entre o then e o end. Elas só rodam se a condição for verdadeira. Os 2 espaços na frente não são obrigatórios para o Lua, mas mostram para quem lê que a linha está dentro do if.
end
"Fim". Fecha o if. Todo if precisa do seu end (é o mesmo end que fecha um do … end; veja Sintaxe e Blocos).
print("Fim do programa.")
Esta linha está depois do end, fora do if: ela roda sempre, com a condição verdadeira ou falsa.
$ lua votar.lua
A Ana pode votar.
Fim do programa.

E quando a condição é falsa?

Troque a idade para 15 e rode de novo:

local idade = 15
if idade >= 18 then
  print("A Ana pode votar.")
end
print("Fim do programa.")

$ lua votar.lua
Fim do programa.

A condição 15 >= 18 deu false, e o Lua pulou tudo o que estava entre o then e o end. Não deu erro, não apareceu nada no lugar: o bloco só não rodou. O programa continuou na linha seguinte ao end, que mostrou Fim do programa.

idadeidade >= 18O que o Lua fez
20trueRodou o bloco (A Ana pode votar.) e depois a linha de fora
15falsePulou o bloco inteiro e foi direto para a linha de fora

E se você quiser mostrar outra coisa quando a condição for falsa (por exemplo, "Ainda não pode votar")? Para isso existe o else, o assunto da próxima aula: if e else.

Missão: a Ana só toma sorvete quando faz calor. No lugar do comentário, escreva um if: se a temperatura for maior que 30, mostre Dia de sorvete!. Depois, troque a temperatura para 25 e veja a mensagem sumir.

local temperatura = 32

2. Várias linhas dentro do if

O bloco pode ter quantas linhas você quiser: tudo o que estiver entre o then e o end roda junto, ou não roda nada. Na padaria do bairro, quando o estoque de pão fica baixo, o programa mostra três avisos:

local estoque = 3
if estoque < 5 then
  print("Atenção: estoque baixo!")
  print("Restam só " .. estoque .. " pães.")
  print("Hora de fazer mais uma fornada.")
end
print("Estoque conferido.")

$ lua estoque.lua
Atenção: estoque baixo!
Restam só 3 pães.
Hora de fazer mais uma fornada.
Estoque conferido.

Com estoque = 3, a condição 3 < 5 é verdadeira e as três linhas do bloco rodam. Com estoque = 40, nenhuma delas rodaria: só apareceria Estoque conferido..

Indente com 2 espaços

Para o Lua, os espaços no começo da linha não fazem diferença: quem diz onde o bloco termina é o end. Mesmo assim, ponha 2 espaços na frente de cada linha de dentro do if. Assim, quem lê (inclusive você, daqui a uma semana) enxerga de relance o que está dentro e o que está fora, e percebe na hora quando falta um end. A comunidade Lua usa 2, 3 ou 4 espaços; este guia usa 2 (veja Estilo de Código).

3. O if numa linha só

Como os espaços e as quebras de linha não importam para o Lua, um if curto pode ficar inteiro numa linha:

local chovendo = true
if chovendo then print("Leve o guarda-chuva.") end

$ lua umalinha.lua
Leve o guarda-chuva.

Funciona igual à versão em três linhas. Use essa forma só quando o bloco for uma ação curta; com duas ou mais ações, prefira uma por linha, que é mais fácil de ler. Repare que o end continua obrigatório, mesmo na linha única.

4. O que conta como verdadeiro no Lua

A condição do if não precisa ser uma comparação. Ela pode ser qualquer valor, e o Lua decide assim:

  • false e nil são falsos;
  • todo o resto é verdadeiro: qualquer número (até o 0), qualquer texto (até o vazio, ""), qualquer tabela.
if 0 then print("0 conta como verdadeiro") end
if "" then print("o texto vazio também") end
if false then print("false: nunca aparece") end
if nil then print("nil: nunca aparece") end
print("só false e nil são falsos")

$ lua verdade.lua
0 conta como verdadeiro
o texto vazio também
só false e nil são falsos
Quem vem de outra linguagem: o 0 é verdadeiro!

Em muitas linguagens (C, JavaScript, Python, PHP), o número 0 e o texto vazio contam como falso. No Lua, não. Um if quantidade then com quantidade = 0 entra no bloco. Se você quer saber se a quantidade é zero, compare de verdade: if quantidade == 0 then (ou if quantidade > 0 then para "tem alguma coisa").

Testando se uma variável tem valor

Essa regra tem um uso muito comum: descobrir se uma variável tem um valor ou se está vazia (nil; veja O Valor nil). O not ("não") inverte a pergunta (veja and, or e not):

local apelido = nil
if apelido then
  print("Oi, " .. apelido .. "!")
end
if not apelido then
  print("A Ana ainda não escolheu um apelido.")
end

$ lua apelido.lua
A Ana ainda não escolheu um apelido.
if apelido then
"Se apelido tem valor". Como ele vale nil, que é falso, o bloco é pulado. Ainda bem: juntar nil com texto (..) daria erro.
if not apelido then
"Se apelido não tem valor". not nil dá true, então o bloco roda.

Troque a primeira linha por local apelido = "Aninha" e o resultado se inverte: aparece Oi, Aninha! e o segundo bloco é pulado.

Experimente: troque o valor de x por 0, "", false, nil, "não" e {} (uma tabela vazia), e rode a cada troca. Quais valores fazem a mensagem aparecer?

local x = 0
if x then
  print("entrou no if com", x)
end
print("fim")

5. Condições com comparações e com and/or

As condições mais comuns são as comparações. Um lembrete dos sinais (a aula completa é Comparações):

SinalPerguntaExemplo
==é igual?if senha == "pao123" then
~=é diferente?if senha ~= "abc" then
< e >é menor? é maior?if estoque < 5 then
<= e >=é menor ou igual? maior ou igual?if idade >= 18 then

Para juntar duas perguntas numa só, use and ("e": as duas têm de ser verdadeiras) ou or ("ou": basta uma):

local senha = "pao123"
if senha == "pao123" then print("Senha certa, pode entrar.") end
if senha ~= "abc" then print("Não é abc.") end
local nota = 7
if nota >= 6 and nota <= 10 then print("Aprovada!") end

$ lua comp.lua
Senha certa, pode entrar.
Não é abc.
Aprovada!

A última condição lê-se "a nota é maior ou igual a 6 e menor ou igual a 10". O Lua não entende a forma "encadeada" da matemática (6 <= nota <= 10). Ele faz a primeira comparação (6 <= 7 dá true) e depois tenta comparar esse true com 10:

$ lua -e 'local nota = 7 if 6 <= nota <= 10 then print("x") end'
lua: (command line):1: attempt to compare boolean with number
stack traceback:
	(command line):1: in main chunk
	[C]: in ?

"Tentativa de comparar um booleano com um número". Escreva as duas comparações separadas, com and no meio: nota >= 6 and nota <= 10.

6. if no modo interativo

No modo interativo (o > do Lua; veja O Modo Interativo), quando você digita uma linha com if … then e aperta Enter, o prompt vira >>: o Lua está esperando o resto do bloco. Ele só roda o if quando recebe o end:

$ lua
Lua 5.5.0  Copyright (C) 1994-2025 Lua.org, PUC-Rio
> idade = 20
> if idade >= 18 then
>> print("Pode votar.")
>> end
Pode votar.
> if idade > 60 then
>> print("Tem prioridade na fila.")
>> end
> if idade >= 18 then print("maior de idade") end
maior de idade
> os.exit()

O segundo if não mostrou nada: 20 > 60 é falso. E o terceiro, numa linha só, rodou na hora, porque o end já veio na mesma linha. (Aqui a variável foi criada sem local de propósito: no modo interativo, uma local não sobrevive de uma linha para a outra.)

Formas diferentes de fazer a mesma coisa

As três versões abaixo fazem exatamente o mesmo: mostram o aviso quando o apelido está vazio.

local apelido = nil

-- 1) comparando com nil
if apelido == nil then
  print("sem apelido (1)")
end

-- 2) com not: "se não tem valor"
if not apelido then
  print("sem apelido (2)")
end

-- 3) numa linha só
if not apelido then print("sem apelido (3)") end

$ lua formas.lua
sem apelido (1)
sem apelido (2)
sem apelido (3)

Há uma diferença pequena entre a 1 e a 2: apelido == nil só é verdadeiro para nil; not apelido é verdadeiro para nil e para false. Para uma variável que guarda texto, dá no mesmo.

SituaçãoQual usar
Fazer algo só quando uma condição é verdadeiraif condição then … end
Uma ação curtaif condição then ação end numa linha
Saber se uma variável tem valorif variavel then (ou if not variavel then)
Saber se um número é zeroif n == 0 then (nunca if not n: o 0 é verdadeiro)
Fazer uma coisa se for verdade e outra se não forif … else … end (aula if e else)
Escolher entre três ou mais caminhoselseif (aula elseif)

"Era esperado then perto de print". Depois da condição idade >= 18, o Lua esperava o then; em vez dele, chegou o print.

Repare que o erro aponta a linha 3, mas o then faltou na linha 2: o Lua só percebe que faltou quando chega à palavra seguinte. Olhe sempre a linha do erro e a de cima. Também não apareceu nenhuma mensagem do programa: com erro de sintaxe, o Lua nem começa a rodar (e o código de saída é 1). Como consertar: if idade >= 18 then.

  print("A Ana pode votar.")

A linha 5, que nem existe: o arquivo tem 4 linhas. É o "depois do fim".
'end' expected
"Era esperado um end"…

"…para fechar o if da linha 2". O Lua diz qual bloco ficou aberto. É a parte mais útil da mensagem.

"Perto do end of file", o fim do arquivo. O Lua leu tudo procurando o end e o arquivo acabou.

Aqui a indentação ajuda a achar o lugar: o segundo print está na margem esquerda, então ele deveria estar fora do if, e o end vai logo antes dele. Como consertar: ponha o end na linha 4, antes de print("Fim do programa.").

Sobrou um end 
local idade = 20
if idade >= 18 then
  print("A Ana pode votar.")
end
end

$ lua endsobra.lua
lua: endsobra.lua:5: <eof> expected near 'end'

"Era esperado o fim do arquivo perto de end". O end da linha 4 já fechou o if; o da linha 5 não tem o que fechar, e o Lua esperava que o arquivo acabasse ali. Como consertar: apague o end que sobrou. Conte: cada if tem exatamente um end.

Usou = no lugar de == 
local senha = "pao123"
if senha = "pao123" then
  print("Senha certa.")
end

$ lua igual.lua
lua: igual.lua:2: 'then' expected near '='

Um = sozinho é atribuição ("guarde este valor na variável"), e não uma pergunta. Para o Lua, a condição terminou em senha e ele esperava o then; chegou um =. Como consertar: para comparar, use dois sinais: if senha == "pao123" then. (O lado bom: no Lua esse engano nunca passa despercebido, ele sempre dá erro.)

Usou != no lugar de ~= 
local senha = "abc"
if senha != "pao123" then
  print("Senha errada.")
end

$ lua diferente.lua
lua: diferente.lua:2: 'then' expected near '!'

O "diferente" da maioria das linguagens é !=, mas o do Lua é ~= (o til, como num "≠" deitado). O Lua não conhece o ! e reclama dele. Como consertar: if senha ~= "pao123" then.

Escreveu If com maiúscula 
local idade = 20
If idade >= 18 then
  print("A Ana pode votar.")
end

$ lua maiuscula.lua
lua: maiuscula.lua:2: syntax error near 'idade'

"Erro de sintaxe perto de idade". O Lua diferencia maiúsculas de minúsculas: If não é a palavra if, é um nome qualquer (como se fosse uma variável). Um nome seguido de outro nome (If idade) não forma nada que o Lua entenda. Como consertar: as palavras-chave do Lua são sempre minúsculas: if, then, end.

Missão: a padaria do bairro dá um pão de queijo de brinde em compras acima de R$ 20. A cliente levou 3 bolos de R$ 7,50. No lugar do comentário, escreva um if que compare o total com 20 e, se passar, mostre Ganhou um pão de queijo de brinde!. A linha Obrigada pela compra! tem de aparecer sempre.

local quantidade = 3

print("Total: R$ " .. total)
-- escreva o if aqui

print("Obrigada pela compra!")

Resumo

  • if condição then … end ("se … então … fim") roda o bloco só quando a condição é verdadeira. Se for falsa, o Lua pula até depois do end, sem erro.
  • O then e o end são obrigatórios, até no if de uma linha só. Indente o bloco com 2 espaços para enxergar o que está dentro.
  • No Lua, só false e nil são falsos. O 0 e o "" são verdadeiros. if variavel then pergunta "tem valor?".
  • Compare com == (dois sinais) e "diferente" é ~=. Junte condições com and e or.
  • Erro de then esquecido aparece na linha seguinte; erro de end esquecido diz qual if ficou aberto (to close 'if' at line N).
  • Para fazer outra coisa quando a condição é falsa, a próxima aula: if e else.
