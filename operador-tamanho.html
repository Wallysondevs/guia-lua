Lua # (tamanho)

"Quantas letras tem esse nome?", "a senha tem pelo menos 8 caracteres?", "quantos itens tem a lista de compras?". Perguntas sobre tamanho aparecem o tempo todo. No Lua, a resposta vem de um único símbolo, o # (chamado de "cerquilha", "jogo da velha" ou, em inglês, hash), escrito antes do valor: #nome.

Você vai aprender
  • Como medir o tamanho de um texto com #.
  • Por que #"ação" dá 6, e não 4: o # conta bytes, e letras com acento ocupam mais de um.
  • Como contar os itens de uma lista, pegar o último item e acrescentar um item no fim.
  • Por que o # dá 0 numa tabela com nomes ({nome = "Ana"}).
  • Os erros reais: attempt to get length of a number value e de um valor nil.
  • As outras formas de medir: string.len, texto:len() e utf8.len.

Todos os programas desta aula rodaram no Lua 5.5 da máquina da Ana (usuária ana, computador notebook), salvos na pasta pessoal dela e executados com lua arquivo.lua (veja Rodando um Programa). Você pode rodar cada um no editor do guia.

A ideia: a fita métrica

Pense no # como uma fita métrica: você encosta no valor e ela diz um número. Para um texto, ela conta quantos "quadradinhos" de memória o texto ocupa. Para uma lista de compras, ela conta quantos itens estão enfileirados, do primeiro até o último.

A fita sempre devolve um número inteiro: 0, 3, 10… Ela não muda o valor medido; só mede. E ela só serve para duas coisas: textos e tabelas. Tentar medir um número ou um nil é erro, como você vai ver.

1. O tamanho de um texto

local nome = "Ana"
print(#nome)
print(#"Ana Lima")
print(#"")
print(#" ")
local senha = "padaria123"
print("A senha tem " .. #senha .. " caracteres")
#nome
O # vem antes do valor, encostado nele (um espaço no meio, # nome, também funciona, mas ninguém escreve assim). Ele devolve o tamanho do texto guardado em nome: 3.
#"Ana Lima"
Funciona com um texto escrito direto, entre aspas. O espaço conta: são 3 + 1 + 4 = 8.
#""
O texto vazio (duas aspas sem nada dentro) tem tamanho 0.
#" "
Um texto com só um espaço não é vazio: tem tamanho 1.
"A senha tem " .. #senha .. " caracteres"
O resultado do # é um número como outro qualquer: dá para fazer conta com ele, guardar numa variável ou colar num texto com .. (veja Juntando Textos).
$ lua tamanho.lua
3
8
0
1
A senha tem 10 caracteres

A segunda e a terceira linhas mediram tabelas (a lista {"a", "b", "c"} e a tabela vazia {}). Elas aparecem na seção 3.

local senha = "pao123"
print("Sua senha tem ? caracteres")

local senha = "pao123"
print("Sua senha tem " .. #senha .. " caracteres")

2. Acentos: o # conta bytes, não letras

Aqui mora a grande surpresa do #. Olhe:

print(#"pao", #"pão")
print(#"ação")
print(utf8.len("ação"))
print(#"€", #"😀")

$ lua acentos.lua
3	4
6
4
3	4

"pão" tem 3 letras, mas o # disse 4. "ação" tem 4 letras, e ele disse 6. O # não está errado: ele conta bytes, não letras.

  • Um byte é o "quadradinho" de memória do computador: cabe um número de 0 a 255.
  • Os textos do Lua são guardados em UTF-8, o jeito mais usado hoje de escrever qualquer letra do mundo em bytes. No UTF-8, as letras sem acento (de a a z, os números, o espaço) ocupam 1 byte cada.
  • Letras com acento, como ã e ç, ocupam 2 bytes. Por isso "ação" = a (1) + ç (2) + ã (2) + o (1) = 6.
  • Outros símbolos ocupam ainda mais: o € ocupa 3 bytes, e um emoji como 😀, 4.

Para contar letras (os programadores dizem "caracteres"), use utf8.len, da biblioteca utf8 que já vem com o Lua: utf8.len("ação") deu 4. A aula Acentos e a Biblioteca utf8 mostra o resto dessa biblioteca.

No modo interativo, a mesma coisa:

$ lua
Lua 5.5.0  Copyright (C) 1994-2025 Lua.org, PUC-Rio
> #"ação"
6
> os.exit()
Quando isso importa

Se o programa verifica "o nome tem no máximo 10 letras" com #, o nome João conta como 5, e Conceição, como 11 (são 9 letras). Para textos com acento que o leitor vai ler (nomes, palavras), prefira utf8.len. O # é o certo quando você quer o tamanho em bytes: ao gravar num arquivo, mandar pela rede, ou quando o texto só tem letras sem acento.

3. O tamanho de uma lista

Uma lista no Lua é uma tabela com os itens numerados a partir de 1: o 1º item, o 2º, o 3º… (veja Tabelas e Tabelas como Listas). O # diz quantos itens ela tem:

local compras = {"pão", "leite", "café"}
print(#compras)
print("Último item: " .. compras[#compras])
compras[#compras + 1] = "ovos"
print(#compras)
print("Último item: " .. compras[#compras])
print(#{})

$ lua lista.lua
3
Último item: café
4
Último item: ovos
0
#compras
A lista tem 3 itens. Repare que o # conta itens, não letras: "leite" tem 5 letras, mas é um item só.
compras[#compras]
O último item. Como os itens são numerados de 1 até o tamanho, o último está na posição #compras, que aqui é compras[3]: café.
compras[#compras + 1] = "ovos"
Acrescenta um item no fim: a próxima posição livre é o tamanho + 1 (aqui, 4). É um dos usos mais comuns do # em programas de Lua. Outro jeito de fazer o mesmo, com uma função pronta, está em table.insert e table.remove.
print(#compras)
Agora são 4, e o último item passou a ser ovos.
#{}
A tabela vazia tem tamanho 0.

Missão: acrescente "ovos" no fim da lista com compras[#compras + 1] = "ovos", antes do print, para o programa mostrar Último: ovos e Itens: 4.

local compras = {"pão", "leite", "café"}
print("Itens: " .. #compras)
print("Último: " .. compras[#compras])

local compras = {"pão", "leite", "café"}
compras[#compras + 1] = "ovos"
print("Itens: " .. #compras)
print("Último: " .. compras[#compras])

Tabela com nomes: o # não conta

Uma tabela também pode guardar valores com nomes em vez de números, como uma ficha (nome = "Ana", idade = 30; veja Tabelas como Dicionários). O # só enxerga a parte numerada:

local cliente = {nome = "Ana", idade = 30}
print(#cliente)
local misto = {"pão", "leite", preco = 4.5}
print(#misto)

$ lua dicionario.lua
0
2

A ficha da cliente tem dois campos, mas nenhum é numerado: o # dá 0. Na tabela misto, ele conta só "pão" e "leite" (as posições 1 e 2) e ignora o preco. Para contar os campos com nome é preciso percorrê-los um a um, com o pairs (aula Percorrendo Chaves).

Listas com buracos

O # só é confiável numa lista sem buracos: itens nas posições 1, 2, 3… até o fim, sem nenhum nil no meio. Se você apagar um item do meio com lista[2] = nil, o resultado do # deixa de ser garantido (o manual do Lua permite mais de uma resposta). Esse assunto tem aula própria: Sequências e Buracos.

4. # no meio de uma conta

O # "gruda" no valor que vem logo depois dele, antes de qualquer conta ou ..:

local nome = "Ana"
print(#nome + 1)
print(#nome .. "!")
print(#(nome .. "!"))
print(#nome * 2)

$ lua precedencia_tam.lua
4
3!
4
6
  • #nome + 1: primeiro o tamanho (3), depois a soma: 4.
  • #nome .. "!": primeiro o tamanho (3), depois o ..: o texto 3!.
  • #(nome .. "!"): com parênteses, o Lua monta "Ana!" primeiro e mede depois: 4.
  • #nome * 2: 3 × 2 = 6.

Os operadores que vêm "colados na frente" de um valor (#, o - de número negativo, o not) têm prioridade sobre quase todos os outros. A tabela completa está em Precedência dos Operadores.

Formas diferentes de fazer a mesma coisa

Para textos, o # tem três "irmãos":

local nome = "Ana Lima"
print(#nome)
print(string.len(nome))
print(nome:len())
print(utf8.len(nome))

$ lua formas_tam.lua
8
8
8
8
#nome
O operador: curto, rápido e o mais usado.
string.len(nome)
A função len ("length", comprimento) da biblioteca string. Dá o mesmo resultado que o #: conta bytes.
nome:len()
A mesma função, escrita com dois-pontos: o nome: na frente quer dizer "aplique ao nome". Esse jeito de chamar funções de texto aparece em Funções de Texto.
utf8.len(nome)
Conta caracteres. Como "Ana Lima" não tem acento, deu 8, igual aos outros. Com "ação", daria 4 contra os 6 dos outros três.
SituaçãoQual usar
Tamanho de um texto sem acento, ou em bytes#texto
Quantas letras tem um texto com acentoutf8.len(texto)
Quantos itens tem uma lista (sem buracos)#lista

Quando dá errado

O # só mede textos e tabelas. Qualquer outra coisa para o programa com attempt to get length of … ("tentativa de obter o tamanho de…").

Mediu um número

A Ana quer saber quantos dígitos tem o telefone, guardado como número:

local telefone = 99887766
print(#telefone)

$ lua erro_num.lua
lua: erro_num.lua:2: attempt to get length of a number value (local 'telefone')
stack traceback:
	erro_num.lua:2: in main chunk
	[C]: in ?

Linha por linha:

lua: erro_num.lua:2:
O erro está no arquivo erro_num.lua, na linha 2.
attempt to get length of a number value
"Tentativa de obter o tamanho de um valor do tipo número". Para o Lua, um número não tem "tamanho": 99887766 é uma quantidade, não uma fileira de dígitos.
(local 'telefone')
O valor problemático estava na variável local telefone.
stack traceback: …
O rastro: linha 2 do programa principal (main chunk), chamado pelo lua ([C]: in ?). Mais em Lendo uma Mensagem de Erro.

Como consertar: transforme o número em texto antes de medir, com tostring (veja Conversão):

local telefone = 99887766
print(#tostring(telefone))

$ lua erro_num2.lua
8

Melhor ainda: telefones, CEPs e documentos devem ser guardados como texto desde o começo ("99887766"), porque ninguém faz contas com eles, e um zero à esquerda ("01310100") sumiria num número.

Mediu uma variável que não existe (nil) 
local compras = {"pão", "leite"}
print(#compra)

$ lua erro_nil.lua
lua: erro_nil.lua:2: attempt to get length of a nil value (global 'compra')
stack traceback:
	erro_nil.lua:2: in main chunk
	[C]: in ?

"Tentativa de obter o tamanho de um valor nil (a global compra)". A variável se chama compras, com s; a linha 2 escreveu compra, que nunca foi criada e por isso vale nil (veja O Valor nil). Como consertar: corrija o nome. Com um campo de tabela que não existe, a mensagem termina com (field '…'):

local cliente = {nome = "Ana"}
print(#cliente.sobrenome)

$ lua erro_campo.lua
lua: erro_campo.lua:2: attempt to get length of a nil value (field 'sobrenome')
stack traceback:
	erro_campo.lua:2: in main chunk
	[C]: in ?
Mediu true ou false 
local ativo = true
print(#ativo)

$ lua erro_bool.lua
lua: erro_bool.lua:2: attempt to get length of a boolean value (local 'ativo')
stack traceback:
	erro_bool.lua:2: in main chunk
	[C]: in ?

Um booleano (veja Booleanos) não tem tamanho. Normalmente esse erro aparece quando uma variável que deveria guardar um texto acabou recebendo true ou false por engano: confira de onde veio o valor.

O # deu um número "a mais"

Não é uma mensagem de erro, mas confunde muita gente: #"João" dá 5. É o acento (seção 2). Como consertar: para contar letras, utf8.len("João").

Para quem quer ir além

Uma tabela pode "ensinar" o # a medir de outro jeito, com o metamétodo __len. É assunto avançado: __tostring, __call e __len.

Missão final: letras e bytes

Missão: o programa deveria mostrar coração: 7 letras, 9 bytes, mas usa # nas duas contas e mostra 9 letras. Conserte a conta das letras com utf8.len.

local palavra = "coração"
local letras = #palavra
local bytes = #palavra
print(palavra .. ": " .. letras .. " letras, " .. bytes .. " bytes")

local palavra = "coração"
local letras = utf8.len(palavra)
local bytes = #palavra
print(palavra .. ": " .. letras .. " letras, " .. bytes .. " bytes")

Resumo

  • #valor devolve o tamanho de um texto ou de uma tabela, sempre um número inteiro.
  • Em texto, o # conta bytes: letras sem acento valem 1, letras com acento valem 2 (#"ação" = 6). Para contar letras, utf8.len.
  • Numa lista, #lista é o número de itens; lista[#lista] é o último; lista[#lista + 1] = v acrescenta no fim.
  • Campos com nome ({nome = "Ana"}) não entram no #, e listas com buracos (nil no meio) dão resultado não garantido: veja Sequências e Buracos.
  • O # vem antes das contas: #nome + 1 é o tamanho mais 1.
  • Número, nil ou booleano no # param o programa com attempt to get length of a … value.
