Lua Instalar

As caixas Experimente do guia rodam o Lua de verdade no navegador, então você pode estudar as primeiras aulas sem instalar nada. Mas, para escrever os seus próprios programas, guardar os arquivos e rodar quando quiser, você vai querer o Lua no seu computador. Ao contrário de outras linguagens, o Lua não vem instalado no Ubuntu. A boa notícia: ele é minúsculo, e a instalação leva poucos segundos. Nesta aula você vai conferir se ele já está aí, instalar o Lua 5.5, evitar duas armadilhas que pegam quase todo mundo e fazer um teste final.

Você vai aprender
  • Como descobrir se o Lua já está instalado, e qual versão, com lua -v.
  • A ler a mensagem do Ubuntu quando o Lua não está lá, e qual pacote escolher.
  • A instalar com sudo apt install lua5.5 liblua5.5-dev, e por que o segundo pacote faz as setas funcionarem.
  • A compilar o Lua do código-fonte oficial, para quando o seu sistema não tem o 5.5.
  • Como instalar no Fedora, no Arch, no Windows (LuaBinaries) e no macOS (Homebrew).
  • A armadilha do luarocks, que troca o seu lua para o 5.1, e como desfazer.
  • Os erros mais comuns de quem está instalando, com as mensagens reais.

As saídas de terminal desta aula vêm do computador da Ana, que usa Ubuntu 26.04. Os comandos com sudo instalam coisas no sistema; as saídas deles foram colhidas num Ubuntu 26.04 de verdade, e o que não deu para rodar (tudo o que é de Windows e de macOS, e as outras distribuições) está marcado como ilustrativo, conferido nas páginas oficiais (lua.org/download.html, LuaBinaries e Homebrew).

A ideia: a música e o tocador

Um arquivo de música no celular não toca sozinho: você precisa de um aplicativo de música para tocá-lo. Com o Lua é igual. O seu programa (o arquivo .lua) é a música; o interpretador lua é o tocador. "Instalar o Lua" é instalar o tocador. Depois disso, qualquer programa Lua, seu ou de outra pessoa, pode ser "tocado" no seu computador.

No Ubuntu, as peças do Lua vêm em pacotes separados:

PacoteO que trazComparação
lua5.5O interpretador lua (e o luac, que você viu na Introdução), com as bibliotecas padrãoO tocador de música
liblua5.5-devOs arquivos para programas em C usarem o Lua. E, de brinde, a biblioteca que faz as setas e o histórico funcionarem no modo interativo (seção 3)O controle remoto do tocador
luarocksO instalador de bibliotecas feitas por outras pessoasA loja de músicas novas (com uma pegadinha: seção 9)

Para todas as aulas do Nível 1, o lua5.5 basta. O liblua5.5-dev é recomendado para o modo interativo ficar confortável. O luarocks fica para muito depois (aula LuaRocks): não instale agora.

1. O Lua já está instalado?

Antes de instalar, pergunte ao computador. Abra o terminal (no Ubuntu: Ctrl+Alt+T) e digite lua -v. Num Ubuntu recém-instalado, a resposta é esta:

$ lua -v
Comando 'lua' não encontrado, mas poder ser instalado com:
sudo apt install lua5.1  # version 5.1.5-12, or
sudo apt install lua5.2  # version 5.2.4-4
sudo apt install lua5.3  # version 5.3.6-3
sudo apt install lua5.4  # version 5.4.8-1build1
sudo apt install lua5.5  # version 5.5.0-3

O terminal não achou nenhum programa chamado lua, e o Ubuntu (com o programa dele de "comando não encontrado") sugeriu os pacotes que trazem um. Linha por linha:

Comando 'lua' não encontrado,
Não há nenhum programa lua neste computador. O Lua não está instalado.
mas poder ser instalado com:
"Mas pode ser instalado com". O "poder" no lugar de "pode" é um erro de tradução do próprio Ubuntu, não do seu computador.
sudo apt install lua5.1 … lua5.5
Cinco pacotes, um para cada versão do Lua, da 5.1 à 5.5. Qualquer um deles cria o comando lua. O número depois de version é a revisão do pacote.

Escolha o lua5.5, a versão que este guia ensina. O Ubuntu lista do mais antigo para o mais novo, e o primeiro da lista (o 5.1) é de 2006. Os outros comandos do Lua dão a mesma resposta, até que você instale:

$ lua5.5 -v
Comando 'lua5.5' não encontrado, mas poder ser instalado com:
sudo apt install lua5.5
lua
O nome do interpretador do Lua.
-v
"Versão": em vez de rodar um programa, mostre a versão e saia. Só existe a forma curta, -v; o --version de outros programas não funciona no Lua (você vai ver o erro em Quando dá errado).

Se o seu computador respondeu com uma linha começando por Lua 5., o Lua já está aí. Veja qual é a versão e pule para a seção 2 ou 3.

3. Por que o liblua5.5-dev: as setas do modo interativo

No modo interativo do Lua (o >, que você vai conhecer daqui a duas aulas), é muito cômodo apertar a seta para cima para repetir a linha anterior, ou as setas para os lados para corrigir uma letra. Quem cuida disso é uma biblioteca chamada readline. O lua5.5 do Ubuntu procura essa biblioteca quando abre, mas ela só existe no computador junto com um pacote "de desenvolvimento" (o libreadline-dev), que não vem com o lua5.5.

Num Ubuntu com só o lua5.5, a seta para cima vira um monte de símbolos, e o Enter depois dela dá um erro esquisito:

$ lua
Lua 5.5.0  Copyright (C) 1994-2025 Lua.org, PUC-Rio
> ^[[A                                             « a seta para cima, sem a readline
stdin: bad binary format (truncated chunk)

O ^[[A é o "código" que o teclado manda quando você aperta a seta para cima. Sem a readline, ninguém traduz esse código, e o Lua recebe os símbolos como se fossem um programa. O primeiro deles (o ^[, a tecla Esc) é justamente o primeiro byte de um arquivo de bytecode do Lua, então ele acha que recebeu uma tradução (binary) cortada no meio (truncated chunk). Nada se estragou: é só a falta da biblioteca. O Lua até avisa o motivo, se você abrir o modo interativo com os avisos ligados (lua -W): junto com as linhas de abertura, aparece esta:

Lua warning: library 'libreadline.so' not found     « "biblioteca libreadline.so não encontrada"

O conserto é instalar o liblua5.5-dev (que puxa o libreadline-dev) ou só o libreadline-dev. O próprio apt mostra a ligação entre os dois:

$ apt-cache depends lua5.5
lua5.5
  Depende: libc6                                    « o lua5.5 sozinho não traz a readline
$ apt-cache show liblua5.5-dev | grep -E "^(Version|Depends)"
Version: 5.5.0-3ubuntu0.1
Depends: liblua5.5-0 (= 5.5.0-3ubuntu0.1), libc6-dev | libc-dev, libreadline-dev
Version: 5.5.0-3
Depends: liblua5.5-0 (= 5.5.0-3), libc6-dev | libc-dev, libreadline-dev

(O grep filtrou só as linhas de versão e de dependências; aparecem duas versões porque o Ubuntu guarda a original e a atualizada.) Depois de instalar, feche o lua e abra de novo: as setas e o histórico passam a funcionar, e o lua -W não reclama mais.

Isso só afeta o modo interativo

Programas em arquivo (lua programa.lua) funcionam igualzinho com ou sem a readline. E o lua5.4 do Ubuntu não tem esse problema: ele já depende da readline. Se você não quiser instalar o pacote -dev, dá para viver sem as setas: é só redigitar a linha.

O 5.5 de lua.org e o do Ubuntu

O site oficial já está na revisão 5.5.1; o Ubuntu 26.04 traz a 5.5.0, e o editor do guia também. A diferença são só correções de defeitos: nada do que o guia ensina muda.

8. macOS

O macOS também não traz o Lua. O jeito mais simples é o Homebrew, o gerenciador de pacotes mais usado no Mac. Segundo a página da fórmula (formulae.brew.sh/formula/lua), ela instala o 5.5.1 (ilustrativo):

brew install lua
lua -v

No Mac, o comando é lua, como no Ubuntu: tudo o que o guia mostra no terminal vale igual lá. Sem o Homebrew, dá para compilar do código-fonte, como na seção 5 (o Mac precisa das ferramentas de linha de comando da Apple, que trazem o compilador).

9. A armadilha do luarocks: o lua vira 5.1

Mais adiante no guia você vai conhecer o LuaRocks, o instalador de bibliotecas do Lua. No Ubuntu 26.04, o pacote luarocks do apt traz uma surpresa: ele depende do Lua 5.1, e, ao instalar o 5.1, o Ubuntu troca o atalho lua para ele. Entre as muitas linhas de sudo apt install luarocks, aparece esta:

update-alternatives: usando /usr/bin/lua5.1 para fornecer /usr/bin/lua (lua-interpreter) no modo automático

E, a partir daí:

$ lua -v
Lua 5.1.5  Copyright (C) 1994-2012 Lua.org, PUC-Rio     « era 5.5, virou 5.1!

Por que acontece: lembra do "modo automático" da seção 2? Cada versão instalada tem uma prioridade, e no modo automático o Ubuntu aponta o atalho lua para a de prioridade maior. O pacote do 5.1 tem prioridade 110; o do 5.5, só 20. Instalou o 5.1, ele "ganhou".

Como desfazer: diga ao Ubuntu qual versão você quer, com dois comandos (um para o lua, outro para o luac):

sudo update-alternatives --set lua-interpreter /usr/bin/lua5.5
sudo update-alternatives --set lua-compiler /usr/bin/luac5.5

O --set ("defina") passa o atalho para o modo manual: o Ubuntu não muda mais sozinho, nem que você instale outras versões. No computador da Ana isso já foi feito, e o --display ("mostre") confirma:

$ update-alternatives --display lua-interpreter
lua-interpreter - modo manual                       « não muda mais sozinho
  a melhor versão de link é /usr/bin/lua5.1          « a que "ganharia" no automático
  o link atualmente aponta para /usr/bin/lua5.5      « a que está valendo
  link lua-interpreter é /usr/bin/lua
  secundário lua-manual é /usr/share/man/man1/lua.1.gz
/usr/bin/lua5.1 - prioridade 110
  secundário lua-manual: /usr/share/man/man1/lua5.1.1.gz
/usr/bin/lua5.4 - prioridade 20
  secundário lua-manual: /usr/share/man/man1/lua5.4.1.gz
/usr/bin/lua5.5 - prioridade 20
  secundário lua-manual: /usr/share/man/man1/lua5.5.1.gz

(Também existe o sudo update-alternatives --config lua-interpreter, que mostra as versões numeradas e pergunta qual você quer.) E tem mais: o luarocks do apt nem instala bibliotecas para o 5.5. A aula LuaRocks mostra o jeito que funciona. Até lá, você não precisa dele.

10. Um editor para escrever os programas

Um programa Lua é um arquivo de texto puro. Qualquer editor de texto serve, menos os de "documento", como o LibreOffice Writer ou o Word: eles gravam fontes, cores e margens junto com o texto, e o Lua não entende nada disso. Algumas opções:

EditorComo conseguir no UbuntuBom para
nanoJá vem. Roda dentro do terminal.Arquivos pequenos, sem sair do terminal. É o que as aulas usam (aula Rodando um Programa).
Editor de TextoJá vem (é o editor com janela do Ubuntu).Começar sem instalar nada. Ele pinta as palavras do Lua com cores quando o arquivo termina em .lua.
VS CodeBaixado do site da Microsoft ou pela Central de Aplicativos, mais a extensão "Lua"Quem quer o editor que a maioria dos programadores usa, com cores, dicas e avisos de erro enquanto digita.

Não existe editor "certo". Para as primeiras aulas, o nano ou o Editor de Texto são ótimos. Uma dica para qualquer um deles: configure a tecla Tab para inserir 2 espaços, que é o recuo que o guia usa (a aula Sintaxe e Blocos explica para que ele serve).

11. O teste final

Com o Lua instalado, rode um programinha de teste. Crie um arquivo chamado teste.lua com este conteúdo (a aula Rodando um Programa (.lua) mostra como criar o arquivo pelo terminal):

print("Lua está funcionando!")
print("Versão:", _VERSION)

$ lua teste.lua
Lua está funcionando!
Versão:	Lua 5.5
print("Lua está funcionando!")
Mostra a frase na tela.
print("Versão:", _VERSION)
Mostra duas coisas na mesma linha: o texto Versão: e o valor de _VERSION, que todo Lua tem, com o nome da versão (só o principal: Lua 5.5, sem a revisão). A vírgula separa as duas, e o print põe uma tabulação entre elas (aula print()).

Se apareceram as duas linhas, está tudo pronto. Faça o mesmo teste no editor do guia:

Missão: o programa mostra só a frase. Acrescente uma segunda linha que mostre a versão: print("Versão:", _VERSION). Rode e veja qual versão o editor do guia usa.

O que aconteceu: o > quer dizer que quem está ouvindo é o Lua, e não o terminal. O Lua leu lua -v como uma conta: "lua menos v". Como ninguém criou nada chamado lua lá dentro, ele vale nil ("nada"), e não dá para fazer conta com nada: attempt to perform arithmetic on a nil value (global 'lua'), "tentativa de fazer aritmética com um valor nil (o nome lua)". O stdin:1: é o "arquivo" do modo interativo (stdin = o que você digita), linha 1. Repare que a primeira linha, a que começa com Lua 5.5.0, já tinha dito a versão.

Como resolver: saia do Lua com os.exit() (ou Ctrl+D) e digite o comando no terminal, onde aparece o $. A aula O Modo Interativo (>) mostra a diferença entre os dois com calma.

A seta para cima vira ^[[A 
$ lua
Lua 5.5.0  Copyright (C) 1994-2025 Lua.org, PUC-Rio
> ^[[A
stdin: bad binary format (truncated chunk)

O que aconteceu: o lua5.5 não achou a biblioteca readline, que cuida das setas e do histórico (seção 3). Como resolver: sudo apt install liblua5.5-dev (ou libreadline-dev), e abra o lua de novo.

Instalei o luarocks e o lua -v diz 5.1 
$ lua -v
Lua 5.1.5  Copyright (C) 1994-2012 Lua.org, PUC-Rio

O que aconteceu: o pacote luarocks trouxe o Lua 5.1, que tem prioridade maior e "roubou" o atalho lua (seção 9). O seu 5.5 continua instalado: lua5.5 -v responde Lua 5.5.0. Um sintoma comum é um programa que usa novidades (como a divisão //) parar de funcionar de repente. Como resolver: sudo update-alternatives --set lua-interpreter /usr/bin/lua5.5 e sudo update-alternatives --set lua-compiler /usr/bin/luac5.5.

Resumo

  • Instalar o Lua é instalar o interpretador, o "tocador" dos seus programas .lua. Confira se ele está aí com lua -v.
  • O Ubuntu não traz o Lua. Sem ele, aparece Comando 'lua' não encontrado, mas poder ser instalado com: e uma lista de pacotes: escolha o lua5.5.
  • No Ubuntu 26.04: sudo apt install lua5.5 liblua5.5-dev. O pacote -dev traz a readline, sem a qual a seta para cima vira ^[[A no modo interativo.
  • O programa se chama lua5.5; o lua é um atalho criado pelo update-alternatives.
  • Sem o pacote lua5.5 (Ubuntu 24.04, Debian 13), compile de lua.org com make all test, ou estude com o lua5.4.
  • Fedora 45+ e Arch: dnf install lua / pacman -S lua. Windows: LuaBinaries (lua55.exe) ou WSL. macOS: brew install lua.
  • O luarocks do apt troca o lua para o 5.1; desfaça com sudo update-alternatives --set lua-interpreter /usr/bin/lua5.5.
  • Dentro do > quem ouve é o Lua; os comandos do terminal vão no $.
