Lua math.random

Jogar um dado, sortear quem lava a louça, embaralhar as cartas, fazer o inimigo do jogo aparecer num lugar diferente a cada partida: tudo isso precisa de números que o programa não sabe de antemão. No Lua, quem sorteia é a função math.random ("aleatório"), da biblioteca math. Nesta aula você vai sortear de todos os jeitos e entender a semente, o truque para os sorteios se repetirem quando você quiser.

Você vai aprender
  • As três formas do math.random: sem nada (entre 0 e 1), com um número (de 1 até ele) e com dois (de um até o outro).
  • Receitas prontas: jogar dados, sortear um item da lista, embaralhar, sortear sem repetir e "uma chance de 30%".
  • O que é a semente e como math.randomseed(42) faz os mesmos números saírem toda vez.
  • Que no Lua 5.5 a semente já é sorteada sozinha, e que no Lua 5.1 não era (por isso o velho math.randomseed(os.time())).
  • Os erros reais: interval is empty, number has no integer representation e wrong number of arguments.

As saídas são do Lua 5.5 da máquina da Ana. Atenção: nos exemplos sem semente, os números que você vai ver ao rodar serão outros. É esse o ponto!

A ideia: o globo do bingo e o livro de números

No bingo da quermesse, o globo gira e uma bola sai: ninguém sabe qual. O computador não tem globo. Ele é uma máquina que faz sempre a mesma coisa com as mesmas entradas, então ele finge: usa uma conta esperta que, a partir de um número inicial, vai produzindo uma sequência que parece não ter padrão nenhum. Por isso se diz que os números são pseudoaleatórios ("falsamente aleatórios").

Imagine um livro grosso cheio de números embaralhados. O número inicial, a semente (em inglês, seed), diz em que página você começa a ler. Cada math.random lê o próximo número do livro. Duas consequências:

  • Se cada execução do programa começar numa página diferente, os números mudam a cada vez. É o que o Lua 5.5 faz sozinho.
  • Se você mandar começar sempre na mesma página (a mesma semente), os números se repetem, na mesma ordem. Ótimo para testar um programa.

1. As três formas do math.random

print(math.random(6), math.random(6), math.random(6))
print(math.random(10, 20))
print(math.random())

$ lua dado.lua
2	2	3
17
0.5567239515761212
$ lua dado.lua
6	4	2
12
0.63035605516434146
math.random(6)
Com um número n: um inteiro de 1 até n, incluindo os dois. É o dado: 1, 2, 3, 4, 5 ou 6. Repare que o mesmo número pode sair duas vezes seguidas (saiu 2 2), como num dado de verdade.
math.random(10, 20)
Com dois números: um inteiro de 10 até 20, incluindo os dois.
math.random()
Sem nada: um float de 0 até 1 (pode dar 0, mas nunca chega a 1). Serve para chances e porcentagens (seção 3).

A Ana rodou o mesmo programa duas vezes e os números foram outros. No Lua 5.5 (e no 5.4), cada execução começa com uma semente diferente, escolhida pelo próprio Lua.

"Será que é justo?"

Um dado bom dá cada face mais ou menos o mesmo número de vezes. Este programa joga o dado 6000 vezes e conta:

local contagem = {0, 0, 0, 0, 0, 0}
for _ = 1, 6000 do
  local face = math.random(6)
  contagem[face] = contagem[face] + 1
end
for face = 1, 6 do
  print(face, contagem[face])
end

$ lua contar.lua
1	1020
2	1033
3	985
4	971
5	977
6	1014

Cerca de 1000 de cada (6000 ÷ 6), nunca exatamente. A face sorteada serve direto de posição na lista contagem, porque o math.random(6) dá um inteiro de 1 a 6. (O _ é o nome costumeiro para uma variável que você não vai usar; veja for Numérico.)

Missão: o jogo de tabuleiro da Ana usa dois dados. Mude o programa para jogar os dois (cada um com math.random(6)) e mostrar também uma linha Soma: … com o total. Rode várias vezes: cada Rodar dá outro resultado.

local d1 = math.random(6)
print("Dado: " .. d1)

local d1 = math.random(6)
local d2 = math.random(6)
print("Dados: " .. d1 .. " e " .. d2)
print("Soma: " .. d1 + d2)

2. A semente: math.randomseed

Agora, o contrário: a Ana está testando um jogo e quer que os sorteios sejam sempre os mesmos, para conseguir repetir um defeito. Ela escolhe a página do livro com math.randomseed(42) (qualquer número inteiro serve; 42 é só um costume):

math.randomseed(42)
print(math.random(1, 100), math.random(1, 100), math.random(1, 100))
print(math.random(6), math.random())

$ lua semente.lua
50	76	86
6	0.0096006865506838013
$ lua semente.lua
50	76	86
6	0.0096006865506838013

Igualzinho nas duas vezes. Com a mesma semente, o Lua 5.5 produz a mesma sequência, na mesma ordem. O editor do guia usa a mesma conta do Lua 5.5: com math.randomseed(42), ele também mostra 50 76 86 (conferido). Já em outra versão do Lua a sequência é outra (veja a seção 5).

math.randomseed(42)
"Comece na página 42." Chame uma vez, no começo do programa, antes dos sorteios.
math.randomseed()
Sem número: o Lua escolhe uma semente nova, imprevisível (o que ele já faz sozinho ao começar).

Curiosidade: o math.randomseed devolve os dois números que usou como semente:

$ lua -e 'print(math.randomseed(42))'
42	0
$ lua -e 'print(math.randomseed())'
973348601	-1608846346381695232
$ lua -e 'print(math.randomseed())'
3101133992	1420972818218884809

Para que serve? Se o seu jogo sorteou algo estranho, guarde a semente que saiu de math.randomseed(); depois, com math.randomseed(973348601, -1608846346381695232), você repete exatamente aquela partida.

Não chame math.randomseed a toda hora

A semente é para o começo. Se você a puser dentro de um laço, com o mesmo número, todo sorteio volta para a mesma página e sai o mesmo número:

$ lua -e 'math.randomseed(42) print(math.random(6)) math.randomseed(42) print(math.random(6))'
6
6

Missão: o programa sorteia três números duas vezes e compara. Sem semente, as duas sequências saem diferentes (iguais: false). Faça elas saírem iguais: chame math.randomseed(7) antes da primeira sequência e de novo antes da segunda.

local function tres()
  return math.random(1000) .. " " .. math.random(1000) .. " " .. math.random(1000)
end

local a = tres()
local b = tres()
print(a)
print(b)
print("iguais: " .. tostring(a == b))

local function tres()
  return math.random(1000) .. " " .. math.random(1000) .. " " .. math.random(1000)
end

math.randomseed(7)
local a = tres()
math.randomseed(7)
local b = tres()
print(a)
print(b)
print("iguais: " .. tostring(a == b))

3. Receitas de sorteio

Nos exemplos abaixo, a Ana fixou uma semente, para que você veja no editor a mesma saída do lab. Tire a linha do math.randomseed para ter sorteios de verdade.

Sortear um item da lista

math.randomseed(2026)
local nomes = {"Ana", "Bia", "Caio", "Duda", "Edu"}
local i = math.random(#nomes)
print("Posição sorteada:", i)
print("Quem lava a louça hoje: " .. nomes[i])

$ lua sorteio.lua
Posição sorteada:	2
Quem lava a louça hoje: Bia

O segredo é math.random(#nomes): sorteia uma posição de 1 até o tamanho da lista (o #; veja O Operador de Tamanho). Se alguém entrar na lista, o sorteio já inclui a pessoa nova, sem mudar mais nada.

Embaralhar

math.randomseed(7)
local cartas = {"A", "2", "3", "4", "5", "6"}
for i = #cartas, 2, -1 do
  local j = math.random(i)
  cartas[i], cartas[j] = cartas[j], cartas[i]
end
print(table.concat(cartas, " "))

$ lua embaralhar.lua
A 6 4 5 2 3

Esta receita tem nome: embaralhamento de Fisher–Yates. Ela anda da última posição para a primeira e, em cada uma, troca a carta com uma posição sorteada entre as que ainda não foram fixadas (de 1 até i). A troca usa a atribuição múltipla. Ela é justa: todas as ordens têm a mesma chance. (Nesse sorteio, o A acabou ficando no lugar dele, o que é perfeitamente possível.)

Sortear sem repetir: o bingo

math.randomseed(10)
local bolas = {}
for n = 1, 10 do bolas[n] = n end
for rodada = 1, 4 do
  local i = math.random(#bolas)
  local bola = table.remove(bolas, i)
  print("Rodada " .. rodada .. ": bola " .. bola .. " (sobram " .. #bolas .. ")")
end

$ lua bingo.lua
Rodada 1: bola 6 (sobram 9)
Rodada 2: bola 3 (sobram 8)
Rodada 3: bola 2 (sobram 7)
Rodada 4: bola 9 (sobram 6)

Como no globo: a bola sorteada sai do globo (table.remove tira e devolve o item; veja table.insert e table.remove), então nunca sai de novo. Outro jeito: embaralhar a lista inteira e ir pegando na ordem.

Uma chance de 30%

math.randomseed(1)
local chuva = 0
for dia = 1, 1000 do
  if math.random() < 0.3 then
    chuva = chuva + 1
  end
end
print("Dias de chuva em 1000:", chuva)

$ lua chance.lua
Dias de chuva em 1000:	290

math.random() dá um número entre 0 e 1, espalhado por igual. Ele cai abaixo de 0,3 em cerca de 30% das vezes. Então if math.random() < 0.3 then quer dizer "com 30% de chance". Em 1000 dias, choveu em 290: perto de 300, como esperado.

Os números do math.random são ótimos para jogos e sorteios entre amigos, mas quem sabe a semente sabe todos os números. Para senhas, chaves e qualquer coisa de segurança, é preciso um gerador próprio do sistema (no Linux, o arquivo /dev/urandom), assunto fora deste curso.

5. E no Lua 5.1, no LuaJIT e no 5.4?

Aqui as versões são bem diferentes. No lab, o mesmo comando, rodado duas vezes em cada versão:

$ lua5.1 -e 'print(math.random(1, 100), math.random(1, 100))'
85	40
$ lua5.1 -e 'print(math.random(1, 100), math.random(1, 100))'
85	40
$ luajit -e 'print(math.random(1, 100), math.random(1, 100))'
80	70
$ luajit -e 'print(math.random(1, 100), math.random(1, 100))'
80	70
$ lua5.4 -e 'print(math.random(1, 100), math.random(1, 100))'
2	6
$ lua5.4 -e 'print(math.random(1, 100), math.random(1, 100))'
39	92

No Lua 5.1 e no LuaJIT, o programa começa sempre na mesma página: sem semente, sai 85 40 (ou 80 70) toda vez. Por isso, em código antigo (e em muitos tutoriais), você vai ver esta linha no começo:

math.randomseed(os.time())

Ela usa a hora atual, em segundos (veja os.time), como semente. No Lua 5.5 ela não é necessária, e tem um defeito: dois programas abertos no mesmo segundo sorteiam os mesmos números. Se o seu código também tiver de rodar no 5.1 ou no LuaJIT (no Neovim, no LÖVE), mantenha a linha.

E a mesma semente dá números diferentes em cada versão, porque a conta por dentro mudou no 5.4:

$ lua5.4 -e 'math.randomseed(42) print(math.random(1, 100), math.random(1, 100))'
50	76
$ luajit -e 'math.randomseed(42) print(math.random(1, 100), math.random(1, 100))'
96	1
$ lua5.1 -e 'math.randomseed(42) print(math.random(1, 100), math.random(1, 100))'
4	33

O 5.4 e o 5.5 concordam (50 76); o LuaJIT e o 5.1 dão outra coisa. Moral: a semente repete os números na mesma versão. Veja as diferenças entre versões.

Quando dá errado

O intervalo ao contrário 
$ lua -e 'print(math.random(10, 1))'
lua: (command line):1: bad argument #1 to 'random' (interval is empty)
stack traceback:
	[C]: in field 'random'
	(command line):1: in main chunk
	[C]: in ?

"Argumento ruim nº 1 para random (o intervalo está vazio)". De 10 até 1 não há número nenhum: o menor vem primeiro. Como consertar: math.random(1, 10).

Número com vírgula 
$ lua -e 'print(math.random(1.5))'
lua: (command line):1: bad argument #1 to 'random' (number has no integer representation)
stack traceback:
	[C]: in field 'random'
	(command line):1: in main chunk
	[C]: in ?
$ lua -e 'print(math.random(3.0))'
2

"O número não tem representação inteira": com um ou dois números, o math.random sorteia inteiros, e 1,5 não é inteiro. Já 3.0 funciona, porque é um float "redondo". Isso costuma acontecer com uma conta como math.random(#lista / 2): com 5 itens, 5 / 2 é 2,5. Como consertar: use // ou math.floor (math.random(#lista // 2)). Para um float entre a e b, use a + (b - a) * math.random().

Três números 
$ lua -e 'print(math.random(1, 2, 3))'
lua: (command line):1: wrong number of arguments
stack traceback:
	[C]: in field 'random'
	(command line):1: in main chunk
	[C]: in ?

"Número errado de argumentos": o math.random aceita nenhum, um ou dois. Para sortear entre três valores específicos, ponha-os numa lista e sorteie a posição.

Uma curiosidade: math.random(0) não é erro 
$ lua -e 'math.randomseed(42) print(math.random(0))'
-1276290044721465627

Talvez você esperasse "intervalo vazio" (de 1 até 0). No 5.4 e no 5.5, o 0 é um caso especial: sorteia um inteiro qualquer, de math.mininteger até math.maxinteger, positivo ou negativo. Você dificilmente vai precisar dele de propósito, mas ele aparece sem querer quando a lista está vazia:

$ lua -e 'local l = {} print(math.random(#l), l[math.random(#l)])'
-5866118092075993803	nil

Com a lista vazia, #l é 0, o math.random(0) devolve um número gigante, e a posição gigante da lista não existe: nil, sem erro nenhum na hora. O erro só aparece depois, quando o programa tenta usar esse nil. Como evitar: antes de sortear, confira if #lista > 0 then.

Missão: rode e leia o erro interval is empty. Conserte o sorteio para dar um número de 1 até 10.

local sorte = math.random(10, 1)
print("Número da sorte: " .. sorte)

local sorte = math.random(1, 10)
print("Número da sorte: " .. sorte)

Missão final: o vencedor da rifa

Missão: a rifa da escola sempre dá a primeira pessoa da lista, o que não tem graça. Troque o 1 por um sorteio de uma posição de 1 até o tamanho da lista (use #nomes, para funcionar mesmo se mais gente entrar). Rode várias vezes e veja o vencedor mudar.

local nomes = {"Ana", "Bia", "Caio", "Duda", "Edu"}
local i = 1

local nomes = {"Ana", "Bia", "Caio", "Duda", "Edu"}

print("Vencedor: " .. nomes[i])

Resumo

  • math.random() dá um float de 0 a 1; math.random(n), um inteiro de 1 a n; math.random(m, n), um inteiro de m a n.
  • Os números são pseudoaleatórios: saem de uma conta que começa na semente. No Lua 5.5 (e no 5.4), a semente já é sorteada a cada execução.
  • math.randomseed(42), uma vez no começo, faz os sorteios se repetirem (na mesma versão do Lua; o editor do guia dá os mesmos números do terminal).
  • Receitas: lista[math.random(#lista)], if math.random() < 0.3 then, Fisher–Yates para embaralhar, table.remove para não repetir.
  • No Lua 5.1 e no LuaJIT, sem semente, os números se repetem: daí o math.randomseed(os.time()) dos códigos antigos.
  • Erros: interval is empty (intervalo ao contrário ou lista vazia), number has no integer representation (número quebrado).
