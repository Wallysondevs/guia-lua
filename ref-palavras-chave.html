Lua Palavras Reservadas

Esta é a página de consulta rápida das palavras reservadas (ou palavras-chave; em inglês, keywords): as palavras que fazem parte da própria linguagem, como if, for e end. Elas têm um significado fixo e não podem ser usadas como nome de variável ou de função. O manual do Lua 5.5 lista 23. Uma delas é nova: global 5.5.

Como ler as tabelas
  • Exemplo é o que você digitaria depois do > do modo interativo (vários comandos numa linha só, para caber).
  • Resultado é o que o Lua 5.5.0 respondeu no computador da Ana. Vários valores aparecem separados por vírgula; várias linhas, uma embaixo da outra.
  • O Lua diferencia maiúsculas de minúsculas: end é reservada, mas End e END são nomes comuns.

As 23, como o manual do 5.5 as escreve:

and       break     do        else      elseif    end
false     for       function  global    goto      if
in        local     nil       not       or        repeat
return    then      true      until     while

E o que acontece quando a Ana tenta usar uma delas como nome de variável:

$ lua
Lua 5.5.0  Copyright (C) 1994-2025 Lua.org, PUC-Rio
> local end = 1
warning: locals do not survive across lines in interactive mode
stdin:1: <name> expected near 'end'
> t = {end = 1}
stdin:1: unexpected symbol near 'end'
> t = {}; t["end"] = 1; print(t["end"])
1
> os.exit()

A mensagem <name> expected near 'end' quer dizer "esperava um nome perto de end": depois de local o Lua esperava um nome de variável e encontrou uma palavra reservada. Como chave de tabela, a palavra reservada funciona entre colchetes e aspas: t["end"].

O caso do global 5.5

O manual do 5.5 diz, na lista de incompatibilidades (§8.1): "The word global is a reserved word. Do not use it as a regular name" ("a palavra global é reservada; não a use como nome comum"). Ela declara variáveis globais, e depois de qualquer declaração global o Lua passa a exigir que todo nome livre seja declarado. Este programa da Ana mostra isso:

global print
global x = 10
x = x + 1
print(x)
y = 5

$ lua g2.lua
lua: g2.lua:5: variable 'y' not declared

Nada foi impresso, nem o print(x) da linha 4: o erro aparece antes de o programa começar a rodar, quando o Lua lê o arquivo, como um erro de sintaxe. O y da linha 5 não foi declarado. Outras formas da declaração, conferidas no lab:

No Lua 5.5.0 de verdade, global ainda funciona como nome

O código-fonte oficial do 5.5.0 vem com a opção LUA_COMPAT_GLOBAL ligada no luaconf.h ("avoids 'global' being a reserved word"). Com ela, o Lua entende global como declaração quando ela faz sentido e, nos outros lugares, como um nome comum. No lab, tanto o lua do Ubuntu quanto o editor do guia aceitaram local global = 1; print(global) (deu 1) e global = 2; print(global) (deu 2), sem erro. Mesmo assim, não use global como nome: o manual a trata como reservada, e um Lua compilado sem essa opção (ou uma versão futura) vai recusar. Mais em A Declaração global e Novidades do Lua 5.5.

Em outras versões

No lab, global x = 10 deu lua5.4: g1.lua:1: syntax error near 'x' no 5.4 e luajit: g1.lua:1: '=' expected near 'x' no LuaJIT: lá, global é só um nome. Uma mensagem estranha: local function = 1

Com local function, o Lua achou que a Ana estava criando uma função local (local function nome() … end) e esperava o nome dela. Por isso a mensagem fala do =: stdin:1: <name> expected near '='. Já local and = 1 deu stdin:1: <name> expected near 'and'. Mais mensagens em Mensagens de Erro Comuns.

Experimente

Missão: o programa da Ana não roda: ela usou uma palavra reservada como nome de variável. Rode, leia a mensagem de erro e troque o nome repeat por outro (por exemplo, vezes) nas duas linhas onde ele aparece. O programa certo termina com Olá, Ana! (3).

local repeat = 3
for i = 1, repeat do
  print("Olá, Ana! (" .. i .. ")")
end

local vezes = 3
for i = 1, vezes do
  print("Olá, Ana! (" .. i .. ")")
end

Livre: teste as palavras and, or e not com valores diferentes. Lembre: só nil e false são falsos.

print(1 and 2, nil and 2, false or "padrão")
print(not 0, not nil, not "")

local nome = nil
print("Olá, " .. (nome or "visitante"))

for i = 1, 5 do
  if i % 2 == 0 then goto continue end
  print(i)
  ::continue::
end

Resumo

  • O Lua 5.5 tem 23 palavras reservadas: and break do else elseif end false for function global goto if in local nil not or repeat return then true until while.
  • Não podem ser nome de variável nem de função (o erro é <name> expected near '…'); como chave de tabela, use t["end"].
  • Maiúsculas importam: End e AND são nomes comuns.
  • 5.5 global é nova; no 5.5.0 oficial ainda é aceita como nome, mas evite.
  • continue não existe (use goto continue); const e close são atributos, não palavras reservadas.
