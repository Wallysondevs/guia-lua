Lua Booleanos (true e false)

A padaria está aberta? Está chovendo? A Ana já tem 18 anos? São perguntas de sim ou não, e o computador responde a elas o tempo todo. No Lua, a resposta "sim" se escreve true ("verdadeiro") e a resposta "não", false ("falso"). Esses dois valores formam o tipo boolean (lê-se "booliano", em homenagem ao matemático George Boole). Eles são pequenos, mas é com eles que o programa toma decisões.

Você vai aprender
  • Os dois valores booleanos, true e false, e o tipo boolean.
  • Que toda comparação (5 > 3, idade >= 18) devolve um booleano, e como guardá-lo numa variável.
  • A regra mais importante desta aula: no Lua, só nil e false são falsos. O 0 e o texto vazio "" são verdadeiros.
  • O not, que inverte: not true é false.
  • Como mostrar um booleano num texto (tostring) e como transformar uma resposta "s"/"n" em booleano.
  • Os erros reais: True com maiúscula, somar um booleano, juntar um booleano num texto com ...

Todos os programas desta aula rodaram no Lua 5.5 da máquina da Ana (usuária ana, computador notebook), salvos na pasta pessoal dela e executados com lua arquivo.lua (veja Rodando um Programa). Você pode rodar cada um no editor do guia.

A ideia: o interruptor da luz

Um interruptor só tem duas posições: ligado ou desligado. Não existe "meio ligado". O cartaz da porta da padaria também: ABERTO ou FECHADO. Um booleano é isso: um valor que só pode ser uma de duas coisas.

No dia a diaNo LuaEm inglês
sim, ligado, aberto, verdadeirotrue"verdadeiro"
não, desligado, fechado, falsofalse"falso"

true e false são palavras reservadas do Lua: escritas assim, em minúsculas e sem aspas. Com aspas, "true" seria só um texto de quatro letras.

local aberta = true
local chovendo = false
print(aberta, chovendo)
print(type(aberta), type(false))
print(5 > 3, 5 < 3, 2 + 2 == 4)
local idade = 17
local maior = idade >= 18
print("maior de idade?", maior)

$ lua bool.lua

Uma variável que guarda um booleano. O nome responde a uma pergunta de sim ou não ("está aberta?"): é um bom costume para variáveis booleanas (aberta, tem_estoque, pode_votar).
type(aberta)
O tipo é boolean (veja Descobrindo o Tipo).
5 > 3, 5 < 3, 2 + 2 == 4
Toda comparação é uma pergunta, e a resposta é um booleano: "5 é maior que 3?" → true; "5 é menor que 3?" → false; "2 + 2 é igual a 4?" → true. Os operadores de comparação têm aula própria: Comparações.
local maior = idade >= 18
A resposta da pergunta pode ser guardada numa variável, como qualquer outro valor. O Lua calcula 17 >= 18 (dá false) e guarda o false em maior.

2. A regra de ouro: só nil e false são falsos

Leia com atenção: isto é diferente de muitas outras linguagens

Quando o Lua precisa decidir se uma condição é verdadeira (num if, num while, no not), ele usa uma regra só: false e nil contam como falso. Todo o resto conta como verdadeiro: o número 0, o texto vazio "", o texto "false", uma tabela vazia. Em linguagens como JavaScript e Python, o 0 e o texto vazio contam como falso (e em C, o 0); no Lua, não.

if 0 then print("0 é verdadeiro") end
if "" then print("o texto vazio é verdadeiro") end
if "false" then print("o texto \"false\" é verdadeiro") end
if {} then print("a tabela vazia é verdadeira") end
if false then print("isto nunca aparece") end
if nil then print("isto também não") end
print("fim")

$ lua verdade.lua
0 é verdadeiro
o texto vazio é verdadeiro
o texto "false" é verdadeiro
a tabela vazia é verdadeira
fim

O if … then … end ("se … então … fim") roda o que está no meio só quando a condição é verdadeira (aula própria: if … then). Quatro mensagens apareceram; as duas de false e de nil, não.

ValorNuma condição, conta como…
falsefalso
nilfalso
trueverdadeiro
0, 0.0, -1, qualquer númeroverdadeiro
"" (texto vazio), "false", "0", qualquer textoverdadeiro
{} (tabela vazia), qualquer tabela ou funçãoverdadeiro

Os programadores chamam os valores que contam como verdadeiro de "verdadeiros" e os que contam como falso de "falsos", mesmo quando não são exatamente true ou false. O manual do Lua diz assim: "Both nil and false make a condition false; they are collectively called false values. Any other value makes a condition true": "nil e false tornam uma condição falsa; juntos, eles são chamados de valores falsos. Qualquer outro valor torna a condição verdadeira".

Por que isso importa: o estoque zerado

A Ana quis avisar quando acabasse o pão e escreveu if paes then, pensando "se tiver pães". Com zero pães:

local paes = 0
if paes then
  print("Tem pão! Restam " .. paes)
else
  print("Acabou o pão.")
end

$ lua estoque.lua
Tem pão! Restam 0

O 0 é verdadeiro, então o programa diz que tem pão. A pergunta certa é "tem mais que zero?": if paes > 0 then. Use if variavel then só para perguntar "a variável existe?" (não é nil), como no if not idade then da aula Conversão. Você vai consertar isso na missão final.

3. not: o contrário

O not ("não") vira a resposta ao contrário. Ele sempre devolve true ou false, seguindo a regra de ouro:

print(not true, not false)
print(not nil, not 0, not "")
print(not not 0, not not nil)

$ lua nao.lua
false	true
true	false	false
true	false
not true, not false
O contrário de verdadeiro é falso, e vice-versa.
not nil
nil conta como falso, então not nil é true. É por isso que if not idade then quer dizer "se não houver idade".
not 0, not ""
0 e "" contam como verdadeiros, então o contrário deles é false.
not not 0
Dois not seguidos desfazem um ao outro e sobra o booleano "puro": not not x é true se x conta como verdadeiro, e false se não. Um truque para transformar qualquer valor em true/false.

O interruptor: x = not x

Trocar um booleano para o valor contrário é tão comum que tem até nome: alternar. É o interruptor da lâmpada:

local acesa = false
print("acesa?", acesa)
acesa = not acesa
print("acesa?", acesa)
acesa = not acesa
print("acesa?", acesa)

$ lua lampada.lua
acesa?	false
acesa?	true
acesa?	false

O not é um dos três operadores lógicos. Os outros dois, and ("e") e or ("ou"), juntam várias perguntas numa só: aula and, or e not.

4. Booleanos e textos

Mostrar um booleano numa frase

O print mostra um booleano direto (print(true)), mas o .. não junta booleanos num texto. Use tostring, que transforma true no texto "true" (veja Conversão):

$ lua -e 'print("aberta: " .. tostring(true))'
aberta: true

O texto "true" não é o booleano true

$ lua -e 'print("true" == true, tostring(true) == "true")'
false	true
$ lua -e 'print(true == 1, false == 0, false == nil)'
false	false	false
  • "true" == true é false: um é texto, o outro é booleano. Valores de tipos diferentes nunca são iguais.
  • true == 1 e false == 0 também são false: no Lua, booleano não é número (em algumas linguagens é).
  • false == nil é false: os dois contam como falsos numa condição, mas são valores diferentes.

De uma resposta digitada para um booleano

Não existe uma função pronta que transforme "s" em true. Basta uma comparação, que já devolve um booleano:

io.write("Quer sacola? (s/n) ")
local resposta = io.read()
local quer_sacola = resposta == "s"
print("quer_sacola =", quer_sacola, type(quer_sacola))

$ echo s | lua resposta.lua
Quer sacola? (s/n) quer_sacola =	true	boolean
$ echo n | lua resposta.lua
Quer sacola? (s/n) quer_sacola =	false	boolean

Leia a linha 3 da direita para a esquerda: primeiro o Lua faz a pergunta resposta == "s"; depois guarda a resposta (true ou false) em quer_sacola. (O echo s | "digita" o s para o programa; ele não aparece na tela.)

Formas diferentes de fazer a mesma coisa

Para perguntar se uma variável booleana é verdadeira, há um jeito longo e um curto:

JeitoExemploComentário
Comparar com trueif aberta == true thenFunciona se aberta for sempre true ou false, mas é redundante
Usar a variável diretoif aberta thenO jeito usual. Lê-se "se aberta"
Comparar com falseif aberta == false thenRedundante, e não pega o nil
Usar o notif not aberta thenO jeito usual. Pega false e nil

Cuidado: o == true só aceita o true de verdade, e não "qualquer coisa verdadeira". Olhe:

local nome = "Ana"
if nome == true then
  print("tem nome")
else
  print("não tem nome?")
end
if nome then
  print("tem nome")
end

$ lua igual_true.lua
não tem nome?
tem nome

"Ana" == true é false (texto não é igual a booleano), mas "Ana" conta como verdadeiro num if. Por isso o jeito curto (if nome then) é o mais seguro e o mais usado.

E para guardar uma resposta, compare direto em vez de escrever um if:

LongoCurto (faz o mesmo)
local maior = false
if idade >= 18 then maior = true end		local maior = idade >= 18

Quando dá errado

True com maiúscula (o Lua não reclama!) 
local aberta = True
print(aberta)
if aberta then
  print("Pode entrar!")
else
  print("Fechado.")
end

$ lua maiuscula.lua
nil
Fechado.

Nenhuma mensagem de erro, e a padaria aparece fechada. O Lua diferencia maiúsculas de minúsculas: true é o booleano, mas True é só um nome de variável que ninguém criou, e uma variável que não existe vale nil (veja O Valor nil). Como nil conta como falso, o if foi para o else. Quem vem do Python (que escreve True e False) cai muito nessa. Como consertar: local aberta = true, tudo minúsculo.

Juntou um booleano num texto com .. 
local aberta = true
print("Aberta: " .. aberta)

$ lua junta_bool.lua

"Tentativa de juntar (concatenate) um valor booleano". O .. aceita textos e números, mas não booleanos. Como consertar: print("Aberta: " .. tostring(aberta)), ou deixe o print separar com vírgula: print("Aberta:", aberta).

Comparou booleanos com < 
$ lua -e 'print(true < false)'
lua: (command line):1: attempt to compare two boolean values
stack traceback:
	(command line):1: in main chunk
	[C]: in ?

"Tentativa de comparar dois valores booleanos". Booleanos só se comparam com == e ~= ("diferente"); não existe "maior" ou "menor" entre true e false.

Tentou usar true como nome de variável 
$ lua -e 'local true = 1'
lua: (command line):1: <name> expected near 'true'

"Era esperado um nome perto de true". Como true e false são palavras reservadas, não podem ser nomes de variáveis (veja Nomes de Variáveis). É um erro de sintaxe: o programa nem começa.

Resumo

  • O tipo boolean tem dois valores: true (verdadeiro) e false (falso), em minúsculas e sem aspas.
  • Toda comparação devolve um booleano, que pode ser guardado: local maior = idade >= 18.
  • Só nil e false são falsos. 0, "", "false" e {} são verdadeiros. Para perguntar "tem mais que zero?", compare: x > 0.
  • not x inverte; x = not x alterna; not not x dá o booleano "puro".
  • Booleano não é número nem texto: true + 1 e "a" .. true dão erro; use tostring(x) para mostrar.
  • True com maiúscula não é o booleano: é uma variável inexistente, que vale nil, sem erro nenhum.
  • Prefira if x then e if not x then a if x == true then.
