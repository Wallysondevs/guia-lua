Lua string.format

Juntar textos com .. funciona (veja Juntando Textos), mas o preço sai R$ 13.5 em vez de R$ 13.50, e as colunas de um recibo ficam tortas. O string.format ("formatar texto") resolve isso: você escreve um molde com lacunas marcadas por %, e ele preenche cada lacuna com um valor, do jeito que você pedir: com duas casas decimais, com largura fixa, com zeros à esquerda.

Você vai aprender
  • Como funciona o molde: o texto, as lacunas (%s, %d, %f) e os valores que as preenchem.
  • Como mostrar dinheiro com duas casas decimais: %.2f.
  • Como fixar a largura e alinhar colunas: %5d, %-10s, %8.2f, %05d.
  • Outras lacunas úteis: %x (hexadecimal), %q (texto "entre aspas" para o Lua) e %% (o próprio símbolo de por cento).
  • Por que os acentos desalinham as colunas, e como contornar.
  • Os erros reais, a começar pelo mais comum: %d com um número quebrado.

Todos os programas desta aula rodaram no Lua 5.5 da máquina da Ana (usuária ana, computador notebook), salvos na pasta pessoal dela e executados com lua arquivo.lua (veja Rodando um Programa). Você pode rodar cada um no editor do guia.

A ideia: um formulário com lacunas

Pense num formulário de papel: "Eu,         , de      anos, declaro…". O texto já está impresso; você só preenche as lacunas, na ordem. E cada lacuna tem um tipo: numa vai um nome, na outra um número.

O string.format é esse formulário. O primeiro valor que você passa é o molde (o texto com as lacunas); os outros são o que vai em cada lacuna, na ordem. Cada lacuna começa com % e termina com uma letra que diz o tipo: %s para texto (de string), %d para número inteiro (de decimal), %f para número com casas decimais (de float).

1. O primeiro molde

local nome = "Ana"
local idade = 30
local texto = string.format("%s tem %d anos.", nome, idade)
print(texto)
print(string.format("Total: R$ %.2f", 13.5))

$ lua primeiro.lua
Ana tem 30 anos.
Total: R$ 13.50
string.format(…)
A função format da biblioteca string, que já vem com o Lua. Ela devolve o texto pronto; quem mostra é o print. Por isso dá para guardar o resultado numa variável (local texto = …).
"%s tem %d anos."
O molde: o texto fixo, com duas lacunas.
%s
A 1ª lacuna, do tipo texto. É preenchida pelo 1º valor depois do molde: nome.
%d
A 2ª lacuna, do tipo número inteiro. Preenchida pelo 2º valor: idade.
%.2f
Número com casas decimais, com exatamente 2 casas (o .2). O 13.5 virou 13.50: é o jeito de mostrar dinheiro.

O molde e os valores são separados por vírgulas. Se o molde tem 3 lacunas, vêm 3 valores depois dele.

2. %s: qualquer valor como texto

print(string.format("[%s]", "pão"))
print(string.format("[%s] [%s] [%s]", 42, 4.5, true))
print(string.format("[%s] [%s]", nil, {1} ~= nil))

$ lua s.lua
[pão]
[42] [4.5] [true]
[nil] [true]

O %s aceita qualquer valor: ele o transforma em texto do mesmo jeito que o tostring (veja Conversão). Até true e nil, que o .. recusa (veja Juntando Textos). Os colchetes do molde são só texto fixo, para enxergar onde cada valor começa e termina.

3. %d: números inteiros

print(string.format("%d pães", 6))
print(string.format("%d", 3.0))
print(string.format("%d", "12"))
print(string.format("%d", -7))

$ lua d.lua
6 pães
3
12
-7
  • %d mostra um número inteiro, sem casas decimais.
  • 3.0 é um float (veja Números), mas tem valor inteiro: o %d aceita e mostra 3.
  • Um texto que parece número, como "12", é convertido sozinho.
  • E se o número tiver casas decimais de verdade, como 7.5? Aí o %d não arredonda: o programa para com um erro. É o erro mais comum desta aula, e ele aparece na seção Quando dá errado.

4. %f e as casas decimais

local preco = 4.5
print(string.format("%f", preco))
print(string.format("%.2f", preco))
print(string.format("%.1f", 7.25))
print(string.format("%.0f", 7.6))
print(string.format("%.2f", 10))
print(string.format("%.2f", 1/3))

$ lua f.lua
4.500000
4.50
7.2
8
10.00
0.33
%f → 4.500000
Sem dizer quantas casas, o %f mostra seis. Quase nunca é o que se quer.
%.2f → 4.50
O ponto e o número entre o % e o f são a precisão: quantas casas depois da vírgula. Duas casas para dinheiro.
%.1f de 7.25 → 7.2
O número é arredondado para caber nas casas pedidas. (Por que 7.2 e não 7.3? O 7.25 está exatamente no meio do caminho, e nesse caso a regra é arredondar para o algarismo par; a caixa "Arredondamento" abaixo explica.)
%.0f de 7.6 → 8
Zero casas: arredonda para o inteiro mais próximo. Diferente do %d, o %.0f aceita qualquer número.
%.2f de 10 → 10.00
Um inteiro também serve: ganha as casas.
%.2f de 1/3 → 0.33
O 0.333333… ficou com 2 casas.
Arredondamento: o computador não é a calculadora da escola

Os floats são guardados em binário, e muitos números com casas decimais (como 2.675 ou 0.1) não têm representação exata; o que fica guardado é um número muito próximo, um pouquinho acima ou abaixo. E, quando o número está exatamente no meio, a regra é arredondar para o algarismo par. No lab:

print(string.format("%.2f", 2.675))
print(string.format("%.0f", 0.5), string.format("%.0f", 1.5), string.format("%.0f", 2.5))
print(math.floor(7.5), string.format("%d", math.floor(7.5)))

$ lua arred.lua
2.67
0	2	2
7	7

O 2.675 "de verdade" é um pouquinho menor que 2.675, por isso virou 2.67. E 0.5, 1.5 e 2.5 viraram 0, 2 e 2 (o par mais próximo). Para valores de dinheiro, isso quase nunca incomoda; para contas em que cada centavo importa, guarde os valores em centavos, como inteiros. O math.floor (veja A Biblioteca math) corta as casas e dá um inteiro, que o %d aceita.

Missão: o programa mostra Total: R$ 13.5. Troque a concatenação por um string.format com %.2f para ele mostrar Total: R$ 13.50.

local total = 3 * 4.5
print("Total: R$ " .. total)

local total = 3 * 4.5
print(string.format("Total: R$ %.2f", total))

5. Largura e alinhamento

Um número entre o % e a letra é a largura: o espaço mínimo, em caracteres, que o valor vai ocupar. O que faltar é completado com espaços. É isso que permite alinhar colunas.

print(string.format("[%5d]", 42))
print(string.format("[%-5d]", 42))
print(string.format("[%05d]", 42))
print(string.format("[%8.2f]", 4.5))
print(string.format("[%5.2f]", 4.5))
print(string.format("[%10s]", "pão"))
print(string.format("[%-10s]", "pao"))
print(string.format("[%5.2f]", 1234.567))

$ lua largura.lua
[   42]
[42   ]
[00042]
[    4.50]
[ 4.50]
[      pão]
[pao       ]
[1234.57]
%5d → [ 42]
Largura 5: três espaços e o 42, encostado à direita. Números alinhados à direita ficam com as unidades uma embaixo da outra.
%-5d → [42 ]
O sinal de menos alinha à esquerda: o valor primeiro, os espaços depois.
%05d → [00042]
Um zero antes da largura completa com zeros em vez de espaços. Bom para códigos de pedido, notas fiscais, horas (%02d:%02d).
%8.2f → [ 4.50]
Largura e precisão juntas: 8 caracteres no total, contando o ponto e as 2 casas.
%5.2f → [ 4.50]
5 no total: um espaço e 4.50 (4 caracteres).
%10s → [ pão]
Para textos, a mesma ideia. Mas conte: o pão ganhou só 6 espaços, e não 7. A largura conta bytes, e o ã ocupa 2 (veja a seção 6).
%-10s → [pao ]
Texto alinhado à esquerda, o normal para a coluna de nomes.
%5.2f de 1234.567 → [1234.57]
A largura é um mínimo: se o valor não couber, ele não é cortado; a coluna é que fica mais larga.

Um recibo alinhado

print(string.format("%-12s %3s %8s", "Item", "Qtd", "Total"))
print(string.format("%-12s %3d %8.2f", "Pao frances", 6, 6 * 0.75))
print(string.format("%-12s %3d %8.2f", "Leite", 2, 2 * 5.9))
print(string.format("%-12s %3d %8.2f", "Cafe", 1, 1 * 18.5))

$ lua recibo.lua
Item         Qtd    Total
Pao frances    6     4.50
Leite          2    11.80
Cafe           1    18.50

O mesmo molde nas três linhas de itens: nome com 12 caracteres à esquerda, quantidade com 3 à direita, total com 8 e 2 casas. O cabeçalho usa as mesmas larguras, com %s. O resultado é uma tabela alinhada, coisa que o \t (veja Caracteres de Escape) não garante. Quando você aprender a repetir com for (for Numérico e ipairs), uma linha só dentro do laço fará o recibo inteiro.

6. Acentos desalinham as colunas

O recibo acima foi escrito sem acentos de propósito. Com acentos:

print(string.format("%-12s %3d %8.2f", "Pão francês", 6, 4.5))
print(string.format("%-12s %3d %8.2f", "Leite", 2, 11.8))
print(string.format("%-12s %3d %8.2f", "Café", 1, 18.5))
print(#"Pão francês", utf8.len("Pão francês"))

$ lua recibo_acento.lua
Pão francês   6     4.50
Leite          2    11.80
Café          1    18.50
13	11

As linhas com acento ficaram uma coluna para a esquerda (a de "Pão francês" até duas, mas ela já passava das 12 de largura). O motivo é o mesmo do # (veja O Operador de Tamanho): o string.format conta bytes, e cada letra com acento ocupa 2. "Pão francês" tem 11 letras, mas 13 bytes. Para alinhar textos com acento, complete os espaços você mesmo, contando as letras com utf8.len:

local function coluna(texto, largura)
  return texto .. string.rep(" ", largura - utf8.len(texto))
end
print(coluna("Pão francês", 12) .. string.format(" %3d %8.2f", 6, 4.5))
print(coluna("Leite", 12) .. string.format(" %3d %8.2f", 2, 11.8))
print(coluna("Café", 12) .. string.format(" %3d %8.2f", 1, 18.5))

$ lua recibo_utf8.lua
Pão francês    6     4.50
Leite          2    11.80
Café           1    18.50

A função coluna (funções têm aula própria: Funções) acrescenta ao texto quantos espaços faltam para chegar à largura, contando letras. O string.rep(" ", n) repete o espaço n vezes (veja Funções de Texto). Os números continuam com o string.format, que para eles funciona bem.

7. Outras lacunas: %x, %q, %%…

%x: hexadecimal

print(string.format("%x", 255))
print(string.format("%X", 255))
print(string.format("%#x", 255))
print(string.format("#%02X%02X%02X", 255, 136, 0))
print(string.format("%o", 8))

$ lua hex.lua
ff
FF
0xff
#FF8800
10

%x mostra um inteiro em hexadecimal (base 16; veja Operadores de Bits), com letras minúsculas; %X, com maiúsculas; %#x põe o 0x na frente. A quarta linha monta o código de uma cor para páginas da internet: cada parte com 2 algarismos (%02X). O %o é a base 8 (octal), rara hoje.

%q: o texto "como o Lua escreveria"

print(string.format("%q", "Ana"))
print(string.format("%q", 'Ela disse "oi"'))
print(string.format("%q", "linha 1\nlinha 2"))
print(string.format("%q", 42))
print(string.format("%q", 0.5))
print(string.format("%q", "tab\taqui"))

$ lua q.lua
"Ana"
"Ela disse \"oi\""
"linha 1\
linha 2"
42
0x1p-1
"tab\9aqui"

O %q (de quoted, "entre aspas") escreve o valor do jeito que ele teria de ser escrito num programa Lua: com as aspas, com \" nas aspas de dentro, com a quebra de linha como \ no fim da linha (veja Caracteres de Escape) e a tabulação como \9. Os floats saem em hexadecimal (0x1p-1 é 0.5), para não perder nenhuma casa. Serve para gravar dados num arquivo que depois vai ser lido de volta pelo Lua (veja load, loadfile e dofile), e para enxergar caracteres invisíveis num texto. Não é para mostrar ao usuário.

%%: o símbolo de por cento

print(string.format("Desconto de %d%%", 10))

$ lua porcento.lua
Desconto de 10%

Como o % começa uma lacuna, para mostrar o símbolo de verdade escreva dois: %%. Um % sozinho dá erro (veja Quando dá errado).

As raras

print(string.format("%e", 1234.5))
print(string.format("%g", 1234.5), string.format("%g", 0.0001), string.format("%g", 1e20))
print(string.format("%c%c%c", 65, 110, 97))
print(string.format("%i", 42))

$ lua outros.lua

Formas diferentes de fazer a mesma coisa

E a vírgula decimal do Brasil?

O string.format usa ponto. O jeito simples e seguro é trocar o ponto pela vírgula depois, com o gsub (aula Substituindo; o %. quer dizer "um ponto de verdade"):

local total = 13.5
local texto = string.format("%.2f", total)
print(texto)
print((texto:gsub("%.", ",")))

$ lua virgula.lua
13.50
13,50

Existe outro caminho, o os.setlocale(""), que põe o programa no idioma do sistema (o pt_BR, na máquina da Ana). Mas ele muda todas as conversões de número, inclusive o print e o tonumber:

print(string.format("%.2f", 13.5))
print(os.setlocale(""))
print(string.format("%.2f", 13.5))
print(tonumber("13.5"), tonumber("13,5"))

$ lua locale.lua
13.50
pt_BR.UTF-8
13,50
13,5	13,5

Depois do setlocale, até o print de um número saiu com vírgula, e o tonumber("13,5") passou a funcionar. Isso pode quebrar um programa que lê arquivos com ponto, e o resultado depende do computador de quem roda. Prefira o gsub. (Datas em português, com os.setlocale, aparecem em Datas e Horas.)

Quando dá errado

Os erros do string.format têm sempre o mesmo formato: bad argument #N to 'format' (…), "argumento ruim número N para a format". O N conta o molde como argumento #1: o argumento #2 é o primeiro valor, o #3 é o segundo, e assim por diante.

%d com um número quebrado 
local media = 7.5
print(string.format("Média: %d", media))

$ lua erro_d.lua
lua: erro_d.lua:2: bad argument #2 to 'format' (number has no integer representation)
stack traceback:
	[C]: in field 'format'
	erro_d.lua:2: in main chunk
	[C]: in ?
$ echo $?
1

Linha por linha:

lua: erro_d.lua:2:
O erro aconteceu na linha 2.
bad argument #2 to 'format'
"Argumento ruim, o número 2, para a format". O #1 é o molde; o #2 é o media.
(number has no integer representation)
"O número não tem representação inteira": o %d pede um inteiro, e 7.5 não é. O Lua não arredonda nem corta: ele para.
[C]: in field 'format'
A primeira linha do rastro diz que o erro foi dentro da função format, que é escrita em C (por isso o [C]), chamada pela linha 2 do programa principal. Mais em Lendo uma Mensagem de Erro.
echo $? → 1
O programa terminou com erro.

Esse erro costuma aparecer com o resultado de uma divisão com /, que é sempre float (15 / 2 = 7.5; veja Divisão), ou com uma média. Como consertar, dependendo do que você quer:

  • mostrar as casas: %.1f ou %.2f;
  • arredondar: %.0f;
  • cortar as casas: string.format("%d", math.floor(media));
  • mostrar do jeito que o Lua mostraria: %s.
Em outras versões

$ luajit -e 'print(string.format("%d", 7.5))'
7
$ lua5.4 -e 'print(string.format("%d", 7.5))'

Missão final: a etiqueta do pedido

Missão: a padaria imprime uma etiqueta para cada pedido. Hoje sai Pedido 42: 3 x pão = R$ 13.5. Reescreva com string.format para sair Pedido 00042: 3 x pão = R$ 13.50: o número do pedido com 5 algarismos (%05d) e o total com 2 casas.

local pedido = 42
local quantidade = 3
local item = "pão"
local preco = 4.5
print("Pedido " .. pedido .. ": " .. quantidade .. " x " .. item .. " = R$ " .. quantidade * preco)

local pedido = 42
local quantidade = 3
local item = "pão"
local preco = 4.5
print(string.format("Pedido %05d: %d x %s = R$ %.2f", pedido, quantidade, item, quantidade * preco))

Resumo

  • string.format(molde, v1, v2, …) devolve o molde com cada lacuna %… preenchida pelos valores, na ordem.
  • %s: qualquer valor como texto. %d: inteiro. %f: float; %.2f: com 2 casas, arredondando.
  • Largura: %5d (à direita), %-10s (à esquerda), %05d (zeros), %8.2f (largura e casas). A largura conta bytes: acentos desalinham.
  • %x hexadecimal, %q valor escrito como no código Lua, %% o símbolo de por cento.
  • %d com número quebrado (7.5) para o programa com bad argument #2 to 'format' (number has no integer representation); o #2 é o primeiro valor depois do molde.
  • Para a vírgula decimal, troque depois: ("%.2f"):format(v):gsub("%.", ",").
