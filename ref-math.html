Lua Biblioteca math

Esta é a página de consulta rápida da biblioteca math ("matemática"): as 25 funções e as 4 constantes que o Lua 5.5 traz para fazer contas, arredondar, sortear números e lidar com inteiros e floats. Todas ficam dentro da tabela math: math.floor(3.7), math.pi. As contas básicas (+, -, *, /, //, %, ^) não são funções: são operadores (veja Operadores).

Como ler as tabelas
  • Exemplo é o que você digitaria depois do > do modo interativo.
  • Resultado é o que o Lua 5.5.0 respondeu no computador da Ana. Vários valores aparecem separados por vírgula; no terminal, o Lua separa com TAB.
  • Preste atenção no .0: 4 é um inteiro e 4.0 é um float. Muitas funções desta página devolvem um ou outro conforme o que receberam. A diferença está em Números (inteiro e float).
  • O Lua 5.5 escreve os floats com todos os dígitos necessários: math.pi aparece como 3.1415926535897931. Para mostrar bonito, use string.format("%.2f", x).

Assim fica no terminal da Ana:

$ lua

> math.max(4, 9, 2)

> math.sqrt(-1)

O math.sqrt(-1) não deu erro: deu -nan, o float especial "não é um número" (not a number). Já a divisão inteira 3 // 0 dá erro (attempt to divide by zero = "tentativa de dividir por zero"), porque não existe inteiro que represente o resultado.

  • Ângulos: sin, cos, tan, asin, acos, atan, deg, rad

  • Números aleatórios: random, randomseed
  • Constantes: pi, huge, maxinteger, mininteger

Lua mais antigo: precisava de math.randomseed(os.time())

Desde o 5.4, o Lua sorteia uma semente nova sozinho a cada vez que o programa começa (o manual do 5.5 diz: "math.random should generate different sequences of results each time the program runs"). No Lua 5.1 e no LuaJIT, quem esquece o math.randomseed(os.time()) pode ver os mesmos números toda vez (ilustrativo: não comparamos aqui). Os números sorteados com a semente 42 desta página são os do 5.5; outra versão pode dar outros.

Como saber se um valor é nan?

O nan é o único valor que é diferente de si mesmo: x ~= x só dá true quando x é nan. No lab ele aparece como -nan (com o sinal); em outros computadores pode aparecer nan. Não compare o texto: use x ~= x.

Funções que sumiram

Se você copiou código de um Lua antigo: math.pow, math.cosh, math.sinh, math.tanh, math.log10 e math.atan2 não existem no 5.5 (no lab, todas deram nil no lua e existem no lua5.1). Use x ^ y no lugar de math.pow(x, y), math.log(x, 10) no lugar de math.log10(x) e math.atan(y, x) no lugar de math.atan2(y, x). Veja As Diferenças entre Versões.

Experimente

Missão: a pizza da Ana custou R$ 87,50 e vai ser dividida entre 3 amigos. A divisão dá 29.166666666666668, e ninguém paga dízima. Arredonde para cima, nos centavos, para ninguém pagar a menos: multiplique por 100, use math.ceil e divida por 100. Mostre com string.format("%.2f", …). O resultado certo é cada um paga R$ 29.17.

local total = 87.50
local pessoas = 3

local parte = total / pessoas
print("cada um paga R$ " .. parte)

local total = 87.50
local pessoas = 3

local parte = math.ceil(total / pessoas * 100) / 100
print("cada um paga R$ " .. string.format("%.2f", parte))

Livre: teste as funções desta página. Com math.randomseed(42) os sorteios se repetem a cada Rodar; apague essa linha e veja os números mudarem.

print(math.floor(3.7), math.ceil(3.2), math.abs(-5))
print(math.max(4, 9, 2), math.min(4, 9, 2))
print(math.sqrt(2), 2 ^ 0.5)
print(math.type(10), math.type(10 / 2), math.tointeger(10 / 2))
print(string.format("pi com 4 casas: %.4f", math.pi))

math.randomseed(42)
for i = 1, 5 do
  io.write(math.random(1, 6), " ")
end
print()

Resumo

  • A tabela math tem 25 funções e 4 constantes (pi, huge, maxinteger, mininteger).
  • Arredondar: floor (para baixo), ceil (para cima), math.floor(x + 0.5) (normal); para mostrar, string.format("%.2f", x).
  • max/min com vários valores; numa lista, math.max(table.unpack(lista)).
  • sqrt e o operador ^ no lugar do antigo math.pow; ângulos em radianos.
  • math.type diz se é inteiro ou float; math.tointeger converte quando não perde nada.
  • math.random(1, 6) sorteia um dado; math.randomseed(42) repete a sequência.
