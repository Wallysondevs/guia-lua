Lua Divisão: /, // e %

Dividir parece simples, mas na vida real a pergunta muda conforme a situação. 17 fatias de pizza para 5 pessoas: quanto dá para cada uma, exatamente? (3,4.) Quantas fatias inteiras cada uma come? (3.) Quantas sobram? (2.) O Lua tem um operador para cada pergunta: /, // e %. Esta aula mostra os três, o que acontece com números negativos e com zero, e os usos clássicos do resto, como descobrir se um número é par.

Você vai aprender
  • A divisão /, que sempre dá float: 6 / 2 é 3.0.
  • A divisão inteira //, que arredonda para baixo: 7 // 2 é 3.
  • O resto %: 7 % 2 é 1.
  • O que acontece com números negativos (-7 // 2 é -4, -7 % 3 é 2) e com floats.
  • Os usos do % e do //: par ou ímpar, minutos em horas, o último algarismo, o relógio que dá a volta.
  • A divisão por zero: inf e nan com /; erro com // e % de inteiros.
  • As diferenças no Lua 5.1 e no LuaJIT (que não têm //).

Todos os programas desta aula rodaram no Lua 5.5 da máquina da Ana (usuária ana, computador notebook), salvos na pasta pessoal dela e executados com lua arquivo.lua (veja Rodando um Programa). Você pode rodar cada um no editor do guia.

A ideia: a divisão da escola, com resto

Lembra da "conta armada" de dividir, da escola? 17 dividido por 5 dá 3 e sobra 2, porque 3 × 5 = 15, e de 15 para 17 faltam 2. Essas duas respostas, o quociente e o resto, são exatamente o que o // e o % calculam. E a divisão "com vírgula" (17 ÷ 5 = 3,4) é a /.

local fatias = 17
local pessoas = 5
print("Cada um come:", fatias // pessoas)
print("Sobram:", fatias % pessoas)
print("Divisão exata:", fatias / pessoas)

$ lua pizza.lua

Sobram:	2
Divisão exata:	3.4

"Quantas vezes cabe inteiro?"// (divisão inteira)17 // 5 → 3
"Quanto sobra?"% (resto, ou módulo)17 % 5 → 2

1. Os três lado a lado

print(7 / 2, 7 // 2, 7 % 2)
print(6 / 2, 6 // 2, 6 % 2)
print(1 / 3, 10 // 3, 10 % 3)

$ lua tres.lua
3.5	3	1
3.0	3	0
0.33333333333333331	3	1
7 / 2 → 3.5
A barra simples é a divisão de verdade, com casas decimais.
6 / 2 → 3.0
Mesmo quando a conta "fecha", a / sempre devolve um float (veja Números). É a regra, não um defeito.
1 / 3 → 0.33333333333333331
Um terço não tem fim em decimal; o float guarda uma aproximação, e o Lua 5.5 mostra todos os algarismos dela.
7 // 2 → 3, 10 // 3 → 3
A barra dupla é a divisão inteira (em inglês, floor division, "divisão com chão"): faz a divisão e arredonda o resultado para baixo. Com dois inteiros, dá inteiro.
7 % 2 → 1, 6 % 2 → 0
O sinal de porcentagem é o resto. Quando a divisão é exata, o resto é 0.

O // e o % sempre andam juntos. Para quaisquer números a e b, vale a prova da conta armada: (a // b) * b + a % b dá de volta o a. No lab, 17 // 5 * 5 + 17 % 5 deu 17.

Quero o resultado da / como inteiro

Se você sabe que a divisão é exata e quer o inteiro: 6 // 2 já dá 3. Se a conta veio de uma /: math.tointeger(6 / 2) dá 3 (ou nil, se não for exata), e math.floor(7 / 2) arredonda para baixo e dá 3. No lab, os três deram 3.

2. Usos clássicos do % e do //

Par ou ímpar

Um número é par quando dividir por 2 não deixa resto. É o uso mais famoso do %:

for n = 1, 6 do
  if n % 2 == 0 then
    print(n, "par")
  else
    print(n, "ímpar")
  end
end

$ lua par.lua
1	ímpar
2	par
3	ímpar
4	par
5	ímpar
6	par

O for n = 1, 6 do repete o bloco com n valendo 1, 2, … 6 (aula for Numérico), e o if escolhe o que mostrar (aula if e else). A pergunta n % 2 == 0 lê-se "o resto de n por 2 é zero?". Do mesmo jeito, n % 3 == 0 pergunta "é múltiplo de 3?", e n % 10 == 0, "termina em zero?".

Minutos em horas e minutos

local minutos = 135
local horas = minutos // 60
local resto = minutos % 60
print(minutos .. " minutos = " .. horas .. "h" .. resto .. "min")
print(string.format("%d:%02d", horas, resto))

$ lua horas.lua
135 minutos = 2h15min
2:15

Uma hora tem 60 minutos: 135 // 60 diz quantas horas inteiras cabem (2), e 135 % 60 diz quantos minutos sobram (15). O %02d do string.format mostra o número com 2 algarismos, completando com zero (aula string.format). O mesmo truque converte segundos em minutos, centavos em reais, dias em semanas.

Missão: o forno da padaria ficou ligado 200 minutos. O programa usa / e mostra um número quebrado de horas. Troque a conta das horas para a divisão inteira e calcule o resto com %, para sair 200 minutos = 3h20min.

local minutos = 200
local horas = minutos / 60
local resto = 0   -- troque pela conta do resto
print(minutos .. " minutos = " .. horas .. "h" .. resto .. "min")

local horas = minutos // 60
local resto = minutos % 60
print(minutos .. " minutos = " .. horas .. "h" .. resto .. "min")

Os últimos algarismos

local n = 2026
print(n % 10, n // 10)
print(n % 100, n // 100)

$ lua digitos.lua
6	202
26	20

Dividir por 10 "corta" o último algarismo: n % 10 é o algarismo cortado (6) e n // 10 é o que sobrou do número (202). Com 100, são os dois últimos.

O relógio que dá a volta

local agora = 22
print((agora + 5) % 24)
local dia = 6
print((dia + 3) % 7)

$ lua relogio.lua
3
2

São 22 horas; daqui a 5 horas serão 27 horas? Não: o relógio dá a volta no 24, e serão 3 da manhã. O % 24 faz essa volta. Do mesmo jeito, com os dias da semana numerados de 0 (domingo) a 6 (sábado), três dias depois do sábado (6) é o dia (6 + 3) % 7 = 2, terça-feira. Sempre que algo "recomeça do zero" depois de um limite, o % resolve.

3. Números negativos: para baixo é para baixo

Aqui o Lua pode surpreender. "Arredondar para baixo" quer dizer ir na direção do menos infinito, e não "cortar as casas decimais". Para números negativos, isso faz diferença:

print(7 // 2, -7 // 2, 7 // -2, -7 // -2)
print(7 % 3, -7 % 3, 7 % -3, -7 % -3)
print(math.floor(-3.5), -7 / 2)
print(math.fmod(-7, 3), math.fmod(7, -3))

$ lua negativos.lua
3	-4	-4	3
1	2	-2	-1
-4	-3.5
-1	1
-7 // 2 → -4
−7 ÷ 2 = −3,5. Para baixo de −3,5 (na direção do −∞) fica o −4, não o −3. É o mesmo que math.floor(-3.5).
-7 % 3 → 2
O resto acompanha: -7 // 3 é −3, e −3 × 3 = −9; de −9 para −7 faltam 2. A regra prática: o resto tem o sinal do número da direita (o divisor). Com divisor positivo, o resto fica sempre entre 0 e o divisor menos 1.
7 % -3 → -2
Divisor negativo, resto negativo (ou zero).
math.fmod(-7, 3) → -1
Se você quer o resto "cortando as casas" (o jeito do C e do JavaScript), a biblioteca math tem o math.fmod: aí o resto tem o sinal do número da esquerda.

A prova da conta armada continua valendo com negativos:

local a, b = -7, 3
print(a // b, a % b, (a // b) * b + a % b)

$ lua identidade.lua
-3	2	-7
Por que isso é bom

O jeito do Lua faz o relógio funcionar até "para trás": 2 horas da manhã menos 5 horas é (2 - 5) % 24, que dá 21 (9 da noite), e não um número negativo. Com o math.fmod, daria -3.

4. // e % com floats

print(7.0 // 2, 7.5 // 2, 7 // 2.0)
print(5.5 % 2, 7.0 % 2, -5.5 % 2)
print(math.type(7.0 // 2), math.type(7 // 2))

$ lua floats.lua
3.0	3.0	3.0
1.5	1.0	0.5
float	integer

Os dois funcionam com floats também, com a mesma ideia (arredondar para baixo, e o que sobra). A diferença é o subtipo: com algum float na conta, o resultado é float, mesmo no // (7.0 // 2 é 3.0). E o % com float pode ter casas: 5.5 % 2 sobra 1.5.

5. Divisão por zero

Na matemática, dividir por zero não tem resposta. No Lua, o que acontece depende do operador e do subtipo:

print(10 / 0, -10 / 0, 0 / 0)
print(10.0 // 0, 10 // 0.0, 10 % 0.0)
print(10 / 0 == math.huge)

$ lua zero.lua
inf	-inf	-nan
inf	inf	-nan
true
  • Com / (que é sempre float), não dá erro: 10 / 0 dá inf (infinito, o mesmo que math.huge), -10 / 0 dá -inf, e 0 / 0 dá nan (not a number, "não é um número"; no Linux aparece -nan).
  • Com // e %, se houver um float na conta, acontece o mesmo: inf ou nan.
  • Com // e % de dois inteiros, o programa para com erro (seção Quando dá errado): um inteiro não tem como guardar "infinito".
O nan é traiçoeiro

A média de uma turma sem alunos dá 0 / 0, e o programa continua, sem erro, com um nan que estraga todas as contas seguintes. Pior: o nan não é igual nem a ele mesmo.

local soma, quantidade = 0, 0
local media = soma / quantidade
print("Média:", media)
print(media == media)

$ lua media0.lua
Média:	-nan
false

Antes de dividir por algo que pode ser zero, pergunte: if quantidade > 0 then … end.

O // só chegou no Lua 5.3. No Lua 5.1 e no LuaJIT (Neovim, LÖVE, OpenResty), ele é erro de sintaxe; lá se usa math.floor(a / b). O % existe e segue a mesma regra do sinal. No lab:

$ lua5.1 -e 'print(7 // 2)'
lua5.1: (command line):1: unexpected symbol near '/'
$ lua5.1 -e 'print(-7 % 3, 7 / 2, 6 / 2, math.floor(-7 / 2), math.fmod(-7, 3))'
2	3.5	3	-4	-1
$ luajit -e 'print(-7 % 3, 6 / 2, 7 % 0)'
2	3	nan

Repare: no 5.1, 6 / 2 mostra 3 (sem .0, porque lá não existem inteiros), e no LuaJIT 7 % 0 dá nan em vez de erro. Mais em Lua 5.1, LuaJIT, 5.4 e 5.5.

"Tentativa de fazer n%0" (o resto de um número n por zero). A mensagem é diferente da do //, mas a causa e o conserto são os mesmos.

Usou / e apareceu um .0 (ou um número quebrado)

Não é um erro do Lua, mas é o "erro" mais comum desta aula: 6 / 2 mostra 3.0 e 200 / 60 mostra 3.3333333333333335. Se você queria "quantas vezes cabe", o operador certo é o //.

O resto negativo que você não esperava

Quem vem do C ou do JavaScript espera -7 % 3 = −1, e o Lua dá 2. Não é erro: o Lua arredonda o quociente para baixo (seção 3). Se o seu programa precisa do outro comportamento, use math.fmod(-7, 3), que dá -1.

O // no Lua 5.1 ou no LuaJIT

Se o seu código vai rodar num programa que usa LuaJIT (um plugin do Neovim, um jogo no LÖVE) e aparecer unexpected symbol near '/', é o //, que lá não existe. Troque por math.floor(a / b).

Resumo

  • / é a divisão com casas e sempre dá float (6 / 2 → 3.0).
  • // é a divisão inteira: arredonda para baixo, na direção do −∞ (7 // 2 → 3, -7 // 2 → -4).
  • % é o resto, com o sinal do divisor (-7 % 3 → 2). (a // b) * b + a % b é sempre a. Para o resto do jeito do C, use math.fmod.
  • Usos clássicos: par (n % 2 == 0), horas e minutos (// 60 e % 60), último algarismo (% 10), relógio que dá a volta (% 24).
  • Divisão por zero: com / (ou floats) dá inf/nan sem erro; com // e % de inteiros, o programa para. Confira o divisor antes.
  • O Lua 5.1 e o LuaJIT não têm //: lá se usa math.floor(a / b).
