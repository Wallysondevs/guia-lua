Lua Biblioteca table

Esta é a página de consulta rápida da biblioteca table: as 8 funções que o Lua 5.5 traz para trabalhar com listas (tabelas com as chaves 1, 2, 3…). Elas inserem, removem, ordenam, juntam e copiam itens. Todas ficam dentro da tabela table e são chamadas com ponto: table.insert(lista, x). Uma é nova no 5.5: table.create.

Como ler as tabelas
  • Exemplo é o que você digitaria depois do > do modo interativo. Vários comandos na mesma linha são separados por ;.
  • O modo interativo mostra uma tabela só como um endereço (table: 0x…, que muda a cada vez). Por isso os exemplos terminam com print(table.concat(t, ", ")), que mostra os itens.
  • Resultado é o que o Lua 5.5.0 respondeu no computador da Ana. Vários valores aparecem separados por vírgula; no terminal, o Lua separa com TAB.
  • Estas funções olham só a parte de lista da tabela (as chaves 1, 2, 3…) e usam o tamanho #t. Chaves de texto, como t.nome, são ignoradas.

Assim fica no terminal da Ana:

$ lua
Lua 5.5.0  Copyright (C) 1994-2025 Lua.org, PUC-Rio
> compras = {"pão", "leite"}
> table.insert(compras, "café")
> table.insert(compras, 1, "ovos")
> table.concat(compras, ", ")
ovos, pão, leite, café
> table.remove(compras)
café
> table.sort(compras)
> table.concat(compras, ", ")
leite, ovos, pão
> compras
table: 0x561ce37c5e60
> os.exit()

O table.insert e o table.sort não mostram nada: eles mudam a própria tabela e não devolvem valor. O table.remove devolve o item que tirou (café). E digitar só compras mostra o endereço da tabela na memória (0x561ce37c5e60), que muda a cada execução.

Pule direto para o grupo que você procura:

  • Inserir e remover: insert, remove
  • Juntar em texto: concat
  • Ordenar: sort
  • Desempacotar e empacotar: unpack, pack
  • Copiar e criar: move, create
  • Todas de A a Z

Não use t[i] = nil para tirar um item do meio

Isso deixa um buraco na lista, e aí o #t, o ipairs e as funções desta página se confundem. Para tirar do meio, use table.remove(t, i), que puxa os outros e fecha o buraco. Veja Sequências e Buracos.

Montando um texto grande? Use uma lista e table.concat

Num laço com milhares de voltas, texto = texto .. pedaco cria um texto novo a cada volta e fica lento. O jeito do Lua é guardar os pedaços numa lista (partes[#partes + 1] = pedaco) e juntar tudo no fim com table.concat(partes). Veja Juntando Textos.

O sort não é "estável"

O manual avisa: itens que a sua função comp considera iguais (duas pessoas com a mesma nota) podem trocar de lugar entre si. Se a ordem do desempate importa, inclua o desempate na função: if a.nota ~= b.nota then return a.nota > b.nota end return a.nome < b.nome. E a função tem de ser coerente: usar <= no lugar de < pode dar erro: no lab, table.sort(t, function(a, b) return a <= b end) numa lista com números repetidos parou com stdin:1: invalid order function for sorting.

table.pack(…)O contrário: junta os valores numa tabela nova e guarda quantos eram no campo n (contando os nil).t = table.pack("a", nil, "c"); print(t.n, #t, t[3])3, 1, ctable.unpack e table.pack
sem nadatable.pack().n0

Repare no #t do table.pack("a", nil, "c"): deu 1, não 3. Com um nil no meio, a tabela tem um buraco, e o # pode parar em qualquer "borda" (o manual permite tanto 1 quanto 3). Por isso o pack guarda o n: use t.n, nunca #t, para saber quantos valores vieram.

unpack sem table. é do Lua 5.1

No Lua 5.1 e no LuaJIT (Neovim, LÖVE) a função se chama unpack, sem o table.. No 5.5 o unpack sozinho é nil (conferido no lab). Código que precisa rodar nos dois costuma começar com local unpack = table.unpack or unpack. Veja As Diferenças entre Versões.

Experimente

Missão: a Ana quer o ranking da turma, da maior nota para a menor: Ana > Caio > Bia. O programa já junta os nomes com table.concat, mas na ordem em que foram digitados. Antes do for, ordene a lista alunos com table.sort e uma função que compare as notas (a.nota > b.nota).

local alunos = {
  {nome = "Bia", nota = 7.0},
  {nome = "Ana", nota = 9.5},
  {nome = "Caio", nota = 8.0},
}

local nomes = {}
for _, aluno in ipairs(alunos) do
  table.insert(nomes, aluno.nome)
end
print(table.concat(nomes, " > "))

local alunos = {
  {nome = "Bia", nota = 7.0},
  {nome = "Ana", nota = 9.5},
  {nome = "Caio", nota = 8.0},
}

table.sort(alunos, function(a, b) return a.nota > b.nota end)

local nomes = {}
for _, aluno in ipairs(alunos) do
  table.insert(nomes, aluno.nome)
end
print(table.concat(nomes, " > "))

Livre: teste as funções desta página na lista de compras. Insira em outras posições, remova do meio, ordene ao contrário.

local compras = {"pão", "leite"}
table.insert(compras, "café")
table.insert(compras, 1, "ovos")
print(#compras, table.concat(compras, ", "))

local tirado = table.remove(compras, 2)
print("tirei:", tirado, "ficou:", table.concat(compras, ", "))

table.sort(compras)
print(table.concat(compras, " | "))

local t = table.pack("a", nil, "c")
print(t.n, table.unpack(t, 1, t.n))

Resumo

  • São 8 funções na tabela table, e todas trabalham com a parte de lista (chaves 1, 2, 3…).
  • insert e remove põem e tiram itens sem deixar buracos (no fim ou numa posição).
  • concat junta em texto (só textos e números); sort ordena a própria lista, com uma função comp opcional.
  • unpack espalha os itens; pack junta valores e guarda o total em n.
  • move copia trechos entre listas.
  • 5.5 table.create(n) cria uma tabela vazia com espaço reservado.
