Lua Métodos e o Dois-Pontos (:)

Uma tabela pode guardar não só dados (o titular e o saldo de uma conta), mas também funções que trabalham com esses dados (depositar, sacar, mostrar o extrato). Uma função assim, que pertence a uma tabela e mexe nela, se chama método. Nesta aula você vai entender o self ("si mesmo") e o dois-pontos do conta:depositar(50), que é só um jeito curto de escrever conta.depositar(conta, 50). Essa é a peça que falta para as classes.

Você vai aprender
  • Como guardar funções numa tabela, e por que uma função "presa" ao nome da tabela dá problema.
  • O parâmetro self: passar a tabela para a função trabalhar nela.
  • O dois-pontos: obj:metodo(x) é obj.metodo(obj, x), e function obj:metodo(x) é function obj.metodo(self, x).
  • Os métodos que os textos já têm: nome:upper().
  • Encadear chamadas devolvendo self.
  • Os erros reais de trocar o ponto pelo dois-pontos (e vice-versa), e de chamar um método que não existe.

Todos os programas rodaram no Lua 5.5 da máquina da Ana (usuária ana, computador notebook) com lua arquivo.lua. Você precisa conhecer funções, parâmetros e Funções São Valores (uma função pode ser guardada numa tabela como qualquer valor).

A ideia: o formulário com o número da conta

No banco, o caixa tem um carimbo "DEPÓSITO". O carimbo é o mesmo para todos os clientes. Para ele saber em qual conta pôr o dinheiro, o cliente entrega um formulário com o número da conta dele. Sem o formulário, o carimbo não sabe onde depositar.

  • O carimbo é a função depositar: uma só, para todas as contas.
  • O formulário com o número da conta é o self: o parâmetro que diz "trabalhe nesta conta".
  • O dois-pontos é o atendente que preenche o formulário por você: conta_ana:depositar(50) entrega a conta_ana como formulário automaticamente.

1. Uma função dentro da tabela

A conta da Ana é uma tabela com o titular e o saldo. A função de depósito fica num campo da própria tabela:

local conta = { titular = "Ana", saldo = 100 }

conta.depositar = function (valor)
  conta.saldo = conta.saldo + valor
end

conta.depositar(50)
print(conta.titular, conta.saldo)

$ lua conta1.lua
Ana	150

Funciona: conta.depositar é uma função guardada no campo depositar, e conta.depositar(50) a chama. Mas repare que, lá dentro, ela escreve conta.saldo: ela está presa à variável conta. Veja o que acontece quando a Bia usa a mesma função na conta dela:

local conta = { titular = "Ana", saldo = 100 }

conta.depositar = function (valor)
  conta.saldo = conta.saldo + valor
end

local conta_bia = { titular = "Bia", saldo = 20, depositar = conta.depositar }
conta_bia.depositar(30)
print(conta.titular, conta.saldo)
print(conta_bia.titular, conta_bia.saldo)

$ lua conta2.lua
Ana	130
Bia	20

A Bia depositou 30, e o dinheiro foi parar na conta da Ana (que foi de 100 para 130); a da Bia continuou com 20. Nenhum erro, nenhum aviso: só o resultado errado. A função não tinha como saber de quem era o depósito, porque só conhecia a variável conta. É o carimbo sem formulário.

2. O formulário: o parâmetro self

O conserto é passar a conta como primeiro parâmetro. Assim a função trabalha em qualquer conta que receber. Por tradição, esse parâmetro se chama self:

local function depositar(self, valor)
  self.saldo = self.saldo + valor
end

local conta_ana = { titular = "Ana", saldo = 100, depositar = depositar }
local conta_bia = { titular = "Bia", saldo = 20, depositar = depositar }

conta_ana.depositar(conta_ana, 50)
conta_bia.depositar(conta_bia, 30)
print(conta_ana.titular, conta_ana.saldo)
print(conta_bia.titular, conta_bia.saldo)

$ lua conta3.lua
Ana	150
Bia	50
local function depositar(self, valor)
Uma função só, com dois parâmetros: self (a conta onde depositar) e valor. Ela não fala de nenhuma conta pelo nome.
self.saldo = self.saldo + valor
"Some o valor ao saldo da conta que eu recebi".
depositar = depositar
As duas contas guardam a mesma função no campo depositar (o primeiro depositar é o nome do campo; o segundo, a função local).
conta_bia.depositar(conta_bia, 30)
A Bia entrega o "formulário": a própria conta_bia. Dentro da função, self é a conta_bia, e o dinheiro cai no lugar certo.

O nome self não é obrigatório nem mágico: é um parâmetro como outro qualquer. Mas todo programador Lua usa esse nome, e o dois-pontos (a seguir) também usa.

3. O dois-pontos :

Escrever conta_bia.depositar(conta_bia, 30) é repetitivo: o nome da conta aparece duas vezes. O dois-pontos faz isso por você:

Você escreveO Lua entende
conta:depositar(50)conta.depositar(conta, 50)
function conta:depositar(valor) … endfunction conta.depositar(self, valor) … end

Nas duas linhas, o dois-pontos é um atalho de escrita: na chamada, ele passa a tabela como primeiro argumento; na definição, ele cria o parâmetro self escondido, antes dos outros.

local conta = { titular = "Ana", saldo = 100 }

function conta:depositar(valor)
  self.saldo = self.saldo + valor
end

function conta:extrato()
  print(string.format("%s: R$ %.2f", self.titular, self.saldo))
end

conta:depositar(50)
conta:extrato()
conta.depositar(conta, 25)
conta.extrato(conta)

$ lua conta4.lua
Ana: R$ 150.00
Ana: R$ 175.00
function conta:depositar(valor)
Define o método. Você escreve só valor nos parênteses, mas a função tem dois parâmetros: self (escondido, criado pelo dois-pontos) e valor.
function conta:extrato()
Um método sem parâmetros visíveis. Ele ainda recebe o self, e é com ele que lê o titular e o saldo. O %.2f mostra 2 casas decimais (veja string.format).
conta:depositar(50)
A chamada com dois-pontos: o Lua passa conta como self e 50 como valor.
conta.depositar(conta, 25)
A mesma coisa, escrita por extenso, com ponto. Funcionou igual: o saldo foi a 175. Prova de que o dois-pontos é só um atalho.

E o self é sempre a tabela que veio antes do dois-pontos na chamada, mesmo quando o método foi escrito para outra:

local conta = { titular = "Ana" }
function conta:quem()
  return self == conta, self.titular
end
print(conta:quem())
local outra = { titular = "Bia", quem = conta.quem }
print(outra:quem())

$ lua ver_self.lua
true	Ana
false	Bia

O método quem foi escrito em conta, mas chamado como outra:quem(), o self foi a outra. Compare com o conta2.lua da seção 1: com self, emprestar a função para a Bia funciona.

A regra de bolso

Definiu com :, chame com :. Definiu com ., chame com .. Misturar os dois é o erro mais comum desta aula, e a seção Quando dá errado mostra as mensagens reais de cada mistura.

Missão: os métodos foram definidos com dois-pontos, mas as chamadas usam ponto, e o programa para com attempt to index a number value (local 'self'). Troque o . por : nas duas chamadas.

local conta = { titular = "Ana", saldo = 100 }

function conta:depositar(valor)
  self.saldo = self.saldo + valor
end

function conta:mostrar_saldo()
  print("Saldo: " .. self.saldo)
end

conta.depositar(50)
conta.mostrar_saldo()

end

4. Métodos que você já usou: os dos textos

Se você fez a aula Funções de Texto, já escreveu nome:upper(). É o mesmo dois-pontos: nome:upper() é nome.upper(nome), e o Lua acha o upper na biblioteca string, graças à metatabela que todo texto tem (veja Metatabelas).

local nome = "ana lima"
print(nome:upper())
print(string.upper(nome))
print(nome:sub(1, 3), nome:rep(2, "-"))
print(("%d itens"):format(3))

$ lua texto.lua
ANA LIMA
ANA LIMA
ana	ana lima-ana lima
3 itens

Num texto escrito direto no código, os parênteses em volta são obrigatórios: ("%d itens"):format(3). Sem eles, print("ana":upper()) deu erro de sintaxe no lab: ')' expected near ':' ("era esperado ) perto do :").

5. Métodos que mexem em dados mais complexos: o estoque

O self dá acesso a tudo o que a tabela guarda, inclusive outras tabelas dentro dela. O estoque da padaria com dois métodos, entrada e saída:

local estoque = { produtos = {} }

function estoque:entrada(produto, quantidade)
  self.produtos[produto] = (self.produtos[produto] or 0) + quantidade
end

function estoque:saida(produto, quantidade)
  local tem = self.produtos[produto] or 0
  if quantidade > tem then
    return false, "só temos " .. tem .. " de " .. produto
  end
  self.produtos[produto] = tem - quantidade
  return true
end

estoque:entrada("pao", 40)
estoque:entrada("pao", 10)
print(estoque:saida("pao", 12))
print(estoque:saida("pao", 100))
print(estoque.produtos.pao)

$ lua dados_self.lua

self.produtos[produto]
Dentro do método, self.produtos é a tabela de produtos do estoque; [produto] é a quantidade daquele produto (veja Tabelas Aninhadas).

Se o produto ainda não existe, começa do 0.

Um método pode devolver valores, como qualquer função. Aqui, false e o motivo, quando falta produto (veja Vários Retornos).

Encadear: devolver o self

Se um método devolve o próprio self, dá para chamar outro método logo em seguida, na mesma linha:

local conta = { titular = "Ana", saldo = 0 }

function conta:depositar(valor)
  self.saldo = self.saldo + valor
  return self
end

conta:depositar(10):depositar(20):depositar(5)
print(conta.saldo)

$ lua encadear.lua
35

conta:depositar(10) devolveu a conta, e o :depositar(20) foi chamado nela, e assim por diante. É um estilo que algumas bibliotecas usam; não é obrigatório.

Formas diferentes de fazer a mesma coisa

As quatro formas abaixo definem o mesmo método:

-- 1) dois-pontos (a mais comum)
function conta:depositar(valor) self.saldo = self.saldo + valor end

-- 2) ponto, com o self escrito
function conta.depositar(self, valor) self.saldo = self.saldo + valor end

-- 3) campo recebendo uma função
conta.depositar = function (self, valor) self.saldo = self.saldo + valor end

-- 4) dentro das chaves, na criação da tabela
local conta = {
  titular = "Ana",
  saldo = 100,
  depositar = function (self, valor) self.saldo = self.saldo + valor end,
}

E qualquer uma delas pode ser chamada de duas formas: conta:depositar(50) ou conta.depositar(conta, 50).

local conta = { titular = "Ana", saldo = 100 }

function conta:mostrar_saldo()
  print("Saldo: " .. self.saldo)
end

function conta:sacar(valor)
  if valor > self.saldo then
    print("Saldo insuficiente para R$ " .. valor)
  else
    self.saldo = self.saldo - valor
    print("Saque de R$ " .. valor .. ": ok")
  end
end

Resumo

  • Um método é uma função guardada numa tabela que trabalha nos dados dessa tabela.
  • Uma função presa ao nome da tabela (conta.saldo lá dentro) não serve para outras tabelas. O conserto é receber a tabela como primeiro parâmetro: o self.
  • obj:metodo(x) é obj.metodo(obj, x); function obj:metodo(x) é function obj.metodo(self, x). O dois-pontos é só um atalho.
  • Definiu com :, chame com :. Trocar dá attempt to index a number value (local 'self') ou attempt to perform arithmetic on a table value (local 'valor').
  • Os textos já têm métodos: nome:upper(), graças à metatabela deles.
  • Próximo passo: muitas contas com os mesmos métodos, sem copiar função por função, em Classes com Metatabelas.
