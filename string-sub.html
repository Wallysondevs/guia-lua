Lua sub, byte e char

Muitas vezes você não quer o texto inteiro, só um pedaço dele: o dia de uma data "18/10/2026", a primeira letra de um nome, os últimos 4 dígitos de um cartão, a extensão .txt de um arquivo. A função string.sub (de substring, "pedaço de texto") recorta esse pedaço a partir das posições das letras. Nesta aula você também conhece string.byte e string.char, que mostram o número que o computador guarda para cada letra.

Você vai aprender
  • Como as posições das letras são contadas no Lua: a primeira é a 1.
  • Como recortar com texto:sub(inicio, fim) e com texto:sub(inicio), até o fim.
  • As posições negativas, que contam a partir do fim: -1 é a última letra.
  • O que acontece quando a posição passa do tamanho do texto (spoiler: não dá erro).
  • Como pegar uma letra só, com texto:sub(i, i), e por que texto[1] não funciona.
  • O que são os códigos das letras, com string.byte e string.char.
  • Por que ("ação"):sub(1, 2) mostra a�.

Todos os programas desta aula rodaram no Lua 5.5 da máquina da Ana (usuária ana, computador notebook), salvos na pasta pessoal dela e executados com lua arquivo.lua. Você pode rodar cada um no editor do guia. O dois-pontos de texto:sub(…) é o mesmo atalho de Funções de Texto: texto:sub(1, 3) é o mesmo que string.sub(texto, 1, 3).

A ideia: a fileira de cadeiras numeradas

Imagine o texto como uma fileira de cadeiras no cinema, cada letra sentada numa cadeira numerada. No Lua, a numeração começa na cadeira 1 (em várias outras linguagens ela começa no 0; no Lua, não). E tem um segundo jeito de numerar, de trás para frente: a última cadeira é a -1, a penúltima é a -2, e assim por diante. Para o texto "Lua 5.5":

LetraLua  (espaço)5.5
Posição1234567
Do fim-7-6-5-4-3-2-1

O espaço também ocupa uma cadeira, e o ponto também. Para recortar um pedaço, você diz ao Lua de qual cadeira até qual cadeira, e as duas pontas entram no pedaço.

1. Recortar: texto:sub(inicio, fim)

local s = "Lua 5.5"
print(s:sub(1, 3))
print(s:sub(5, 7))
print(s:sub(2, 2))
print(string.sub(s, 1, 3))
s:sub(1, 3)
Da posição 1 até a 3, incluindo as duas: L, u, a.
s:sub(5, 7)
Da 5 até a 7: 5.5.
s:sub(2, 2)
Começa e termina na mesma cadeira: uma letra só, o u.
string.sub(s, 1, 3)
O jeito longo, sem o dois-pontos: o texto vira o primeiro argumento. O resultado é o mesmo.
$ lua recorte.lua
Lua
5.5
u
Lua

Como toda função de texto, o sub devolve um texto novo; o s continua "Lua 5.5" (veja Funções de Texto, seção 3). Uma conta útil: o pedaço sub(i, j) tem j - i + 1 letras. sub(5, 7) tem 7 − 5 + 1 = 3.

2. Até o fim: texto:sub(inicio)

O segundo número é opcional. Sem ele, o recorte vai até a última letra:

local s = "Lua 5.5"
print(s:sub(5))
print(s:sub(1))

$ lua ate-o-fim.lua
5.5
Lua 5.5

s:sub(1) devolve o texto inteiro: da primeira cadeira até a última.

3. Contando do fim: posições negativas

Quando o que você quer está no fim do texto, e o texto pode ter qualquer tamanho, conte de trás para frente:

local s = "Lua 5.5"
print(s:sub(-3))
print(s:sub(-3, -2))
print(s:sub(-1))

local arquivo = "compras.txt"
print(arquivo:sub(-4))
local cartao = "5502 1234 8765 4321"
print("Cartão final " .. cartao:sub(-4))

$ lua negativo.lua

Da antepenúltima letra até o fim: as 3 últimas, 5.5.

Dá para misturar os dois jeitos: s:sub(2, -2) é "da segunda letra até a penúltima", um jeito fácil de tirar o primeiro e o último caractere (por exemplo, as aspas de '"oi"').

4. Fora dos limites: o Lua não reclama

O que acontece se você pedir cadeiras que não existem? Em vez de dar erro, o sub ajusta as pontas para dentro do texto:

local s = "Lua 5.5"
print("[" .. s:sub(5, 3) .. "]")
print("[" .. s:sub(10, 20) .. "]")
print("[" .. s:sub(0) .. "]")
print(s:sub(-100, 3), s:sub(3, 100))

5. Uma letra só: texto:sub(i, i)

Para pegar uma letra, o início e o fim são a mesma posição. Um uso clássico: pôr a primeira letra de um nome em maiúscula, juntando o sub com o upper de Funções de Texto:

local nome = "ana"
local primeira = nome:sub(1, 1)
local resto = nome:sub(2)
print(primeira, resto)
print(primeira:upper() .. resto)
print("Inicial: " .. nome:sub(1, 1):upper() .. ".")

$ lua inicial.lua
a	na
Ana
Inicial: A.

A linha 5 cola a primeira letra em maiúscula com o resto, que já estava em minúsculas. A linha 6 faz tudo de uma vez, encadeando: recorta, depois põe em maiúscula.

nome[1] não pega a primeira letra

Em outras linguagens, nome[1] ou nome[0] pega uma letra. No Lua, os colchetes servem para as tabelas, e um texto não é uma tabela de letras: nome[1] dá nil, sem erro nenhum (você vê em Quando dá errado). Para uma letra, use sempre nome:sub(1, 1).

6. O número de cada letra: string.byte

Por dentro, o computador não guarda letras: ele guarda números, um para cada caractere, combinados numa tabela que todo computador conhece (a tabela ASCII, de 1963, que vai do 0 ao 127). O A é 65, o a é 97, o algarismo 0 é 48 e o espaço é 32. O string.byte mostra esses números:

print(("A"):byte())
print(("a"):byte(), ("0"):byte(), (" "):byte())
print(("Ana"):byte(1, -1))
print(("Ana"):byte(2))

$ lua codigos.lua

("A"):byte()
Sem posição, ele olha a primeira letra: 65.
("Ana"):byte(1, -1)
Com início e fim (iguais aos do sub, inclusive os negativos), ele devolve vários números, um por letra: 65 (A), 110 (n), 97 (a). O print mostra todos, separados por tabulação.
("Ana"):byte(2)

Repare que A (65) e a (97) são números diferentes: é por isso que, para o Lua, "Ana" == "ana" é falso. As letras estão em ordem (B é 66, C é 67…), e é isso que faz "Ana" < "Bia" ser verdadeiro (veja Comparações). E o nome "byte": cada um desses números cabe num byte, o pedacinho de memória que vai de 0 a 255.

7. Do número para a letra: string.char

O string.char faz o caminho de volta: você dá os números, ele monta o texto. Ele não tem atalho com dois-pontos (os números não têm), então escreva sempre string.char(…):

print(string.char(65, 110, 97))
print(string.char(76, 117, 97))
print(string.char(("a"):byte() + 1))

$ lua char.lua
Ana
Lua
b

A última linha pega o número do a (97), soma 1 (98) e transforma de volta em letra: b, a letra seguinte. É assim que funcionam as cifras de brincadeira do tipo "troque cada letra pela próxima".

8. Acentos: a letra cortada ao meio

A tabela ASCII não tem "ç" nem "ã". As letras com acento usam o padrão UTF-8, que guarda cada uma em 2 bytes. Como o sub e o byte contam bytes, e não letras, o acento atrapalha a conta:

local palavra = "ação"
print(#palavra)
print(palavra:sub(1, 2), palavra:sub(1, 3))
print(("ç"):byte(1, -1))
print(string.char(195, 167))

$ lua acento.lua
6
a�	aç                       « o � é meio "ç": o primeiro dos seus 2 bytes
195	167
ç

O "ação" ocupa 6 bytes: a (1), ç (2), ã (2), o (1). Pedindo sub(1, 2), o Lua entregou o a e só metade do ç; o terminal não sabe mostrar meia letra e põe o � no lugar. Com sub(1, 3) o ç veio inteiro. O byte mostra os dois números do ç (195 e 167), e o char com esses dois números monta o ç de novo.

Para recortar texto com acento contando letras, a biblioteca utf8 tem as ferramentas certas: veja Acentos e a Biblioteca utf8.

Quando dá errado

Usou colchetes para pegar uma letra 
local nome = "Ana"
print(nome[1])

$ lua colchete.lua
nil

Nenhuma mensagem de erro: só um nil (o "nada", veja O Valor nil). O que aconteceu: o Lua procurou um campo chamado 1 na biblioteca string (é lá que os textos procuram tudo, como você viu no dois-pontos), e não existe nenhum. O perigo é o programa seguir com esse nil e quebrar mais adiante, longe do engano. Como consertar: nome:sub(1, 1).

Esqueceu de dizer onde começa 
$ lua -e 'print(("abc"):sub())'
lua: (command line):1: bad argument #1 to 'sub' (number expected, got no value)
stack traceback:
	[C]: in method 'sub'
	(command line):1: in main chunk
	[C]: in ?

"Argumento ruim nº 1 para o sub (esperava um número, não recebeu nenhum valor)". O início é obrigatório; só o fim é opcional. (O lua -e roda um pedacinho de código direto no terminal; por isso o lugar do erro aparece como (command line):1, "linha de comando, linha 1".) Repare no número do argumento: com o dois-pontos, o início é o #1 (in method 'sub'). Escrevendo string.sub("abc"), a mensagem diz bad argument #2 to 'sub', porque aí o texto é o nº 1 e o início é o nº 2. Como consertar: ("abc"):sub(1).

Posição com casas decimais 
local nome = "Ana Lima"
local meio = #nome / 2
print(nome:sub(1, meio))
local impar = "Bia"
print(impar:sub(1, #impar / 2))

$ lua metade.lua
Ana
lua: metade.lua:5: bad argument #2 to 'sub' (number has no integer representation)
stack traceback:
	[C]: in method 'sub'
	metade.lua:5: in main chunk
	[C]: in ?

A primeira metade funcionou: 8 / 2 dá 4.0, um número com vírgula mas que é inteiro, e o Lua aceita. Já 3 / 2 dá 1.5, e não existe a cadeira 1,5: "o número não tem representação inteira". Como consertar: use a divisão inteira //, que sempre dá um número sem vírgula: impar:sub(1, #impar // 2) (veja Divisão: /, // e %).

Número que não é de letra no string.char 
$ lua -e 'print(string.char(256))'
lua: (command line):1: bad argument #1 to 'char' (value out of range)
stack traceback:
	[C]: in field 'char'
	(command line):1: in main chunk
	[C]: in ?

"Valor fora da faixa". Cada número do string.char vira um byte, e um byte vai de 0 a 255. O 256 (ou um negativo, como -1, que dá a mesma mensagem) não cabe. Como consertar: use números de 0 a 255. Para letras além disso, como o €, existe o utf8.char (aula utf8).

Deu uma letra para o string.char 
$ lua -e 'print(string.char("A"))'
lua: (command line):1: bad argument #1 to 'char' (number expected, got string)
stack traceback:
	[C]: in field 'char'
	(command line):1: in main chunk
	[C]: in ?

"Esperava um número, recebeu um texto". O char vai do número para a letra; para ir da letra para o número, o certo é ("A"):byte(). Como consertar: troque de função.

A variável estava vazia 
local nome
print(nome:sub(1, 1))

$ lua vazia.lua
lua: vazia.lua:2: attempt to index a nil value (local 'nome')
stack traceback:
	vazia.lua:2: in main chunk
	[C]: in ?

"Tentativa de indexar um valor nil": para achar o sub, o Lua precisa olhar dentro do nome, e ele está vazio. Como consertar: dê um texto à variável antes de recortar.

Missão final: o crachá

Missão: o sistema da escola guardou o nome todo em minúsculas. Faça o crachá sair como Carla Dias (C.D.): primeira letra de cada parte em maiúscula (sub(1, 1):upper() + sub(2)) e as iniciais entre parênteses.

local nome = "carla"
local sobrenome = "dias"
local nome_bonito = nome
local sobrenome_bonito = sobrenome
local iniciais = "?.?."
print(nome_bonito .. " " .. sobrenome_bonito .. " (" .. iniciais .. ")")

local nome = "carla"
local sobrenome = "dias"
local nome_bonito = nome:sub(1, 1):upper() .. nome:sub(2)
local sobrenome_bonito = sobrenome:sub(1, 1):upper() .. sobrenome:sub(2)
local iniciais = nome_bonito:sub(1, 1) .. "." .. sobrenome_bonito:sub(1, 1) .. "."
print(nome_bonito .. " " .. sobrenome_bonito .. " (" .. iniciais .. ")")

Antes de mudar, o programa mostra carla dias (?.?.). Depois de acertar, troque "carla" por "érica" e veja o que sai: érica, sem a maiúscula. O sub(1, 1) pegou só o primeiro dos 2 bytes do é, o upper não sabe o que fazer com meio é, e o sub(2) trouxe a outra metade de volta. E a inicial sai com meia letra: (�.D.). A solução para nomes com acento está em utf8.

Resumo

  • No Lua, as posições das letras começam em 1. As negativas contam do fim: -1 é a última.
  • s:sub(i, j) recorta da posição i até a j, as duas incluídas; s:sub(i) vai até o fim; s:sub(-n) pega as n últimas.
  • Posições fora do texto não dão erro: o sub ajusta as pontas, e pode devolver "".
  • Uma letra é s:sub(i, i); s[i] dá nil.
  • s:byte(i) dá o código da letra (A = 65, a = 97); string.char(…) faz o caminho de volta, com números de 0 a 255.
  • sub, byte e # contam bytes: letras com acento ocupam 2 e podem ser cortadas ao meio. Para elas, use a biblioteca utf8.
