Lua select e o Número de Argumentos

Na aula Funções Variádicas, o select("#", ...) apareceu para contar argumentos. Mas o select ("selecionar", em inglês) faz mais: ele escolhe valores de uma lista pela posição, do começo ou do fim. Com ele, uma função variádica trabalha com o ... direto, sem criar tabela, e sem perder nenhum nil pelo caminho. Ele também serve para pegar o segundo valor de funções como string.find e string.gsub.

Você vai aprender
  • Os dois modos do select: select("#", ...) (contar) e select(n, ...) (pegar do n-ésimo em diante).
  • Por que select(n, ...) devolve vários valores, e como ficar com um só.
  • Os índices negativos: select(-1, ...) é o último.
  • A percorrer os argumentos com for i = 1, select("#", ...) sem perder os nil.
  • A usar o select com funções que devolvem vários valores.
  • Quando preferir table.pack.
  • Os erros reais: bad argument #1 to 'select' (index out of range) e companhia.

A ideia: a fila do pão

Na fila da padaria, a Ana pode fazer duas perguntas: "quantas pessoas tem na fila?" e "da terceira pessoa em diante, quem está aí?". O select responde as duas, para qualquer lista de valores:

PerguntaNo LuaResposta
Quantos são?select("#", ...)Um número
Do n-ésimo em diante, quem são?select(n, ...)Os valores da posição n até o fim
Quem são os últimos n?select(-n, ...)Os n últimos valores

O primeiro argumento do select é a pergunta; tudo o que vem depois é a fila.

1. Contando: select("#", ...)

print(select("#"))
print(select("#", "Ana"))
print(select("#", "Ana", "Bia", "Carla"))
print(select("#", nil))
print(select("#", nil, nil, nil))

$ lua contar.lua
0
1
3
1
3
"#"
O texto "#" (com aspas) é o pedido "conte". É o mesmo símbolo do operador de tamanho (aula O Operador de Tamanho), mas aqui é um texto passado como argumento.
select("#")
Nada depois do "#": zero valores.
select("#", nil, nil, nil)
3. O select conta posições, não importa o que há nelas. É isso que o # de uma tabela não consegue fazer quando há nil (aula Sequências e Buracos).

2. Escolhendo: select(n, ...)

Com um número no primeiro argumento, o select devolve o valor dessa posição e todos os seguintes:

print(select(1, "a", "b", "c", "d"))
print(select(2, "a", "b", "c", "d"))
print(select(3, "a", "b", "c", "d"))
print(select(4, "a", "b", "c", "d"))
print(select(5, "a", "b", "c", "d"))
print("fim")

$ lua a_partir.lua
a	b	c	d
b	c	d
c	d
d
                                                   « select(5, …): nada
fim

Pedir uma posição depois do fim (a 5ª de quatro) não é erro: o select devolve zero valores, e o print mostra uma linha vazia.

Ficando com um valor só

Quase sempre você quer só o valor da posição, não "dali em diante". As regras de ajuste da aula Vários Retornos resolvem:

local terceiro = select(3, "a", "b", "c", "d")
print(terceiro)
print((select(3, "a", "b", "c", "d")))
print(select(3, "a", "b", "c", "d"), "<- só o c")

$ lua so_um.lua
c
c
c	<- só o c
local terceiro = select(3, …)
Uma variável só: ela fica com o primeiro valor devolvido ("c"), e o "d" é descartado.
(select(3, …))
Os parênteses em volta cortam para um valor.
select(3, …), "…"
Não é o último da lista de argumentos: entra só o primeiro valor.

3. Contando do fim: índices negativos

Um número negativo conta a partir do fim: -1 é o último, -2 são os dois últimos, e assim por diante.

print(select(-1, "a", "b", "c", "d"))
print(select(-2, "a", "b", "c", "d"))
local ultimo = select(-1, "pão", "leite", "café")
print("último item: " .. ultimo)

$ lua negativo.lua
d
c	d
último item: café

O select(-1, ...) é o jeito curto de pegar o último argumento, sem precisar contar antes.

4. O select dentro de uma função variádica

É ali que ele mais aparece. Juntando tudo:

local function info(...)
  local n = select("#", ...)
  print("chegaram " .. n .. " argumentos")
  if n > 0 then
    print("o primeiro é", (select(1, ...)))
    print("o último é", (select(-1, ...)))
    print("do segundo em diante:", select(2, ...))
  end
end

info("Ana", "Bia", "Carla")
info()

$ lua dentro_funcao.lua
chegaram 3 argumentos
o primeiro é	Ana
o último é	Carla
do segundo em diante:	Bia	Carla
chegaram 0 argumentos

Repare no if n > 0: sem argumentos, select(-1, ...) dá erro (veja em Quando dá errado), então a função confere antes.

Missão: a função ultimo deveria devolver o último nome da fila, mas devolve o primeiro. Use select com um índice negativo para ela devolver Carla.

local function ultimo(...)
  return (...)
end

print("Último da fila: " .. ultimo("Ana", "Bia", "Carla"))

local function ultimo(...)
  return (select(-1, ...))
end

print("Último da fila: " .. ultimo("Ana", "Bia", "Carla"))

5. Percorrendo os argumentos sem perder os nil

O ipairs({...}) para no primeiro nil. Com o select, dá para visitar cada posição, de 1 até a contagem:

local function mostrar(...)
  for i = 1, select("#", ...) do
    local valor = (select(i, ...))
    print(i, valor)
  end
end

mostrar("Ana", nil, 42, false)

$ lua laco.lua
1	Ana
2	nil
3	42
4	false
  1. select("#", ...) dá 4, então o for vai de 1 a 4.
  2. A cada volta, (select(i, ...)) pega o valor da posição i, cortado para um só pelos parênteses.
  3. O nil da posição 2 aparece, e o laço continua até o false.

Ou com table.pack

O mesmo laço pode ser escrito com table.pack(...), que guarda os argumentos numa tabela com o campo n (ou com o ...nome do 5.5, aula Funções Variádicas):

local function mostrar(...)
  local args = table.pack(...)
  for i = 1, args.n do
    print(i, args[i])
  end
end

mostrar("Ana", nil, 42, false)

$ lua laco_pack.lua
1	Ana
2	nil
3	42
4	false

A saída é a mesma. A diferença está no trabalho: cada select(i, ...) devolve todos os valores da posição i até o fim (e o Lua joga fora os que sobram), enquanto o table.pack monta a tabela uma vez. Com poucos argumentos não faz diferença. Com muitos, faz: num teste no lab, com 200 argumentos e 20 mil repetições, a versão com select levou cerca de 0,75 segundo e a com table.pack, cerca de 0,11 (os números mudam de computador para computador, mas a diferença fica).

6. select com funções de vários retornos

O select não serve só para o ...: qualquer lista de valores entra. Por isso ele é útil para pegar o segundo valor de uma função que devolve vários:

local texto = "Padaria do bairro"
print(string.find(texto, "do"))
print(select(2, string.find(texto, "do")))
print(select(2, string.gsub("banana", "a", "o")))
print(select("#", string.find(texto, "xyz")))
print(select("#", io.open("nao_existe.txt")))

$ lua retornos.lua
9	10
10
3
1
3
select(2, string.find(…))
O string.find devolve onde o achado começa e termina (9, 10); o select(2, …) fica com o fim.
select(2, string.gsub(…))
Só a quantidade de trocas (3), sem o texto novo. Um jeito de contar quantas vezes uma letra aparece.
select("#", string.find(texto, "xyz"))
Quando não acha, o string.find devolve um valor só, o nil: a contagem dá 1.
select("#", io.open(…))
Quando falha, o io.open devolve três valores (nil, a mensagem e o número do erro).

O select("#", f()) é um bom jeito de descobrir quantos valores uma função devolve.

E nas outras versões?

O select é igual no Lua 5.1, no LuaJIT, no 5.4 e no 5.5, inclusive os índices negativos (o mesmo negativo.lua deu a mesma saída no lua5.1). Ele é o único jeito de contar argumentos que existe em todas as versões: o table.pack não existe no Lua 5.1, e o ...nome só existe no 5.5.

O erro foi percebido dentro do select, que é escrito em C. O nosso código culpado vem na linha de baixo: erro_zero.lua:1.

O mesmo erro aparece com um negativo maior que a lista: select(-5, "a", "b") dá bad argument #1 to 'select' (index out of range). E por isso select(-1, ...) sem nenhum argumento também falha. Como consertar: confira a contagem antes, if select("#", ...) > 0 then.

Esquecer o primeiro argumento, ou mandar um texto qualquer 
print(select("2", "a", "b"))
print(select("dois", "a", "b"))

$ lua erro_texto.lua
b
lua: erro_texto.lua:2: bad argument #1 to 'select' (number expected, got string)
stack traceback:
	[C]: in global 'select'
	erro_texto.lua:2: in main chunk
	[C]: in ?

O "2" funcionou, porque o Lua converte um texto que parece número. Já "dois" não: number expected, got string, "esperava um número, veio um texto". Só o texto "#" tem significado especial. Sem argumento nenhum, select() dá bad argument #1 to 'select' (number expected, got no value) ("veio nada").

Pedir uma posição que não veio 
local function primeiro_nome(...)
  return "Olá, " .. select(1, ...)
end
print(primeiro_nome("Ana", "Bia"))
print(primeiro_nome())

$ lua erro_nome.lua
Olá, Ana
lua: erro_nome.lua:2: attempt to concatenate a nil value
stack traceback:
	erro_nome.lua:2: in local 'primeiro_nome'
	erro_nome.lua:5: in main chunk
	[C]: in ?

Na segunda chamada não há argumentos. select(1, ...) não dá erro (posição depois do fim é permitida), mas devolve zero valores; no .., esse "nada" vira nil. Como o valor não estava numa variável, a mensagem não diz nome. Como consertar: confira select("#", ...) antes, ou dê um padrão: local nome = (...) or "cliente".

Esquecer os parênteses e mostrar valores demais

Sem erro: print(i, select(i, ...)) mostra a posição i e todas as seguintes, porque o select é o último argumento do print. Como consertar: print(i, (select(i, ...))), ou guarde antes numa variável, como em laco.lua. Numa conta, como soma + select(i, ...), isso não acontece: lá só o primeiro valor entra.

Missão final: a chamada da turma

Missão: a professora passa os nomes de quem respondeu à chamada, com nil no lugar de quem faltou. A função deveria dizer Presentes: 3 de 5, mas o ipairs para no primeiro nil. Reescreva a contagem com select: o total é select("#", ...), e os presentes são as posições cujo valor não é nil.

local function presenca(...)
  local presentes = 0
  for _, nome in ipairs({...}) do
    presentes = presentes + 1
  end
  local total = 0
  for _ in ipairs({...}) do
    total = total + 1
  end
  print("Presentes: " .. presentes .. " de " .. total)
end

presenca("Ana", nil, "Bia", nil, "Carla")

local function presenca(...)
  local total = select("#", ...)
  local presentes = 0
  for i = 1, total do
    if (select(i, ...)) ~= nil then
      presentes = presentes + 1
    end
  end
  print("Presentes: " .. presentes .. " de " .. total)
end

presenca("Ana", nil, "Bia", nil, "Carla")

Resumo

  • select("#", ...) conta os valores, inclusive os nil.
  • select(n, ...) devolve do n-ésimo valor até o fim; para ficar com um só, use parênteses ou uma variável.
  • Negativos contam do fim: select(-1, ...) é o último.
  • Posição depois do fim: zero valores. Posição 0, ou negativa além do começo: index out of range.
  • for i = 1, select("#", ...) com (select(i, ...)) percorre tudo sem perder nil; com muitos argumentos, table.pack faz o mesmo com menos trabalho.
  • select(2, f()) pega o segundo valor de uma função de vários retornos.
  • O select existe igual em todas as versões do Lua.
