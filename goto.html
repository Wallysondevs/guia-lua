Lua goto e rótulos

Muitas linguagens têm uma palavra para dizer "esta volta do laço não me interessa, passe para a próxima": é o continue ("continuar"). O Lua não tem continue. No lugar dele, o Lua tem uma ferramenta mais geral: o goto (em inglês, "vá para"), que pula para um ponto marcado do programa, chamado rótulo. Escrever goto continue e pôr o rótulo ::continue:: no fim do laço é o jeito que a comunidade Lua usa no lugar do continue.

Você vai aprender
  • Por que continue sozinho dá erro de sintaxe no Lua.
  • O que é um rótulo (::nome::) e como o goto pula até ele.
  • O jeito idiomático: goto continue + ::continue:: no fim do laço, no for e no while.
  • O erro real "jumps into the scope of": quando o pulo cai dentro do alcance de uma variável local, e como consertar com do … end.
  • A pegadinha do repeat … until com goto continue.
  • Como sair de dois laços de uma vez com um goto.
  • As outras mensagens reais: rótulo que não existe, rótulo repetido, pulo para dentro de um bloco.

Todos os programas desta aula rodaram no Lua 5.5 da máquina da Ana (usuária ana, computador notebook), salvos na pasta pessoal dela e executados com lua arquivo.lua (veja Rodando um Programa). Você pode rodar cada um no editor do guia. Antes desta aula, vale ter visto for Numérico, while e break.

A ideia: "pule para a placa"

A Ana confere o estoque da padaria com uma lista na mão. Para cada produto, ela faz três coisas: olha a prateleira, anota a quantidade e cola uma etiqueta de preço. Mas quando a prateleira está vazia, não há o que etiquetar. O dono deixou uma placa pendurada no fim do corredor, escrita "PRÓXIMO PRODUTO", e um bilhete: "se a prateleira estiver vazia, vá direto para a placa".

  1. Prateleira do pão: tem pão → anota, etiqueta, chega à placa e segue para o próximo.
  2. Prateleira do leite: vazia → pula tudo e vai direto para a placa.
  3. Prateleira do café: tem café → anota, etiqueta, chega à placa…

No Lua, a placa é um rótulo: um nome entre dois pares de dois-pontos, como ::continue::. O bilhete "vá para a placa" é o goto continue. Quando o goto roda, o Lua pula para a linha do rótulo e continua dali. Se o rótulo está no fim do laço, pular para ele é o mesmo que dizer "acabou esta volta, vamos para a próxima".

PeçaComo se escreveO que faz
Rótulo (a placa)::continue::Marca um ponto do programa com um nome. Sozinho, não faz nada: o Lua passa por ele como se não existisse.
O pulo (o bilhete)goto continueFaz o programa continuar a partir do rótulo com esse nome.

1. O Lua não tem continue

Quem já viu outra linguagem tenta logo isto, para mostrar os números de 1 a 5 menos o 3:

for i = 1, 5 do
  if i == 3 then
    continue
  end
  print(i)
end

$ lua continue_palavra.lua
lua: continue_palavra.lua:4: syntax error near 'end'
$ echo $?
1

"Erro de sintaxe perto de end", na linha 4. Para o Lua, continue não é uma palavra especial: é só um nome qualquer, como preco ou x. Um nome sozinho numa linha não é um comando completo (o Lua esperava algo como continue = 1 ou continue()), e ele só percebe isso quando chega ao end da linha 4. Por isso a mensagem aponta o end, e não o continue. Repare que nenhum número foi mostrado: com erro de sintaxe, o programa nem começa a rodar, e não aparece stack traceback.

2. O jeito idiomático: goto continue

Este programa mostra só os números pares de 1 a 10. Quando o número é ímpar, ele pula para o rótulo no fim do laço:

for i = 1, 10 do
  if i % 2 == 1 then
    goto continue
  end
  print(i)
  ::continue::
end
print("fim")
for i = 1, 10 do
Um for numérico comum: i vale 1, 2, 3… até 10.
if i % 2 == 1 then
O % é o resto da divisão (veja Divisão: /, // e %). Resto 1 na divisão por 2 quer dizer "ímpar".
goto continue
"Vá para o rótulo continue." As linhas que estão entre o goto e o rótulo (aqui, o print(i)) são puladas.
print(i)
Só chega aqui quem não pulou: os pares.
::continue::
O rótulo: dois-pontos duplos, o nome, dois-pontos duplos. Ele fica na última linha do corpo do laço, logo antes do end. Chegar até ele (pulando ou não) é chegar ao fim da volta.
end
Fim do corpo. O for passa para o próximo i.
$ lua pares.lua
2
4
6
8
10
fim

O nome continue não é obrigatório: goto proximo com ::proximo:: funcionaria igual. Mas continue é o nome que todo mundo usa, justamente porque faz o papel do continue das outras linguagens. Quem ler o seu código vai entender na hora.

Passo a passo: as três primeiras voltas

Voltaii % 2 == 1?O que acontece
1ª1truegoto continue: pula o print, cai no rótulo, a volta acaba
2ª2falseNão entra no if; mostra 2; passa pelo rótulo (que não faz nada); a volta acaba
3ª3truePula de novo
goto continue × break

O break ("quebrar") sai do laço de vez: as voltas que faltavam não acontecem. O goto continue só encerra a volta atual: o laço segue com o próximo valor. No exemplo acima, um break no lugar do goto pararia tudo logo no i = 1, e o programa mostraria só fim.

Um exemplo da padaria

Agora o estoque da Ana: duas listas, uma com os produtos e outra com as quantidades na mesma ordem (as listas têm aula própria em Tabelas como Listas; por enquanto, basta saber que produtos[2] é o segundo produto e #produtos é quantos são). Produto com quantidade 0 é avisado e pulado:

local produtos = {"pão", "leite", "café", "manteiga"}

  end

  ::continue::
end

$ lua estoque.lua

(pulando manteiga: acabou)

Missão: este programa mostra até os produtos que acabaram (leite: 0 no estoque). Use goto continue e o rótulo ::continue:: para pular os produtos com quantidade 0. (Mostrar um aviso de "pulando" é opcional.)

local produtos = {"pão", "leite", "café", "manteiga"}
local quantidades = {12, 0, 5, 0}

for i = 1, #produtos do
  print(produtos[i] .. ": " .. quantidades[i] .. " no estoque")
end

local quantidades = {12, 0, 5, 0}

for i = 1, #produtos do
  if quantidades[i] == 0 then
    goto continue
  end
  print(produtos[i] .. ": " .. quantidades[i] .. " no estoque")
  ::continue::
end

3. No while também

O goto continue funciona em qualquer laço. A professora da Ana quer a média das notas, mas algumas foram digitadas erradas (fora de 0 a 10) e devem ser ignoradas:

local notas = {7, -1, 9, 15, 6}
local soma, contadas = 0, 0
local i = 0
while i < #notas do
  i = i + 1
  local nota = notas[i]
  if nota < 0 or nota > 10 then
    print("nota inválida ignorada: " .. nota)
    goto continue
  end
  soma = soma + nota
  contadas = contadas + 1
  ::continue::
end
print("média: " .. soma / contadas)

$ lua while_cont.lua
nota inválida ignorada: -1
nota inválida ignorada: 15
média: 7.333333333333333

Repare num detalhe importante: o i = i + 1 está no começo do corpo, antes de qualquer goto. Se ele ficasse depois do goto continue, as voltas que pulam não somariam 1 ao i, o i ficaria parado na nota inválida, e o laço nunca terminaria (um laço infinito; veja while). No for numérico esse perigo não existe: quem anda com o i é o próprio for.

E a local nota declarada antes do goto? Sem problema nenhum. O cuidado é com a local que fica entre o goto e o rótulo, que é o assunto da próxima seção.

4. O erro clássico: pular para dentro do escopo de uma local

Uma variável local existe da linha em que foi declarada até o fim do bloco (o escopo dela; veja local × Global e Escopo e Blocos). O goto tem uma regra: ele não pode pular por cima da declaração de uma local e cair num ponto onde ela já deveria existir. Se pudesse, a variável estaria "valendo" sem nunca ter recebido valor.

Olhe este programa. Ele declara local dobro entre o goto e o rótulo, e ainda tem um print depois do rótulo:

for i = 1, 3 do
  if i == 2 then
    goto continue
  end
  local dobro = i * 2
  print(dobro)
  ::continue::
  print("volta", i, "terminou")
end

$ lua escopo.lua
lua: escopo.lua:8: <goto continue> at line 3 jumps into the scope of 'dobro'
$ echo $?
1

Linha por linha:

lua: escopo.lua:8:
Quem reclama é o lua, no arquivo escopo.lua. A linha 8 é onde ele percebeu o problema: o print depois do rótulo, que ainda está dentro do escopo de dobro.
<goto continue> at line 3
"O goto continue da linha 3…"
jumps into the scope of 'dobro'
"…pula para dentro do escopo de dobro." Pulando da linha 3 para a linha 7, o programa passaria por cima do local dobro = i * 2 (linha 5), mas cairia num lugar onde dobro ainda existe (a linha 8 poderia usá-la).

É um erro de compilação, como um erro de sintaxe: o Lua confere isso antes de rodar a primeira linha. Por isso não saiu nem o 2 da primeira volta, e não há stack traceback.

Por que o pares.lua não deu esse erro?

Tire o print de depois do rótulo, e o mesmo programa funciona:

for i = 1, 3 do
  if i == 2 then
    goto continue
  end
  local dobro = i * 2
  print(dobro)
  ::continue::
end

$ lua escopo_ok.lua
2
6

O manual do Lua explica: o escopo de uma local vai até o último comando "de verdade" do bloco. Rótulos (e o ; sozinho) não contam: o manual os chama de comandos vazios (void statements). Com o ::continue:: sendo a última coisa antes do end, o escopo de dobro já terminou no print(dobro), e o pulo cai do lado de fora. Essa é a razão de o rótulo ::continue:: ficar sempre colado no end.

Como consertar quando você precisa de algo depois do rótulo

Ponha as variáveis que ficam entre o goto e o rótulo dentro de um bloco do … end (veja Sintaxe e Blocos). O escopo delas termina no end desse bloco, antes do rótulo:

for i = 1, 3 do
  if i == 2 then
    goto continue
  end
  do
    local dobro = i * 2
    print(dobro)
  end
  ::continue::
  print("volta", i, "terminou")
end

$ lua escopo_conserto.lua
2
volta	1	terminou
volta	2	terminou
6
volta	3	terminou

(Os espaços largos entre volta, o número e terminou são o TAB que o print põe entre vários valores.) A volta 2 pulou o dobro, mas passou pelo print do fim: o rótulo aqui não é um "fim de volta", é um "pule até aqui".

Missão: este é o escopo.lua, que nem chega a rodar. Conserte-o sem tirar o goto nem o print do fim: ponha a local dobro e o print(dobro) dentro de um do … end.

for i = 1, 3 do
  if i == 2 then
    goto continue
  end
  local dobro = i * 2
  print(dobro)
  ::continue::
  print("volta", i, "terminou")
end

for i = 1, 3 do
  if i == 2 then
    goto continue
  end
  do
    local dobro = i * 2
    print(dobro)
  end
  ::continue::
  print("volta", i, "terminou")
end

5. A pegadinha do repeat … until

No repeat … until, a condição do until faz parte do corpo do laço: ela enxerga as variáveis local do corpo. Isso quer dizer que o ::continue:: antes do until não é a última coisa do bloco, e o erro da seção 4 aparece mesmo com o rótulo "no fim":

local n = 0
repeat
  n = n + 1
  if n == 2 then
    goto continue
  end
  local quadrado = n * n
  print(n, quadrado)
  ::continue::
until n >= 4

$ lua repeat.lua
lua: repeat.lua:10: <goto continue> at line 5 jumps into the scope of 'quadrado'

A linha 10 é a do until: o until n >= 4 poderia usar quadrado, então ele ainda está no escopo dela. O conserto é o mesmo: um do … end em volta da local.

local n = 0
repeat
  n = n + 1
  if n == 2 then
    goto continue
  end
  do
    local quadrado = n * n
    print(n, quadrado)
  end
  ::continue::
until n >= 4

$ lua repeat2.lua
1	1
3	9
4	16

6. Sair de dois laços de uma vez

O break só sai do laço mais de dentro. Quando há um laço dentro de outro (veja Laços Aninhados) e você quer parar tudo assim que achar o que procurava, o goto resolve com um rótulo depois dos dois laços. A Ana procura o Davi nas turmas da escola:

local turmas = {
  {"Ana", "Bia", "Caio"},
  {"Davi", "Eva"},
}
for t = 1, #turmas do
  for a = 1, #turmas[t] do
    if turmas[t][a] == "Davi" then
      print("Achei o Davi na turma " .. t .. ", posição " .. a)
      goto achou
    end
    print("olhando " .. turmas[t][a])
  end
end
print("Davi não está em nenhuma turma")
::achou::
print("fim da busca")

$ lua aninhado.lua
olhando Ana
olhando Bia
olhando Caio
Achei o Davi na turma 2, posição 1
fim da busca

O goto achou sai dos dois for e ainda pula o aviso "não está em nenhuma turma". Com um break no lugar, só o laço de dentro pararia: o de fora seguiria para a próxima turma, e o aviso apareceria mesmo tendo achado o Davi. (turmas[t][a] é "a turma número t, aluno número a": uma lista dentro de outra, assunto de Tabelas Aninhadas.)

7. goto para trás: funciona, mas evite

O goto também pula para um rótulo que está antes dele, e isso cria uma repetição:

local tentativa = 1
::de_novo::
print("tentativa " .. tentativa)
tentativa = tentativa + 1
if tentativa <= 3 then
  goto de_novo
end
print("acabou")

$ lua voltar.lua
tentativa 1
tentativa 2
tentativa 3
acabou

Funciona, mas é um while disfarçado, e mais difícil de ler: quem chega ao ::de_novo:: não sabe que ali começa uma repetição até achar o goto lá embaixo. Programas cheios de goto para cima e para baixo ganharam até um apelido: "código espaguete", porque o caminho do programa vira um prato de macarrão. A regra prática é usar o goto só nos dois casos desta aula: o continue e sair de laços aninhados. Para repetir, use while, repeat ou for.

Formas diferentes de fazer a mesma coisa

Pular uma volta nem sempre precisa de goto. O pares.lua pode ser escrito com o if "ao contrário": em vez de "se for ímpar, pule", diga "se for par, mostre":

for i = 1, 10 do
  if i % 2 == 0 then
    print(i)
  end
end
print("fim")

$ lua if_invertido.lua
2
4
6
8
10
fim

Com uma linha só dentro do if, essa forma é a mais simples. O goto continue ganha quando há várias condições para pular e muito código depois delas: em vez de um if dentro de outro if dentro de outro, empurrando o código para a direita, cada condição vira uma linha "se for assim, pule" no começo da volta, e o resto fica na margem normal.

SituaçãoQual usar
Pular a volta por um motivo simples, com pouco código depoisif com a condição invertida
Várias condições para pular, ou muito código depois delasgoto continue + ::continue:: colado no end
Parar o laço de vezbreak
Parar dois ou mais laços de uma vezgoto para um rótulo depois dos laços (ou pôr os laços numa função e usar return)
Repetirwhile, repeat ou for, nunca goto para trás
Em outras versões do Lua

O goto chegou no Lua 5.2. No Lua 5.1 ele não existe; lá, goto é um nome comum e o pares.lua dá erro de sintaxe:

$ lua5.1 pares.lua
lua5.1: pares.lua:3: '=' expected near 'continue'

O LuaJIT (Neovim, LÖVE), que segue o 5.1, aceita o goto: no lab, luajit pares.lua mostrou 2, 4, 6… igual ao 5.5. No Lua 5.4 a mensagem do escopo diz jumps into the scope of local 'dobro' (com a palavra local); no 5.5 ela diz só 'dobro'. Mais em Lua 5.1, LuaJIT, 5.4 e 5.5.

Quando dá errado

O nome do rótulo não bate com o do goto 
for i = 1, 3 do
  if i == 2 then
    goto continua
  end
  print(i)
  ::continue::
end

$ lua semrotulo.lua
lua: semrotulo.lua:7: no visible label 'continua' for <goto> at line 3

"Nenhum rótulo visível chamado continua para o goto da linha 3." O goto diz continua e o rótulo diz continue: para o Lua são nomes diferentes. A linha 7 é o end do laço, onde ele desistiu de procurar. Como consertar: use o mesmo nome nos dois lugares.

O rótulo está em outro laço 
for i = 1, 3 do
  print(i)
end
goto continue
for j = 1, 3 do
  ::continue::
  print(j)
end

$ lua fora.lua
lua: fora.lua:8: no visible label 'continue' for <goto> at line 4

O rótulo existe, mas não é visível de onde o goto está. Um rótulo só é visível no bloco onde foi escrito (e nos blocos de dentro dele). O ::continue:: está dentro do segundo for; o goto, fora. O goto pode sair de blocos (como na seção 6), mas não pode entrar num. O mesmo vale para um do … end:

goto meio
do
  ::meio::
  print("dentro do bloco")
end

$ lua dentro.lua
lua: dentro.lua:5: no visible label 'meio' for <goto> at line 1
Dois rótulos com o mesmo nome 
for i = 1, 3 do
  ::continue::
  if i == 2 then
    goto continue
  end
  print(i)
  ::continue::
end

$ lua duplicado.lua
lua: duplicado.lua:7: label 'continue' already defined on line 2

"O rótulo continue já foi definido na linha 2." Num mesmo bloco, cada rótulo tem um nome único (senão, para qual dos dois o goto iria?). Como consertar: apague um deles. Laços diferentes podem ter cada um o seu ::continue::, inclusive um laço dentro do outro: cada goto continue vai para o rótulo do laço onde ele está (veja Laços Aninhados). O problema é só repetir o nome no mesmo bloco.

Pulou para dentro do escopo de uma local 
$ lua escopo.lua
lua: escopo.lua:8: <goto continue> at line 3 jumps into the scope of 'dobro'

Visto na seção 4: entre o goto e o rótulo há uma local, e depois do rótulo ainda há código (ou um until). Como consertar: deixe o ::continue:: como última linha antes do end, ou ponha a local dentro de um do … end.

Escreveu continue como em outras linguagens 
$ lua continue_palavra.lua
lua: continue_palavra.lua:4: syntax error near 'end'

O Lua não tem continue; para ele, é só um nome solto. Como consertar: goto continue e o rótulo ::continue:: antes do end do laço.

Missão final: a média só das notas válidas

Missão: o programa calcula a média de todas as notas, mas 12 e -3 foram digitadas erradas. Dentro do laço, antes de somar, use goto continue para pular as notas menores que 0 ou maiores que 10, e ponha o ::continue:: no lugar certo. A média certa é 8.0.

local notas = {8, 12, 7, -3, 9}
local soma, contadas = 0, 0
for i = 1, #notas do
  local nota = notas[i]
  soma = soma + nota
  contadas = contadas + 1
end
print("média: " .. soma / contadas)

local notas = {8, 12, 7, -3, 9}
local soma, contadas = 0, 0
for i = 1, #notas do
  local nota = notas[i]
  if nota < 0 or nota > 10 then
    print("ignorando " .. nota)
    goto continue
  end
  soma = soma + nota
  contadas = contadas + 1
  ::continue::
end
print("média: " .. soma / contadas)

Sem o pulo, o programa mostra média: 6.6 (33 dividido por 5). Com ele, no lab, saiu:

$ lua media.lua
ignorando 12
ignorando -3
média: 8.0

O 8.0 tem o .0 porque a divisão / sempre dá um número com vírgula (um float; veja Números).

Resumo

  • O Lua não tem continue: escrito sozinho, ele dá syntax error.
  • Um rótulo ::nome:: marca um ponto do programa; goto nome pula até ele.
  • O jeito idiomático de pular uma volta: goto continue e o rótulo ::continue:: como última linha do corpo do laço, colado no end. Funciona no for e no while (no while, ande com o contador antes do goto).
  • O goto não pode pular para dentro do escopo de uma local: jumps into the scope of 'x'. Conserto: rótulo colado no end, ou a local dentro de um do … end. No repeat … until, o until conta como parte do corpo.
  • O goto pode sair de blocos (bom para parar laços aninhados), mas não entrar neles.
  • Use o goto só para o "continue" e para sair de laços aninhados. Para repetir, use os laços.
