Lua math

Somar, subtrair, multiplicar e dividir você já sabe fazer com os operadores. Mas a Ana logo precisa de mais: quantas caixas de ovos levar, qual foi a maior nota da turma, quanto mede uma pizza, como mostrar um preço arredondado. Para isso o Lua tem a biblioteca math ("matemática"): uma tabela, que já vem carregada, cheia de funções e valores prontos. Você escreve math. e o nome da ferramenta.

Você vai aprender
  • Arredondar para baixo e para cima: math.floor e math.ceil, e como arredondar para o mais perto (o Lua não tem math.round).
  • O maior, o menor e a distância: math.max, math.min e math.abs.
  • Raiz, potência e o math.pi.
  • Inteiros e floats: math.type, math.tointeger, math.maxinteger e o que acontece quando passa do limite.
  • O infinito (math.huge) e o estranho nan.
  • math.fmod e math.modf, e por que 0.1 + 0.2 não dá exatamente 0.3.
  • Os erros reais: bad argument #1 to 'floor', o Math com maiúscula e o math.round que não existe.

As saídas são do Lua 5.5 da máquina da Ana. Os sorteios (math.random) têm uma aula só para eles: Números Aleatórios. A lista completa de funções está em Referência: a Biblioteca math.

A ideia: a calculadora científica da gaveta

A calculadora simples do caixa da padaria faz as quatro contas. A calculadora científica, que a Ana guardou da escola, tem teclas a mais: raiz quadrada, π, potência, arredondar. Você não precisa saber como ela calcula uma raiz por dentro: aperta a tecla e pronto. A biblioteca math é essa calculadora: cada função é uma tecla.

Ela é uma tabela comum, guardada na variável global math, que o Lua carrega antes do seu programa começar (como as outras bibliotecas padrão; veja Módulos e require). Por isso não precisa de require.

1. Arredondar para baixo e para cima: floor e ceil

print(math.floor(3.7), math.ceil(3.2))
print(math.floor(-3.7), math.ceil(-3.2))
print(math.floor(5), math.type(math.floor(3.7)))

$ lua arredondar.lua
3	4
-4	-3
5	integer
math.floor(3.7) → 3
floor é "chão": desce até o inteiro de baixo. Não importa se faltava pouco (3,7 vira 3, não 4).
math.ceil(3.2) → 4
ceil (de ceiling) é "teto": sobe até o inteiro de cima.
math.floor(-3.7) → -4
Cuidado com os negativos: "para baixo" é na direção do menos infinito, então −3,7 desce para −4 (e não para −3).
math.floor(5) → 5
Um número que já é inteiro fica como está.
math.type(…) → integer
O resultado é um inteiro de verdade (sem .0), pronto para contar coisas ou servir de posição numa lista (veja Números).

Para que serve: as caixas de ovos

A Ana tem 50 ovos para vender e cada caixa leva 12. Quantas caixas ficam cheias? E quantas caixas ela precisa levar para carregar todos os ovos?

local ovos = 50
local por_caixa = 12
print("Divisão:", ovos / por_caixa)
print("Caixas cheias:", math.floor(ovos / por_caixa))
print("Caixas para levar tudo:", math.ceil(ovos / por_caixa))

$ lua ovos.lua
Divisão:	4.166666666666667
Caixas cheias:	4
Caixas para levar tudo:	5

A divisão dá 4,17 caixas, que não existe. Cheias são 4 (arredonda para baixo: a quinta não completa). Mas para levar os 50 ovos, a quinta caixa é necessária, mesmo meio vazia: arredonda para cima. Repare que math.floor(a / b) é o mesmo que a divisão inteira a // b (veja Divisão: /, // e %).

Missão: a padaria vende pães de queijo em pacotes de 6. Um cliente encomendou 45. O programa usa math.floor e diz 7 pacotes, mas aí faltariam pães! Troque pela função que arredonda para cima.

local paes = 45
local por_pacote = 6
local pacotes = math.floor(paes / por_pacote)
print("Pacotes: " .. pacotes)

local paes = 45
local por_pacote = 6
local pacotes = math.ceil(paes / por_pacote)
print("Pacotes: " .. pacotes)

2. Arredondar para o mais perto

Quem vem de outras linguagens procura um math.round. No Lua ele não existe (o erro está em Quando dá errado). Há dois caminhos, e eles servem para coisas diferentes:

local function arredondar(x, casas)
  local fator = 10 ^ (casas or 0)
  return math.floor(x * fator + 0.5) / fator
end
print(arredondar(2.5), arredondar(2.4), arredondar(-2.5))
print(arredondar(3.14159, 2), arredondar(19.995, 2))
print(string.format("%.2f", 3.14159), string.format("%.0f", 2.5), string.format("%.0f", 3.5))

$ lua casas.lua
3.0	2.0	-2.0
3.14	20.0
3.14	2	4
math.floor(x + 0.5)
O truque clássico: somar meio e arredondar para baixo. 2,4 + 0,5 = 2,9 → 2. 2,5 + 0,5 = 3,0 → 3. O "meio" sempre sobe (por isso −2,5 virou −2).
10 ^ (casas or 0)
Para 2 casas, o fator é 100: multiplica por 100, arredonda, divide por 100. Sem o segundo argumento, casas é nil, e o or 0 usa 0 casas. O resultado sai como float (3.0) porque ^ e / sempre dão float.
string.format("%.2f", x)
Não muda o número: escreve um texto com 2 casas (veja string.format). É o certo para mostrar dinheiro.
"%.0f" com 2.5 → 2, com 3.5 → 4
Surpresa: o string.format arredonda o "meio exato" para o par mais perto (2,5 → 2; 3,5 → 4). É uma regra usada em contabilidade, e vem da linguagem C. Se você precisa que o meio sempre suba, use a função arredondar.
Qual usar?

Para mostrar na tela: string.format("%.2f", valor). Para continuar fazendo contas com o número arredondado: a função com math.floor(x + 0.5). E para dinheiro de verdade, muitos programadores guardam os centavos como inteiros (R$ 19,99 = 1999), que nunca têm problema de arredondamento.

3. O maior, o menor e a distância: max, min e abs

local notas = {7.5, 9, 4, 8.5}
print("Maior:", math.max(table.unpack(notas)))
print("Menor:", math.min(table.unpack(notas)))
print("Diferença da meta:", math.abs(6 - 4), math.abs(6 - 9))

$ lua notas.lua
Maior:	9
Menor:	4
Diferença da meta:	2	3
math.max(a, b, c, …)
Devolve o maior dos números que você passar, quantos forem (pelo menos um).
math.min(…)
O menor.
table.unpack(notas)
O max não recebe uma lista: recebe os números soltos. O table.unpack "desempacota" a lista em 7.5, 9, 4, 8.5 (veja table.unpack). Para listas enormes (milhares de itens), prefira um laço.
math.abs(x)
O valor absoluto: o número sem o sinal. 6 - 9 dá −3, mas a distância até a meta é 3. Serve para "quanto falta ou quanto passou", sem importar o lado.

4. Raiz, potência e o math.pi

Qual é a área de uma pizza de 30 cm? A área de um círculo é π × raio²:

local diametro = 30
local raio = diametro / 2
local area = math.pi * raio ^ 2
print(math.pi)
print(area)
print(string.format("Área: %.1f cm²", area))
print(math.sqrt(16), 16 ^ 0.5, 27 ^ (1/3))

$ lua pizza.lua
3.1415926535897931
706.85834705770344
Área: 706.9 cm²
4.0	4.0	3.0
math.pi
Não é uma função (não tem parênteses): é um valor guardado na tabela, o π, com toda a precisão que o computador guarda.
raio ^ 2
A potência é o operador ^: raio ^ 2 = raio ao quadrado. (O Lua 5.1 tinha também math.pow; no 5.5 ela não existe mais: print(math.pow) mostra nil.)
math.sqrt(16)
Square root, a raiz quadrada. O mesmo que 16 ^ 0.5. A raiz cúbica é 27 ^ (1/3).
4.0
A raiz sempre devolve float, mesmo quando o resultado é "redondo".

5. Inteiros e floats: type, tointeger e os limites

Desde o Lua 5.3, há dois tipos de número: o inteiro (10) e o float, com vírgula (10.0). A math tem ferramentas para lidar com os dois:

print(math.maxinteger, math.mininteger)
print(math.maxinteger + 1)
print(math.type(10), math.type(10.0), math.type("10"))
print(math.tointeger(8.0), math.tointeger(8.5))
print(10 // 3, 10.0 // 3, 7 / 7)

$ lua inteiros.lua
9223372036854775807	-9223372036854775808
-9223372036854775808
integer	float	nil
8	nil
3	3.0	1.0
math.maxinteger, math.mininteger
O maior e o menor inteiro que cabem: mais de 9 quintilhões, para cada lado.
math.maxinteger + 1
Passou do limite, dá a volta e vira o menor de todos, sem aviso nenhum (como o hodômetro de um carro velho, que volta a 00000). Na prática, você só chega lá com contas gigantes; mas se um total "virou negativo do nada", lembre disso.
math.type(x)
"integer" (inteiro), "float", ou nil se não for número (o texto "10" não é número). O type comum diria só "number" para os dois (veja type).
math.tointeger(8.0) → 8
Converte um float "redondo" em inteiro. Se tiver parte quebrada (8,5), devolve nil, porque não dá para converter sem perder informação.
10 // 3 → 3, 10.0 // 3 → 3.0, 7 / 7 → 1.0
Um lembrete: a divisão / sempre dá float; a // dá inteiro se os dois lados forem inteiros.
No Lua 5.1 e no LuaJIT

Lá não existe essa separação: todo número é float. Não há math.type, math.tointeger nem math.maxinteger (no lab, lua5.1 -e 'print(math.maxinteger)' mostra nil), e 10 / 2 aparece como 5, sem .0. Veja as diferenças entre versões.

6. Infinito e "não é número": math.huge e nan

print(math.huge, -math.huge)
print(1 / 0, -1 / 0)
print(0 / 0, math.sqrt(-1))
local nan = 0 / 0
print(nan == nan)
local menor = math.huge
for _, p in ipairs({4.5, 2.25, 3}) do
  menor = math.min(menor, p)
end
print("Mais barato:", menor)

$ lua infinito.lua
inf	-inf
inf	-inf
-nan	-nan
false
Mais barato:	2.25
math.huge → inf
O "infinito" dos floats: maior que qualquer número. 1 / 0 com floats também dá inf (não é erro). Já a divisão inteira por zero, 1 // 0, é erro (veja Divisão).
0 / 0 → -nan
NaN é "not a number", "não é um número": o resultado de uma conta sem resposta, como zero dividido por zero ou a raiz de um negativo. O sinal de menos na frente vem da biblioteca C que escreve o número (no lab e no editor do guia sai -nan); em outros sistemas pode sair nan. Não dependa do sinal.
nan == nan → false
O nan não é igual nem a ele mesmo. É o único valor assim, e é o jeito de testar se uma conta deu nan: if x ~= x then.
local menor = math.huge
Um uso prático: para achar o menor preço num laço, comece com o infinito. Qualquer preço de verdade é menor que ele, então o primeiro já ganha.

7. Restos e partes: fmod e modf

print(math.fmod(7, 3), 7 % 3)
print(math.fmod(-7, 3), -7 % 3)
print(math.modf(3.75))
print(math.modf(-3.75))

$ lua restos.lua
1	1
-1	2
3	0.75
-3	-0.75
  • math.fmod(a, b) é o resto da divisão, como o %, mas com o sinal de a: com −7, o fmod dá −1 e o % dá 2. Para números positivos, os dois são iguais; no dia a dia, use %.
  • math.modf(x) devolve dois valores: a parte inteira e a parte quebrada (veja Vários Retornos). De 3,75 sai 3 e 0,75. Ele corta na direção do zero: −3,75 dá −3 (o floor daria −4).

8. Por que 0.1 + 0.2 não é 0.3

print(0.1 + 0.2)
print(0.1 + 0.2 == 0.3)
print(math.abs((0.1 + 0.2) - 0.3) < 1e-9)

$ lua decimal.lua
0.30000000000000004
false
true

Não é defeito do Lua: o computador guarda os floats em binário, e 0,1 em binário é uma dízima sem fim (como 1/3 = 0,333… em decimal). Ele guarda uma aproximação muito boa, mas não exata, e o errinho aparece na 17ª casa. Python, JavaScript e quase todas as linguagens dão o mesmo resultado.

Por isso, não compare floats com ==. Compare a distância entre eles com um número bem pequeno: math.abs(a - b) < 1e-9 (1e-9 é 0,000000001). E, para mostrar, o string.format("%.2f", …) esconde o errinho.

Quando dá errado

Procurou o math.round 
$ lua -e 'print(math.round(2.5))'
lua: (command line):1: attempt to call a nil value (field 'round')
stack traceback:
	(command line):1: in main chunk
	[C]: in ?

"Tentar chamar um valor nil (o campo round)": a tabela math não tem nada com esse nome. O mesmo acontece com math.pow, que existiu no 5.1 e saiu. Como consertar: math.floor(x + 0.5) (seção 2), ou x ^ y no lugar do pow.

Escreveu Math com maiúscula 
$ lua -e 'print(Math.floor(2.5))'
lua: (command line):1: attempt to index a nil value (global 'Math')
stack traceback:
	(command line):1: in main chunk
	[C]: in ?

O Lua diferencia maiúsculas de minúsculas: Math é outro nome, uma variável global que não existe (nil), e pegar .floor de nil é "tentar indexar um valor nil". Como consertar: é tudo em minúsculas: math.floor.

Passou um texto que não é número

Missão: a pizzaria oferece pelo mesmo preço uma pizza grande de 35 cm ou duas médias de 25 cm. Complete a função area(diametro): o raio é metade do diâmetro, e a área é math.pi vezes o raio ao quadrado. O resto do programa já mostra o resultado com uma casa.

local function area(diametro)
  -- calcule e devolva a área do círculo
  return 0
end

print(string.format("Grande: %.1f cm²", area(35)))
print(string.format("Duas médias: %.1f cm²", 2 * area(25)))

local function area(diametro)
  local raio = diametro / 2
  return math.pi * raio ^ 2
end

print(string.format("Grande: %.1f cm²", area(35)))
print(string.format("Duas médias: %.1f cm²", 2 * area(25)))

No lab, as contas deram 962,11 cm² para a grande e 981,75 cm² para as duas médias: as duas médias têm um pouquinho mais de pizza.

Resumo

  • math é uma tabela de funções e valores que já vem carregada: math.nome(…).
  • math.floor arredonda para baixo, math.ceil para cima (os dois dão inteiro). Para o mais perto, math.floor(x + 0.5); para mostrar, string.format("%.2f", x). Não há math.round.
  • math.max e math.min recebem os números soltos (table.unpack para uma lista); math.abs tira o sinal.
  • math.sqrt é a raiz, ^ é a potência, math.pi é o π.
  • math.type diz se é inteiro ou float; math.tointeger converte; passar de math.maxinteger dá a volta sem aviso.
  • math.huge é o infinito; nan é "não é número" e é diferente até dele mesmo. Não compare floats com ==.
