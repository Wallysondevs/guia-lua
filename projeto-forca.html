Projeto Jogo da Forca

O jogo de papel e lápis, agora no terminal: o computador esconde uma palavra, você chuta uma letra por vez, e cada letra errada desenha mais uma parte do boneco. Seis erros e o boneco está completo: você perdeu. O projeto mexe com texto letra por letra, com uma tabela que lembra as letras já tentadas e, no fim, com um arquivo de palavras.

Você vai praticar
  • Pegar uma letra da palavra com sub e contar letras com #.
  • Usar uma tabela como dicionário para lembrar as letras tentadas, e uma lista para as erradas.
  • Juntar pedaços com table.concat.
  • Procurar uma letra com find (e entender o argumento true) e validar o chute com um padrão.
  • Separar o jogo em funções e escolher entre dois valores com o truque do and/or.
  • Sortear a palavra com math.random e lê-la de um arquivo com lines.

Cinco versões, uma novidade em cada:

  1. A palavra escondida (sub, tabela de letras, table.concat).
  2. Erros contados: dá para perder (find com true).
  3. Chute validado (o padrão ^%a$, letra repetida).
  4. Funções, desenho e palavra sorteada (local function, and/or, math.random).
  5. As palavras num arquivo (io.open, lines).

Antes de começar

Este projeto usa o io.read, o while true e o break da Calculadora e do Jogo de Adivinhação. Crie a pasta; o arquivo vai se chamar forca.lua:

$ mkdir -p projetos/forca
$ cd projetos/forca

Versão 1 · A palavra escondida

A primeira versão não tem erros nem boneco: a palavra é sempre banana, a Ana chuta letras até descobrir todas. O coração do jogo é a máscara: a palavra com _ no lugar das letras que ela ainda não tentou.

Para lembrar as letras tentadas, uma tabela usada como conjunto: a chave é a letra e o valor é true. Depois de chutar a e n, a tabela é { a = true, n = true }, e perguntar "já tentou o b?" é só olhar tentadas["b"] (dá nil, que vale como falso).

local palavra = "banana"
local tentadas = {}   -- as letras que a Ana já tentou: tentadas["a"] = true

print("=== Jogo da Forca ===")

while true do
  -- monta a máscara: a letra, se já foi tentada; "_", se não
  local partes = {}
  for i = 1, #palavra do
    local letra = palavra:sub(i, i)
    if tentadas[letra] then
      partes[#partes + 1] = letra
    else
      partes[#partes + 1] = "_"
    end
  end
  local mascara = table.concat(partes, " ")
  print("Palavra: " .. mascara)

  if not mascara:find("_") then
    print("Você venceu!")
    break
  end

  io.write("Uma letra: ")
  local chute = io.read():lower()
  tentadas[chute] = true
end

Por que o true no find: o ponto que acha tudo

Sem os dois últimos argumentos, o find trata o texto procurado como um padrão, e alguns caracteres têm significado especial. O ponto ., por exemplo, quer dizer "qualquer caractere":

$ lua
Lua 5.5.0  Copyright (C) 1994-2025 Lua.org, PUC-Rio
> ("banana"):find("n")
3       3
> ("banana"):find(".")
1       1
> ("banana"):find(".", 1, true)
nil
> ("banana"):find("")
1       0
> os.exit()

O find("n") achou o n na posição 3 (começa e termina na 3). Mas o find(".") "achou" um ponto na posição 1, onde está o b: como padrão, o ponto casa com qualquer letra. Se a Ana chutasse ., a versão 2 sem o true diria "Tem!". Com o terceiro argumento 1 (começar da posição 1) e o quarto true ("simples"), o find procura o ponto de verdade e devolve nil. E o texto vazio ("", a Ana só aperta Enter) é "achado" em qualquer palavra, com ou sem true: a versão 3 resolve recusando o chute vazio.

Palavras com acento: maçã não funciona

A Ana trocou "banana" por "maçã" na versão 2:

$ sed 's/"banana"/"maçã"/' forca.lua > acento.lua
$ lua acento.lua
=== Jogo da Forca ===
Palavra: _ _ _ _ _ _
Uma letra: m
Tem!
Palavra: m _ _ _ _ _
Uma letra: a
Tem!
Palavra: m a _ _ _ _
Uma letra: ç
Tem!
Palavra: m a _ _ _ _

Seis tracinhos para uma palavra de quatro letras, e o ç "tem" mas não aparece. O motivo: o Lua guarda o texto em bytes, e no UTF-8 (o jeito como o Ubuntu guarda o texto) o ç e o ã ocupam 2 bytes cada. O # conta bytes, e o sub(i, i) pega um byte, que sozinho não é letra nenhuma:

$ lua
Lua 5.5.0  Copyright (C) 1994-2025 Lua.org, PUC-Rio
> #"maçã", utf8.len("maçã")
6       4
> os.exit()

O find acha os 2 bytes do ç (por isso "Tem!"), mas a máscara compara byte a byte e nunca encontra um "ç" inteiro. E o padrão %a da versão 3 também não reconhece o ç como letra. Por isso as palavras do jogo são sem acento. Dá para fazer uma forca com acentos usando a biblioteca utf8 (for _, codigo in utf8.codes(palavra) percorre letra por letra); veja Acentos e a Biblioteca utf8.

Versão 4 · Funções, desenho e palavra sorteada

O laço principal está comprido e mistura tudo. A versão 4 separa as tarefas em funções, desenha a forca e sorteia a palavra de uma lista, para o jogo não ser sempre "banana".

-- Jogo da Forca da Ana, versão 4: funções, desenho e palavra sorteada

local PALAVRAS = { "banana", "abacaxi", "laranja", "morango", "goiaba", "melancia" }
local MAX_ERROS = 6

-- A palavra com "_" no lugar das letras que ainda não foram tentadas.
local function mascarar(palavra, tentadas)
  local partes = {}
  for i = 1, #palavra do
    local letra = palavra:sub(i, i)
    partes[#partes + 1] = tentadas[letra] and letra or "_"
  end
  return table.concat(partes, " ")
end

-- Desenha a forca com as partes do boneco que já "caíram".
local function desenhar(erros)
  local cabeca = erros >= 1 and "O" or " "
  local tronco = erros >= 2 and "|" or " "
  local braco1 = erros >= 3 and "/" or " "
  local braco2 = erros >= 4 and "\\" or " "
  local perna1 = erros >= 5 and "/" or " "
  local perna2 = erros >= 6 and "\\" or " "
  print("  +---+")
  print("  |   |")
  print("  " .. cabeca .. "   |")
  print(" " .. braco1 .. tronco .. braco2 .. "  |")
  print(" " .. perna1 .. " " .. perna2 .. "  |")
  print("      |")
  print("=======")
end

-- Pergunta até vir uma letra nova. Devolve a letra, ou nil se a entrada acabou.
local function ler_letra(tentadas)
  while true do
    io.write("Uma letra: ")
    local chute = io.read()
    if chute == nil then
      print()
      return nil
    end
    chute = chute:lower()
    if not chute:match("^%a$") then
      print("Digite uma letra só, de a a z.")
    elseif tentadas[chute] then
      print("Você já tentou a letra " .. chute .. ".")
    else
      return chute
    end
  end
end

Formas diferentes de montar a máscara

Três jeitos de transformar banana (com a e n tentadas) na máscara:

local palavra = "banana"
local tentadas = { a = true, n = true }

-- Forma 1: uma tabela de pedaços + table.concat
local partes = {}
for i = 1, #palavra do
  local letra = palavra:sub(i, i)
  partes[#partes + 1] = tentadas[letra] and letra or "_"
end
print("1: [" .. table.concat(partes, " ") .. "]")

-- Forma 2: juntando com .. dentro do laço
local mascara = ""
for i = 1, #palavra do
  local letra = palavra:sub(i, i)
  mascara = mascara .. (tentadas[letra] and letra or "_") .. " "
end
print("2: [" .. mascara .. "]")

-- Forma 3: gsub com uma função
local m3 = palavra:gsub(".", function (letra)
  return tentadas[letra] and letra or "_"
end)
print("3: [" .. m3 .. "]")

$ lua formas.lua
1: [_ a n a n a]
2: [_ a n a n a ]
3: [_anana]

Os colchetes no print mostram onde cada texto começa e termina. A forma 2 deixa um espaço sobrando no fim (o do último pedaço). A forma 3 usa o gsub com uma função: para cada caractere (o padrão .), o gsub chama a função e troca o caractere pelo que ela devolver; fica curta, mas sem os espaços. (O local m3 = … guarda só o primeiro dos dois valores do gsub.)

FormaQuando usar
Tabela + table.concatO jeito recomendado para montar um texto aos pedaços: o separador fica só entre os itens, e é rápido mesmo com milhares de pedaços.
.. no laçoPara poucos pedaços, é o mais fácil de entender. Com muitos, fica lento: cada .. cria um texto novo inteiro (veja table.concat).
gsub com funçãoQuando cada caractere vira outro, sem separador. Curto, mas exige conhecer padrões e funções como valores.

Ideias para continuar

  • Perguntar "Jogar de novo?" e contar vitórias e derrotas, como o recorde do Jogo de Adivinhação (o jogar já devolve true/false).
  • Aceitar o chute da palavra inteira: se o chute tiver mais de uma letra e for igual à palavra, vitória; se não, conta dois erros.
  • Guardar uma dica junto da palavra no arquivo (caju;fruta do Nordeste) e separar as duas partes com linha:match("^(.-);(.*)$").

Exercícios

1. Uma letra

Complete para pegar a letra da posição i:

local letra = palavra:(i, i)

2. Juntar com espaço

Complete para juntar a lista partes com um espaço entre os itens:

local mascara = table.(partes, " ")

3. Procurar como texto simples

Complete o quarto argumento do find:

if palavra:find(chute, 1, ) then

4. Bytes

Quanto dá #"maçã" no Lua?

5. Para que serve a tabela tentadas, com tentadas["a"] = true?

6. Por que chute:match("^%a$") recusa "ab"?

7. Qual a diferença entre ler as palavras com io.open + lines e com io.lines(nome) direto?

Resumo

  • A máscara é montada a cada volta: sub(i, i) pega cada letra, uma tabela-conjunto diz se ela já foi tentada, e table.concat junta os pedaços.
  • find(chute, 1, true) procura como texto simples; sem o true, o . casa com qualquer letra.
  • Valide antes de usar: nil (fim da entrada), match("^%a$") (uma letra só) e a letra repetida.
  • No Lua o texto é feito de bytes: palavras com acento precisam da biblioteca utf8.
  • Funções com nomes claros (mascarar, desenhar, ler_letra, jogar) e o truque cond and a or b deixam o jogo curto de ler.
  • io.open + lines + close lê um arquivo e deixa você tratar o arquivo que falta.
