Lua Funções Globais

Esta é a página de consulta rápida das funções globais do Lua 5.5: as funções que já vêm prontas e podem ser chamadas pelo nome, em qualquer programa, sem require. O manual oficial chama esse grupo de "biblioteca básica" (basic library). São 23 funções da biblioteca básica, mais o require (que vem da biblioteca de módulos), as variáveis _G e _VERSION, o arg e as tabelas das outras bibliotecas (string, table, math…). Cada linha traz um exemplo curto e o resultado que ele deu de verdade.

Como ler as tabelas
  • Exemplo é o que você digitaria depois do > do modo interativo (abra com lua no terminal).
  • Resultado é o que o Lua 5.5.0 respondeu no computador da Ana. O modo interativo mostra os textos sem aspas: tostring(42) aparece como 42, igual a um número. Use type() quando precisar saber a diferença.
  • Quando o exemplo devolve vários valores, o Lua os mostra na mesma linha, separados por TAB. Aqui eles aparecem separados por vírgula: 42, 7.5.
  • Quando o exemplo dá erro, o resultado mostra a primeira linha da mensagem (em inglês). No terminal, depois dela vem o stack traceback:, como no exemplo logo abaixo.
  • Resultados com 0x… (endereços na memória, como table: 0x55fe39d69d40) mudam a cada execução.

Assim fica no terminal da Ana:

$ lua
Lua 5.5.0  Copyright (C) 1994-2025 Lua.org, PUC-Rio
> tonumber("7,5")
nil
> select("#", "a", "b", "c")
3
> assert(tonumber("abc"), "não é número")
stdin:1: não é número
stack traceback:
        [C]: in global 'assert'
        stdin:1: in main chunk
        [C]: in ?
> os.exit()

O tonumber("7,5") devolveu nil porque o Lua só entende ponto como separador decimal. O select("#", …) contou os valores que vieram depois dele. E o assert parou com a mensagem que a Ana escolheu, porque o primeiro valor (nil) conta como falso. O stdin:1: do começo quer dizer "linha 1 do que foi digitado" (stdin = a entrada padrão, o teclado). Num arquivo, ali aparece o nome do arquivo: main.lua:1:.

Pule direto para o grupo que você procura:

  • Mostrar na tela: print
  • Tipos e conversão: type, tonumber, tostring
  • Percorrer tabelas e argumentos: pairs, ipairs, next, select
  • Acesso "cru" (sem metatabela): rawget, rawset, rawequal, rawlen
  • Metatabelas: setmetatable, getmetatable
  • Erros e avisos: error, assert, pcall, xpcall, warn
  • Carregar código e módulos: load, loadfile, dofile, require
  • Memória: collectgarbage
  • Variáveis globais prontas: _G, _VERSION, arg e as tabelas das bibliotecas
  • Todas de A a Z

O Lua 5.5 passou a escrever os floats "com dígitos suficientes para serem lidos de volta corretamente" (está na lista de mudanças do 5.5). No lab, print(1/3) deu 0.33333333333333331 no lua (5.5) e 0.33333333333333 no lua5.4; math.pi deu 3.1415926535897931 e 3.1415926535898. Para mostrar um número bonito, não dependa do print: use string.format("%.2f", x). Mais em Lua 5.1, LuaJIT, 5.4 e 5.5.

Cuidado com load de texto que veio de fora

load(io.read())() roda qualquer código que a pessoa digitar, inclusive os.remove("notas.txt"). Para transformar o que foi digitado em número, use tonumber. Se precisar mesmo rodar código de fora, passe uma tabela env só com o que ele pode usar, e o modo "t".

Veio de um Lua mais antigo?

Algumas globais do Lua 5.1 e do LuaJIT (Neovim, LÖVE) não existem no 5.5. No lab, unpack, loadstring, setfenv, getfenv, module, table.getn, math.pow deram todos nil no lua (5.5), e todos existem no luajit. Os substitutos: table.unpack no lugar de unpack; load no lugar de loadstring; _ENV no lugar de setfenv/getfenv; #t no lugar de table.getn(t); x ^ y no lugar de math.pow(x, y). No outro sentido, warn não existe no LuaJIT nem no 5.1 (só a partir do 5.4), e rawlen não existe no 5.1. Veja Lua 5.1, LuaJIT, 5.4 e 5.5.

Experimente

Missão: a Ana recebeu estes preços digitados num formulário. Alguns vieram errados ("abc", e "3,5" com vírgula). Do jeito que está, o programa para com erro. Troque local n = texto por local n = tonumber(texto): o que não é número vira nil e é contado como inválido. O resultado certo é soma: 33.5, inválidos: 2 (o "0x10" é hexadecimal: vale 16).

local entradas = {"10", "7.5", "abc", "0x10", "3,5"}
local soma, invalidos = 0, 0

for _, texto in ipairs(entradas) do
  local n = texto
  if n == nil then
    invalidos = invalidos + 1
  else
    soma = soma + n
  end
end

print(string.format("soma: %s, inválidos: %d", soma, invalidos))

local entradas = {"10", "7.5", "abc", "0x10", "3,5"}
local soma, invalidos = 0, 0

for _, texto in ipairs(entradas) do
  local n = tonumber(texto)
  if n == nil then
    invalidos = invalidos + 1
  else
    soma = soma + n
  end
end

print(string.format("soma: %s, inválidos: %d", soma, invalidos))

Resumo

  • O Lua 5.5 tem 24 funções globais: as 23 da biblioteca básica e o require. Estão sempre disponíveis, sem require.
  • Tipos: type (devolve o nome como texto), tonumber (dá nil se não for número; só aceita ponto), tostring.
  • Percorrer: ipairs para listas, pairs para tudo (sem ordem), next(t) == nil para "está vazia?", select("#", …) para contar argumentos.
  • Erros: error para parar, assert para conferir, pcall/xpcall para capturar sem parar o programa. warn só aparece depois de warn("@on").
  • Metatabelas: setmetatable/getmetatable; as raw… ignoram a metatabela.
  • Código: load (texto), loadfile (arquivo, sem rodar), dofile (arquivo, rodando), require (módulo, uma vez só).
  • 5.5 collectgarbage("param", …) é novo; os floats saem com mais dígitos (0.33333333333333331).
