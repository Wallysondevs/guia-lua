Onde o Lua É Usado

Você passou o guia inteiro aprendendo Lua no terminal e no editor. Mas a maior parte do Lua que existe no mundo não roda assim: ele roda dentro de outros programas. Um jogo, um editor de texto, um banco de dados ou um servidor de sites "carrega um Lua dentro de si" para que as pessoas possam escrever pedaços do comportamento dele. Esta aula mostra onde o Lua aparece, qual versão cada um usa (isso importa muito, como você vai ver) e como é esse "Lua por dentro" de um programa.

Você vai aprender
  • O que é uma linguagem embutida (de extensão), com um exemplo real: um programa em C que roda um script em Lua.
  • Onde o Lua é usado: jogos (Roblox, World of Warcraft, LÖVE, Defold), ferramentas (Neovim, Wireshark, Pandoc, Lightroom) e servidores (Redis, OpenResty/nginx).
  • Qual versão cada um usa: Lua 5.1, LuaJIT, Luau, 5.3, 5.4.
  • O que muda para você quando o lugar onde o seu código vai rodar não é o Lua 5.5.

Os programas desta aula rodaram na máquina da Ana (usuária ana, computador notebook), que tem o Lua 5.5 e também o lua5.4, o lua5.1 e o luajit. Os fatos sobre cada produto foram conferidos nas páginas oficiais deles em outubro de 2026 (os links estão em cada item); produtos mudam, então confira de novo antes de começar um projeto.

A ideia: o motor dentro do carro

Pense num motor de liquidificador. Sozinho, em cima da mesa, ele só gira. Ninguém compra "um motor"; compra um liquidificador, uma batedeira, um ventilador, que têm um motor dentro. O Lua foi pensado assim desde o começo: ele nasceu em 1993, no Tecgraf da PUC-Rio, no Rio de Janeiro (o nome quer dizer "Lua", o astro, em português), como uma linguagem para ser colocada dentro de outros programas. A página oficial (lua.org/about.html) diz que ele é "um motor de linguagem rápido e pequeno, que você embute facilmente na sua aplicação" e que é hoje "a principal linguagem de script em jogos".

Por que um programa quer um Lua dentro de si? Porque assim a parte "pesada" (o desenho 3D do jogo, a rede do servidor) fica escrita numa linguagem rápida como C ou C++, e a parte que muda o tempo todo (as regras da fase, a configuração do editor, um filtro de dados) fica em Lua, que qualquer pessoa consegue escrever e trocar sem recompilar nada.

1. Como é um Lua "por dentro" de um programa

Para ver isso de perto, a Ana escreveu um programa em C bem pequeno, a "loja", que cria um Lua, entrega a ele uma função própria (preco_do_dia) e roda um script com as regras da loja. Não precisa entender o C: olhe só os comentários.

#include <stdio.h>
#include <lua.h>
#include <lualib.h>
#include <lauxlib.h>

/* Uma função em C que o script em Lua vai poder chamar */
static int preco_do_dia(lua_State *L) {
  const char *produto = luaL_checkstring(L, 1);
  lua_pushnumber(L, produto[0] == 'p' ? 0.75 : 5.0);
  return 1;
}

int main(void) {
  lua_State *L = luaL_newstate();      /* cria um Lua novinho */
  luaL_openlibs(L);                    /* põe as bibliotecas (print, string...) */
  lua_pushcfunction(L, preco_do_dia);  /* entrega a função ao Lua */
  lua_setglobal(L, "preco_do_dia");
  if (luaL_dofile(L, "regras.lua") != LUA_OK) {
    printf("erro no script: %s\n", lua_tostring(L, -1));
  }
  lua_close(L);
  return 0;
}

local quantidade = 6
local total = quantidade * preco_do_dia("pao")
print(string.format("6 pães custam R$ %.2f", total))
print("Este script roda dentro de um programa em C, com o " .. _VERSION)

$ gcc loja.c -o loja -I/usr/include/lua5.5 -llua5.5
$ ./loja
6 pães custam R$ 4.50
Este script roda dentro de um programa em C, com o Lua 5.5
gcc loja.c -o loja …
Compila o programa em C e o liga à biblioteca do Lua 5.5 (o pacote liblua5.5-dev do Ubuntu; veja Instalar o Lua). Não há lua no comando que roda: quem roda o script é o ./loja.
luaL_newstate()
Cria um Lua inteiro, novinho, dentro do programa. Um jogo pode até criar vários.
lua_setglobal(L, "preco_do_dia")
O programa "dono" (o hospedeiro) decide o que o script enxerga. Aqui ele entregou uma função que não existe no Lua normal.
preco_do_dia("pao")
Do lado do Lua, ela é uma função como outra qualquer.
_VERSION
O script usa o Lua que o hospedeiro escolheu. Aqui, o 5.5. Num jogo, pode ser outro.

Todos os produtos desta aula funcionam com essa mesma ideia: o hospedeiro cria o Lua, escolhe a versão, escolhe quais bibliotecas o script recebe (muitos tiram o io e o os, por segurança) e entrega funções próprias (as "APIs" do produto: vim.* no Neovim, redis.call no Redis, love.* no LÖVE).

2. Jogos

Roblox: o Luau

O Roblox é uma plataforma onde as pessoas criam e jogam jogos; os criadores programam os jogos no Roblox Studio. A linguagem de lá é o Luau. Na documentação oficial (create.roblox.com/docs/luau), o Roblox diz que o Luau é "a linguagem de script que os criadores usam no Roblox Studio" e "uma linguagem de script embutível, rápida, pequena, segura e com tipagem gradual, derivada do Lua 5.1". O site do próprio Luau (luau.org) completa: ele tenta ser compatível com o Lua 5.1 sempre que possível, pegou algumas coisas das versões seguintes, mas não é um Lua 5.4 ou 5.5.

"Tipagem gradual" quer dizer que, no Luau, dá para escrever o tipo de uma variável (local nome: string = "Ana"), e o Studio avisa se você misturar as coisas. Isso não existe no Lua do guia: lá, essa linha é erro de sintaxe. Quase todo o resto que você aprendeu (tabelas, funções, if, for, metatabelas) vale no Luau.

World of Warcraft: Lua 5.1

Os addons do World of Warcraft (complementos que mudam a tela e o comportamento do jogo) são escritos em Lua. A Blizzard não mantém uma página técnica pública sobre a linguagem; segundo a wiki da comunidade (warcraft.wiki.gg/wiki/Lua), o jogo usa um subconjunto do Lua 5.1 desde 2006 (antes era o 5.0). Fóruns de criadores de addons contam que bibliotecas como io e os não existem lá (o addon não pode mexer nos arquivos do computador), o que faz sentido pelo que você viu na seção 1. Trate esses detalhes como informação da comunidade, não da Blizzard.

LÖVE: LuaJIT

O LÖVE é um programa gratuito para fazer jogos 2D em Lua, para Windows, macOS, Linux, Android e iOS. No código-fonte oficial (github.com/love2d/love), ele lista a dependência "Lua / LuaJIT / LLVM-lua" e, na compilação, liga o LuaJIT por padrão (no macOS, o padrão é o Lua 5.1 comum). Na prática: escreva para o Lua 5.1. Um jogo do LÖVE é uma pasta com um main.lua que define funções como love.draw, que o LÖVE chama a cada quadro da tela.

Defold: LuaJIT

O Defold é um motor de jogos gratuito. O manual oficial (defold.com/manuals/lua) diz que ele usa o LuaJIT, "totalmente compatível com o Lua 5.1", que na versão para navegador (HTML5) ele usa o Lua 5.1.4 no lugar do LuaJIT, e recomenda com todas as letras: para o jogo funcionar em todas as plataformas, use só recursos do Lua 5.1.

3. Ferramentas

Neovim: Lua 5.1 (com LuaJIT)

O Neovim é um editor de texto muito usado por programadores, e a configuração dele (o arquivo init.lua) e boa parte dos plugins são escritos em Lua. A documentação oficial (neovim.io/doc/user/lua) é bem direta: "Lua 5.1 é a interface permanente do Lua no Nvim. Os plugins devem usar o Lua 5.1; versões posteriores (que são, essencialmente, dialetos diferentes e incompatíveis) não são suportadas". Ela pede que o Neovim seja compilado com o LuaJIT, por desempenho, mas avisa que os extras do LuaJIT não estão garantidos, e mostra como o código deve conferir:

if jit then
  print("LuaJIT: " .. jit.version)
else
  print("Lua comum: " .. _VERSION)
end

$ lua qual.lua
Lua comum: Lua 5.5
$ luajit qual.lua
LuaJIT: LuaJIT 2.1.1761786044
$ lua5.1 qual.lua
Lua comum: Lua 5.1

A variável global jit só existe no LuaJIT. No Lua comum ela é nil, e o if vai para o else (veja O Valor nil).

Missão: este programa só mostra a versão. Faça como o Neovim recomenda: se existir a variável jit, mostre "LuaJIT: " com o jit.version; senão, mostre "Lua comum: " com o _VERSION. (O editor do guia roda o Lua 5.5, então deve aparecer Lua comum: Lua 5.5.)

print(_VERSION)

if jit then
  print("LuaJIT: " .. jit.version)
else
  print("Lua comum: " .. _VERSION)
end

Wireshark: Lua 5.3 e 5.4 (antes, 5.1 e 5.2)

O Wireshark é um programa que mostra, pacote por pacote, o que passa pela rede. Em Lua dá para escrever dissectors (que ensinam o Wireshark a entender um protocolo novo) e outras extensões. O guia oficial de desenvolvimento (wireshark.org, capítulo "Lua Support in Wireshark") diz: as versões 4.2.x e anteriores usam o Lua 5.1 e 5.2; as mais novas usam o Lua 5.3 e 5.4. É um dos poucos grandes produtos que acompanharam as versões novas do Lua. E um dissector lê bytes: o assunto de Dados Binários (string.pack).

Pandoc: Lua 5.4

O Pandoc converte documentos de um formato para outro (Markdown para Word, HTML para PDF…). Com os "filtros Lua", você muda o documento no meio da conversão (trocar todas as imagens, numerar as tabelas). A documentação oficial (pandoc.org/lua-filters.html) diz que o Pandoc vem com um interpretador Lua 5.4 embutido.

Adobe Lightroom Classic: Lua (versão não divulgada)

O Lightroom é um programa de fotógrafos para organizar e revelar fotos. Os plug-ins dele são escritos em Lua: a página oficial para desenvolvedores (developer.adobe.com/lightroom-classic) diz "crie plug-ins em Lua, a linguagem de script embutida no Lightroom" e que a Adobe "estende o Lua com uma infraestrutura orientada a objetos própria". A própria página "sobre" do Lua cita o Lightroom como exemplo de uso industrial. Qual versão do Lua ele usa, a página oficial não diz; não deu para conferir, então esta aula não afirma.

4. Servidores

Redis: Lua 5.1

O Redis é um banco de dados muito rápido, que guarda tudo na memória. Em Lua, dá para mandar um pequeno programa para rodar dentro do Redis (com o comando EVAL), que faz várias operações de uma vez. A documentação oficial (redis.io, "Redis Lua API reference") diz que o Redis "inclui um interpretador Lua 5.1 embutido", que roda os scripts num ambiente fechado (sem require, com só algumas bibliotecas: string, table, math, um os só com o os.clock, e algumas extras como cjson) e, o mais curioso para quem fez este guia, proíbe variáveis globais: um script com my_global_variable = 'some value' é recusado com o erro Script attempted to create global variable 'my_global_variable'. A própria documentação manda declarar tudo com local. É o "local sempre" de Estilo de Código, virando regra obrigatória.

OpenResty (nginx): LuaJIT

O nginx é um dos servidores de sites mais usados do mundo. O OpenResty (openresty.org) se descreve como "uma plataforma web de código aberto que junta um núcleo nginx melhorado com o LuaJIT" (uma versão do LuaJIT mantida pelo próprio projeto). Com ele, cada pedido que chega ao site pode passar por código Lua: conferir uma senha, decidir para qual servidor mandar, montar a resposta. O LuaJIT que está na máquina da Ana, aliás, é justamente o do OpenResty (o pacote do Ubuntu é o 2.1.0+openresty).

O que muda para você

Um programa que só usa o "miolo" comum da linguagem roda em todas as versões. Este aqui rodou igual nas quatro que a Ana tem:

local nomes = { "Ana", "Bia", "Caio" }
local total = 0
for i, nome in ipairs(nomes) do
  total = total + #nome
end
print(_VERSION, "letras:", total)

$ lua portatil.lua
Lua 5.5	letras:	10
$ lua5.4 portatil.lua
Lua 5.4	letras:	10
$ lua5.1 portatil.lua
Lua 5.1	letras:	10
$ luajit portatil.lua
Lua 5.1	letras:	10

(Repare que o LuaJIT responde Lua 5.1 no _VERSION: ele é compatível com o 5.1.) O que não é igual, e que você vai sentir ao levar código do guia para o Neovim, o Roblox ou o Redis:

Quando dá errado

Uma global num lugar que proíbe globais

Não dá para rodar o Redis de verdade nesta aula, mas dá para imitar a trava dele em Lua puro, com uma metatabela no _G (veja __newindex). A mensagem foi copiada da documentação do Redis; o resto é uma imitação simples:

-- Uma imitação simples da trava do Redis (não é o Redis de verdade)
setmetatable(_G, { __newindex = function (_, nome)
  error("Script attempted to create global variable '" .. nome .. "'", 2)
end })

-- O script de quem usa:
contador = 0
for i = 1, 3 do
  contador = contador + 1
end
print("Total: " .. contador)

$ lua trava.lua
lua: trava.lua:7: Script attempted to create global variable 'contador'
stack traceback:
	[C]: in global 'error'
	trava.lua:3: in metamethod 'newindex'
	trava.lua:7: in main chunk
	[C]: in ?

"O script tentou criar a variável global contador". O rastro mostra o caminho: a linha 7 tentou criar a global, isso acionou o metamétodo newindex da linha 3, que chamou o error. Como consertar: local contador = 0. É a missão final.

Código do guia num lugar que usa o 5.1

Levar um 7 // 2 para o LuaJIT (o do Neovim, do LÖVE, do OpenResty) dá erro de sintaxe:

$ luajit -e 'print(7 // 2)'
luajit: (command line):1: unexpected symbol near '/'

Não é defeito do seu código: é outra versão da linguagem. Antes de escrever para um produto, descubra a versão dele (a tabela da seção 5) e confira em versoes.html o que muda. Para dividir sem a parte decimal no 5.1, use math.floor(7 / 2).

Tipos do Luau no Lua comum

Uma linha do Luau como local nome: string = "Ana" não funciona no Lua 5.5 (nem no 5.1): os dois-pontos depois do nome não fazem parte da linguagem:

$ lua -e 'local nome: string = "Ana"'
lua: (command line):1: unexpected symbol near ':'

O contrário quase sempre funciona: código Lua 5.1 comum, sem tipos, roda no Luau, porque lá os tipos são opcionais e o Luau tenta ser compatível com o 5.1 sempre que possível.

Missão final: um script que o "Redis" aceita

Missão: a imitação da trava do Redis recusa o script porque ele cria uma variável global. Sem mexer na trava (as 4 primeiras linhas), conserte o script para ele rodar e mostrar Total: 3.

-- Uma imitação simples da trava do Redis (não é o Redis de verdade)
setmetatable(_G, { __newindex = function (_, nome)
  error("Script attempted to create global variable '" .. nome .. "'", 2)
end })

-- O script de quem usa:
contador = 0
for i = 1, 3 do
  contador = contador + 1
end
print("Total: " .. contador)

-- Uma imitação simples da trava do Redis (não é o Redis de verdade)
setmetatable(_G, { __newindex = function (_, nome)
  error("Script attempted to create global variable '" .. nome .. "'", 2)
end })

-- O script de quem usa:
local contador = 0
for i = 1, 3 do
  contador = contador + 1
end
print("Total: " .. contador)

Com local, a variável não passa pelo _G, a trava nem fica sabendo, e o script mostra Total: 3.

Resumo

  • O Lua nasceu em 1993 na PUC-Rio para ser embutido em outros programas: o hospedeiro cria o Lua, escolhe a versão, as bibliotecas e entrega funções próprias.
  • Jogos: Roblox (Luau, derivado do 5.1), World of Warcraft (5.1), LÖVE e Defold (LuaJIT).
  • Ferramentas: Neovim (5.1/LuaJIT), Wireshark (5.3/5.4 nas versões novas), Pandoc (5.4), Lightroom (versão não divulgada).
  • Servidores: Redis (5.1, sem globais) e OpenResty/nginx (LuaJIT).
  • Quase ninguém usa o 5.5 ainda. O miolo da linguagem é igual em todas; o que muda (inteiros, //, bits, goto, <const>, global…) está em versoes.html.
