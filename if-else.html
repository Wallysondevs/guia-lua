Lua if e else

Na aula if … then, o programa fazia uma coisa quando a condição era verdadeira e, quando era falsa, simplesmente não fazia nada. Muitas vezes, porém, você quer fazer outra coisa no caso falso: "Pode votar" ou "Ainda não pode votar"; "Compra aprovada" ou "Saldo insuficiente". Para isso o if ganha um segundo bloco, o else, que em inglês quer dizer "senão".

Você vai aprender
  • Como escrever if … then … else … end e o que cada parte faz.
  • Que, com else, sempre roda exatamente um dos dois blocos: nunca os dois, nunca nenhum.
  • Exemplos do dia a dia: par ou ímpar, quantas sacolas, o número digitado que não é número.
  • Uma armadilha importante: a variável local criada dentro do bloco some depois do end.
  • A diferença entre um if/else e dois ifs separados.
  • Os erros reais: else then, o end antes do else, o else com condição e o else repetido.

Todos os programas desta aula rodaram no Lua 5.5 da máquina da Ana (usuária ana, computador notebook), com lua arquivo.lua. Você pode rodar cada um no editor do guia.

A ideia: uma bifurcação na estrada

A Ana combinou com a amiga: "Se fizer sol no sábado, então a gente vai à praia; senão, a gente vai ao cinema." Agora a frase tem dois caminhos, como uma estrada que se divide em duas:

  1. Primeiro vem a pergunta: vai fazer sol?
  2. Se a resposta for sim, elas pegam o caminho da praia.
  3. Se for não, pegam o caminho do cinema.
  4. Os dois caminhos se juntam de novo depois: no domingo, a vida segue igual.

Repare que não existe a opção "não sair" nem a opção "ir aos dois": é um caminho ou o outro, sempre um. O else do Lua funciona assim.

local sol = false
if sol then
  print("Praia!")
else
  print("Cinema!")
end

Leia: "se sol, então praia, senão cinema, fim". Com sol = false, o programa mostra Cinema!.

1. O primeiro else: pode votar ou não?

O programa da aula anterior, agora com uma resposta para o caso falso:

local idade = 15
if idade >= 18 then
  print("A Ana pode votar.")
else
  print("A Ana ainda não pode votar.")
end
print("Fim do programa.")
if idade >= 18 then
Igual ao da aula anterior: a condição e o then.
print("A Ana pode votar.")
O primeiro bloco: roda se a condição for verdadeira.
else
"Senão". Separa os dois blocos. Ele vem sozinho na linha: sem condição e sem then (o "senão" já quer dizer "em todos os outros casos").
print("A Ana ainda não pode votar.")
O segundo bloco: roda se a condição for falsa.
end
Um end só, no fim de tudo, fecha o if inteiro (os dois blocos). Não há um end antes do else.
print("Fim do programa.")
Fora do if: roda sempre, depois de um dos dois blocos.
$ lua votar2.lua
A Ana ainda não pode votar.
Fim do programa.

Com idade = 15, a condição deu false: o Lua pulou o primeiro bloco e rodou o do else. Troque para idade = 20:

Com if … else … end, é impossível os dois blocos rodarem, e é impossível nenhum rodar. Ou a condição é verdadeira (bloco de cima), ou é falsa (bloco do else). É isso que torna o else tão útil: você tem a garantia de que o programa sempre responde alguma coisa.

2. Par ou ímpar

Um número é par quando a divisão por 2 não deixa resto. O operador % dá o resto da divisão (veja Divisão: /, // e %): 7 % 2 é 1, 8 % 2 é 0.

local numero = 7
if numero % 2 == 0 then
  print(numero .. " é par")
else
  print(numero .. " é ímpar")
end

$ lua par.lua
7 é ímpar

A condição numero % 2 == 0 lê-se "o resto de numero dividido por 2 é igual a 0?". Para o 7, o resto é 1, a condição é falsa, e roda o else. Não precisa testar "é ímpar?" no else: se não é par, só pode ser ímpar.

Missão: este programa só sabe dizer quando o número é par; com o 7, ele não mostra nada. Acrescente um else para ele mostrar 7 é ímpar. Depois teste com outros números (8, 0, -3).

local numero = 7
if numero % 2 == 0 then
  print(numero .. " é par")
end

local numero = 7
if numero % 2 == 0 then
  print(numero .. " é par")
else
  print(numero .. " é ímpar")
end

3. Escolhendo um valor: quantas sacolas?

O if/else não serve só para mostrar mensagens. Muitas vezes ele serve para dar um valor a uma variável. No caixa da padaria, até 10 itens cabem numa sacola; mais que isso, vão duas:

local itens = 12
local sacolas
if itens <= 10 then
  sacolas = 1
else
  sacolas = 2
end
print("Itens: " .. itens .. ", sacolas: " .. sacolas)

$ lua sacola.lua
Itens: 12, sacolas: 2
local sacolas
A variável é criada antes do if, ainda sem valor (vale nil). Isso é importante, e a próxima seção mostra por quê.
sacolas = 1 / sacolas = 2
Cada bloco dá um valor à mesma variável, sem local (ela já existe). Como sempre roda um dos dois, depois do end a variável com certeza tem valor.

Cuidado: local dentro do bloco some no end

Uma tentação comum é criar a variável dentro de cada bloco:

local nota = 8
if nota >= 6 then
  local situacao = "aprovada"
else
  local situacao = "reprovada"
end
print("Situação:", situacao)

$ lua localdentro.lua
Situação:	nil

O programa não deu erro, mas mostrou nil no lugar de aprovada. O motivo: uma variável local só existe dentro do bloco onde foi criada, até o end (ou o else) que fecha esse bloco. O situacao de dentro do if nasceu e morreu ali. O situacao do print, lá embaixo, é outro nome, que nunca recebeu valor: por isso nil. (Esse assunto, o escopo, tem aula própria: Escopo e Blocos.)

Missão: conserte o programa para ele mostrar Situação: aprovada. Dica: crie a variável antes do if (local situacao) e, dentro dos blocos, só dê o valor, sem local.

local nota = 8
if nota >= 6 then
  local situacao = "aprovada"
else
  local situacao = "reprovada"
end
print("Situação:", situacao)

local nota = 8
local situacao
if nota >= 6 then
  situacao = "aprovada"
else
  situacao = "reprovada"
end
print("Situação:", situacao)

4. Conferindo o que a pessoa digitou

O io.read() sempre devolve texto (veja io.read()). O tonumber tenta transformar esse texto em número; quando não consegue, ele devolve nil (veja Conversão). Juntando com o else, o programa sabe responder nos dois casos:

io.write("Quantos pães você quer? ")
local resposta = io.read()
local quantidade = tonumber(resposta)
if quantidade then
  print("Saindo " .. quantidade .. " pães!")
else
  print("Isso não é um número: " .. resposta)
end
tonumber(resposta)
Para o texto "6", devolve o número 6. Para "seis", devolve nil.
if quantidade then
"Se deu para converter" (lembre: nil é falso, qualquer número é verdadeiro, até o 0).
else
Todos os outros casos: o texto não era um número.

A Ana rodou duas vezes; na primeira digitou 6, na segunda, seis:

$ lua numero.lua
Quantos pães você quer? 6
Saindo 6 pães!
$ lua numero.lua
Quantos pães você quer? seis
Isso não é um número: seis

Experimente: rode e digite uma quantidade no terminal da caixa. Rode de novo e digite uma palavra, ou 2.5, ou 0x10. Qual bloco roda em cada caso? (No lab, 2.5 deu Saindo 2.5 pães! e 0x10 deu Saindo 16 pães!: o tonumber entende números escritos em hexadecimal.)

io.write("Quantos pães você quer? ")
local resposta = io.read()
local quantidade = tonumber(resposta)
if quantidade then
  print("Saindo " .. quantidade .. " pães!")
else
  print("Isso não é um número: " .. resposta)
end

5. if/else numa linha só

Como no if simples, um if/else curto cabe numa linha:

$ lua -e 'local n = 4 if n % 2 == 0 then print("par") else print("ímpar") end'
par

Dá para ler, mas já fica apertado. Com else, prefira quase sempre a forma em várias linhas.

Formas diferentes de fazer a mesma coisa

Dá para trocar o else por um segundo if, com a condição oposta:

local saldo = 50
local preco = 80
if saldo >= preco then
  print("Compra aprovada.")
end
if saldo < preco then
  print("Saldo insuficiente.")
end

$ lua doisifs.lua
Saldo insuficiente.

Funciona, mas tem dois problemas. Primeiro, a pergunta é feita duas vezes. Segundo, e mais grave: você tem de acertar a condição oposta na mão. Se alguém escrever saldo <= preco no segundo, com saldo igual a preco os dois blocos rodam: "Compra aprovada." e "Saldo insuficiente." ao mesmo tempo. A Ana testou esse engano com saldo e preço iguais a 80:

$ lua -e 'local saldo, preco = 80, 80 if saldo >= preco then print("Compra aprovada.") end if saldo <= preco then print("Saldo insuficiente.") end'
Compra aprovada.
Saldo insuficiente.

Com else, esse engano é impossível:

local saldo = 50
local preco = 80
if saldo >= preco then
  print("Compra aprovada.")
else
  print("Saldo insuficiente.")
end

Quando o if/else só escolhe um valor entre dois, existe ainda uma terceira forma, curta, com and e or: local sacolas = itens <= 10 and 1 or 2. Ela tem uma armadilha, explicada na aula O Truque do and/or.

Quando dá errado

Escreveu else then 
local idade = 15
if idade >= 18 then
  print("Pode votar.")
else then
  print("Ainda não pode votar.")
end

$ lua elsethen.lua
lua: elsethen.lua:4: unexpected symbol near 'then'

"Símbolo inesperado perto de then", na linha 4. O then só vem depois de uma condição, e o else não tem condição. Depois do else, o Lua esperava a primeira linha do bloco, e um then ali não faz sentido. Como consertar: o else fica sozinho: apague o then.

Pôs um end antes do else 
local idade = 15
if idade >= 18 then
  print("Pode votar.")
end
else
  print("Ainda não pode votar.")
end

$ lua endantes.lua
lua: endantes.lua:5: <eof> expected near 'else'

O end da linha 4 fechou o if. Quando o Lua chega ao else da linha 5, não há mais if aberto para ele pertencer. A mensagem "era esperado o fim do arquivo perto de else" quer dizer: "o programa já estava completo, e este else está sobrando". Como consertar: apague o end da linha 4. Lembre: um end por if, no fim de tudo.

Pôs uma condição no else 
local idade = 15
if idade >= 18 then
  print("Pode votar.")
else idade < 18
  print("Ainda não pode votar.")
end

$ lua elsecond.lua
lua: elsecond.lua:4: syntax error near '<'

"Erro de sintaxe perto de <". Para o Lua, o bloco do else começa logo depois da palavra else: ele leu idade como o começo de um comando, e um comando não pode ser idade < 18 (é uma pergunta solta, que não faz nada). Como consertar: o else não leva condição; apague o idade < 18. Se você precisa mesmo de uma segunda condição, a palavra é outra: elseif (aula elseif).

Dois else no mesmo if 
local idade = 15
if idade >= 18 then
  print("Pode votar.")
else
  print("Ainda não pode votar.")
else
  print("???")
end

$ lua doiselse.lua
lua: doiselse.lua:6: 'end' expected (to close 'if' at line 2) near 'else'

"Era esperado um end (para fechar o if da linha 2) perto de else". Depois do primeiro else, a única coisa que pode fechar o if é o end. Faz sentido: o else já é "todos os outros casos", não sobra caso para um segundo. Como consertar: um if tem no máximo um else, sempre o último.

Esqueceu o end do fim 
local idade = 15
if idade >= 18 then
  print("Pode votar.")
else
  print("Ainda não pode votar.")
print("Fim do programa.")

$ lua semendelse.lua
lua: semendelse.lua:7: 'end' expected (to close 'if' at line 2) near <eof>

A mesma mensagem da aula anterior: o if da linha 2 ficou aberto até o fim do arquivo. Repare que o else não fecha nada: ele só separa os blocos. O end vai depois do último bloco, antes de print("Fim do programa.").

Missão: o caixa da lojinha da Ana usa dois ifs com condições opostas. Troque por um único if/else e, no caso do saldo insuficiente, mostre quanto falta: Saldo insuficiente: faltam R$ 30 (a diferença entre o preço e o saldo).

  print("Compra aprovada.")

end

if saldo >= preco then
  print("Compra aprovada.")

Os parênteses em (preco - saldo) deixam claro que a conta é feita primeiro e o resultado é juntado ao texto. Teste depois com saldo = 80: tem de aparecer só Compra aprovada.

Resumo

  • if cond then … else … end: se a condição for verdadeira, roda o primeiro bloco; senão, o do else. Sempre exatamente um dos dois.
  • O else fica sozinho: sem condição, sem then. Um end só, no fim, fecha tudo.
  • Para usar depois do if um valor escolhido dentro dele, crie a variável antes (local x) e só dê o valor nos blocos. Uma local criada dentro do bloco some no end.
  • Prefira if/else a dois ifs com condições opostas: a pergunta é feita uma vez e não há como os dois rodarem.
  • Para três ou mais caminhos, a próxima aula: elseif.
