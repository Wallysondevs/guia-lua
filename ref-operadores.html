Lua Operadores

Esta é a página de consulta rápida de todos os operadores do Lua 5.5: os símbolos e palavras que fazem contas (+, *), comparam (==, <), combinam condições (and, or), juntam textos (..), medem tamanho (#) e mexem em bits (&, <<). No fim está a tabela de precedência: a ordem em que o Lua faz as operações quando há várias na mesma expressão.

Como ler as tabelas
  • Exemplo é o que você digitaria depois do > do modo interativo.
  • Resultado é o que o Lua 5.5.0 respondeu no computador da Ana. Vários valores aparecem separados por vírgula; no terminal, o Lua separa com TAB.
  • Preste atenção no .0: 3 é inteiro, 3.0 é float. Veja Números (inteiro e float).

Assim fica no terminal da Ana:

$ lua
Lua 5.5.0  Copyright (C) 1994-2025 Lua.org, PUC-Rio
> 7 / 2, 7 // 2, 7 % 2
3.5	3	1
> 2 + 3 * 4
14
> "Ana" .. " " .. "Lima"
Ana Lima
> 1 ~= 2
true
> x += 1
stdin:1: syntax error near '+'
> os.exit()

O 2 + 3 * 4 deu 14, não 20: a multiplicação vem antes da soma. "Diferente" no Lua é ~= (não !=). E o x += 1 de outras linguagens não existe: o Lua respondeu syntax error near '+' ("erro de sintaxe perto do +"). Escreva x = x + 1.

Pule direto para o grupo que você procura:

  • Aritméticos: + - * / // % ^
  • Comparação: == ~= < > <= >=
  • Lógicos: and or not
  • Texto e tamanho: .. #
  • Bits: & | ~ << >>
  • A tabela de precedência
  • Operadores que não existem no Lua

Lógicos

Para o Lua, só false e nil são "falsos"; todo o resto é verdadeiro, inclusive 0 e o texto vazio "". O and e o or não devolvem só true/false: devolvem um dos dois valores, e só calculam o segundo se precisarem.

Escreva 1 .. 2 com espaços

Grudado num número, o ponto pode ser lido como a vírgula decimal: 1..2 deu stdin:1: malformed number near '1..2' ("número malformado"). Com espaços (1 .. 2) dá 12. Entre textos e variáveis, os espaços são só uma questão de leitura, mas o costume é sempre usá-los.

A tabela de precedência

Quando uma expressão tem vários operadores, o Lua faz primeiro os de maior precedência. Esta é a tabela do manual do Lua 5.5 (§3.4.8), da maior para a menor (o manual escreve da menor para a maior). Operadores na mesma linha têm a mesma precedência e são feitos da esquerda para a direita, menos .. e ^, que vão da direita para a esquerda.

Na dúvida, use parênteses

Ninguém decora a tabela inteira. Os parênteses deixam a intenção clara para quem lê e para o Lua: (a + b) / 2, not (x == y), (n & 1) == 0. A explicação com mais exemplos está em Precedência dos Operadores.

Experimente

Missão: a Ana tirou 7, 8 e 9, mas o programa diz que a média é 18.0. O problema é a precedência: a divisão acontece antes da soma, então só o n3 está sendo dividido por 3. Use parênteses para que a soma aconteça primeiro. O resultado certo é Média: 8.0.

local n1, n2, n3 = 7, 8, 9

local media = n1 + n2 + n3 / 3
print("Média: " .. media)

local n1, n2, n3 = 7, 8, 9

local media = (n1 + n2 + n3) / 3
print("Média: " .. media)

Livre: teste os operadores e a precedência. Antes de rodar, tente adivinhar cada resultado.

print(7 / 2, 7 // 2, 7 % 2, 7 ^ 2)
print(2 + 3 * 4, (2 + 3) * 4, 2 ^ 3 ^ 2)
print(1 == 1.0, "1" == 1, "10" + 5)
print(nil or "padrão", 0 and "verdadeiro")
print("Ana" .. " " .. 30, #"Ana")
print(5 & 3, 5 | 3, 1 << 4)

Resumo

  • Aritméticos: + - * / // % ^. O / e o ^ sempre dão float; // arredonda para baixo; % é o resto.
  • Comparação: == ~= < > <= >=. Diferente é ~=. Tipos diferentes nunca são iguais; número e texto não se comparam com <.
  • Lógicos: and or not; só nil e false são falsos. x or padrao dá um valor padrão.
  • .. junta textos; # dá o tamanho (texto em bytes).
  • Bits: & | ~ << >> e ~x, só com inteiros.
  • Precedência, da maior para a menor: ^; not # - ~; * / // %; + -; ..; << >>; &; ~; |; comparações; and; or. Na dúvida, parênteses.
