Lua .. (concatenação)

Quase todo programa precisa montar um texto a partir de pedaços: "Olá, " + o nome da pessoa + "!", ou "Total: R$ " + o valor da compra. Juntar textos, um atrás do outro, tem um nome técnico: concatenação (do latim catena, "corrente": os pedaços viram elos de uma corrente). No Lua, quem faz isso são dois pontos seguidos: ...

Você vai aprender
  • Como juntar dois ou mais textos com .., e por que o espaço entre as palavras é responsabilidade sua.
  • Como juntar texto com número ("Total: " .. 30), e por que 1..2, tudo colado, é erro.
  • Que o .. cria um texto novo: a variável original não muda, a não ser que você guarde o resultado nela.
  • A diferença entre .. (juntar) e + (somar).
  • Os erros reais: concatenar nil, true/false e tabelas, e como consertar cada um.
  • Outras formas de montar texto: as vírgulas do print, o io.write, o string.format e o table.concat.

Todos os programas desta aula rodaram no Lua 5.5 da máquina da Ana (usuária ana, computador notebook), salvos na pasta pessoal dela e executados com lua arquivo.lua (veja Rodando um Programa). Você pode rodar cada um no editor do guia.

A ideia: montar um bilhete com etiquetas

Imagine que a Ana tem uma cartela de etiquetas adesivas, cada uma com um pedaço de texto: Olá, numa, Ana em outra, ! numa terceira. Para montar o bilhete, ela cola as etiquetas uma ao lado da outra, na ordem, sem nada no meio:

  1. Olá, (repare: essa etiqueta já termina com um espaço)
  2. Olá, + Ana → Olá, Ana
  3. Olá, Ana + ! → Olá, Ana!

Duas regras do bilhete valem para o .. do Lua:

  • As etiquetas são coladas encostadas. Se você quer um espaço entre duas palavras, o espaço tem de estar dentro de uma das etiquetas (ou ser uma etiqueta só com o espaço, " ").
  • As etiquetas originais continuam na cartela: o que você ganha é um bilhete novo. Daqui a pouco você vai ver que, no Lua, o texto "Ana" não muda quando é colado em outro.

1. O primeiro ..

local nome = "Ana"
print("Olá, " .. nome .. "!")
local nome = "Ana"
Uma variável com um texto (veja Variáveis e local × Global). Texto, em programação, se chama string ("cordão", em inglês): uma sequência de caracteres entre aspas. A aula Strings conta tudo sobre eles.
"Olá, "
O primeiro pedaço: um texto escrito direto no código, com um espaço no fim, antes da aspa.
..
O operador de concatenação: dois pontos seguidos, sem nada entre eles. Ele pega o que está à esquerda e o que está à direita e devolve um texto só, com os dois encostados.
nome
O segundo pedaço: o valor da variável (Ana), não a palavra "nome". Sem aspas, o Lua entende que é uma variável.
.. "!"
Mais um .., mais um pedaço. Dá para encadear quantos você quiser: o Lua junta todos, da esquerda para a direita, num texto só.
print(…)
Mostra o texto pronto (veja print()). O print recebe um valor só: o bilhete já montado.
$ lua ola.lua
Olá, Ana!

No modo interativo

O > do Lua (veja O Modo Interativo) é um ótimo lugar para brincar com o ..: digite a expressão e ele mostra o resultado na hora, sem precisar de print.

$ lua
Lua 5.5.0  Copyright (C) 1994-2025 Lua.org, PUC-Rio
> "Ana" .. " " .. "Lima"
Ana Lima
> nome = "Ana"
> "Olá, " .. nome .. "!"
Olá, Ana!
> os.exit()

Na primeira linha, o pedaço do meio é " ": um texto que tem só um espaço dentro. É a "etiqueta do espaço".

2. O espaço é por sua conta

O .. não adivinha nada: ele cola os pedaços exatamente como estão. Compare as duas linhas:

local nome = "Ana"
local sobrenome = "Lima"
print(nome .. sobrenome)
print(nome .. " " .. sobrenome)
local completo = nome .. " " .. sobrenome
print("Nome completo: " .. completo)
print(#completo)

$ lua nome_completo.lua
AnaLima
Ana Lima
Nome completo: Ana Lima
8
  • nome .. sobrenome deu AnaLima, tudo grudado. Nenhum dos dois textos tinha espaço.
  • nome .. " " .. sobrenome deu Ana Lima: o espaço entrou como um pedaço próprio.
  • local completo = … guardou o resultado numa variável nova. Um texto montado com .. é um texto como outro qualquer: pode ser guardado, mostrado, juntado de novo.
  • #completo mostra o tamanho do texto: 8 (3 letras de "Ana", 1 espaço, 4 de "Lima"). O # tem aula própria: O Operador de Tamanho (#).
Os espaços em volta do .. não contam

Os espaços que você põe fora das aspas, em volta do operador (nome .. " "), são só para o código ficar legível; o Lua ignora. "Total: "..total e "Total: " .. total dão o mesmo resultado. Os espaços que aparecem na saída são os de dentro das aspas. Neste guia, escrevemos sempre com um espaço de cada lado do .., que é mais fácil de ler (e, com números, evita um erro que você vai ver na seção 3).

Missão: o programa já tem o sobrenome guardado, mas não usa. Faça ele mostrar Olá, Ana Lima!, com um espaço entre o nome e o sobrenome. Depois, troque os nomes pelos seus.

local nome = "Ana"
local sobrenome = "Lima"
print("Olá, " .. nome .. "!")

local nome = "Ana"
local sobrenome = "Lima"
print("Olá, " .. nome .. " " .. sobrenome .. "!")

3. Texto com número

Na padaria, a Ana quer mostrar a quantidade de pães e o preço. Esses valores são números, não textos (veja Números). O .. aceita números: ele os transforma em texto antes de colar.

local quantidade = 3
local preco = 4.5
print("Pães: " .. quantidade)
print("Preço: R$ " .. preco)
print("Total: R$ " .. quantidade * preco)
print("Metade: " .. 10 / 2)
print(1 .. 2)
print(type(1 .. 2))
print(10 .. "")

$ lua numeros.lua
Pães: 3
Preço: R$ 4.5
Total: R$ 13.5
Metade: 5.0
12
string
10
"Pães: " .. quantidade
O número 3 virou o texto 3 e foi colado.
"Preço: R$ " .. preco
O número com casas decimais (um float) aparece como o Lua o escreve: 4.5, com ponto, e sem o zero do fim (não é 4.50). Para mostrar dinheiro com duas casas, use o string.format (aula string.format).
"Total: R$ " .. quantidade * preco
Primeiro o Lua faz a conta (3 * 4.5 = 13.5), depois cola. A multiplicação vem antes da concatenação: a seção 5 explica.
"Metade: " .. 10 / 2
A divisão com / sempre dá float, então o texto sai 5.0, e não 5 (veja Divisão).
1 .. 2
Dois números colados viram o texto 12. Não é uma conta: é o 1 encostado no 2.
type(1 .. 2)
O type confirma (veja type): o resultado de um .. é sempre uma string, mesmo quando os dois lados são números.
10 .. ""
Colar um texto vazio ("", duas aspas sem nada dentro) é um truque para transformar um número em texto. O jeito mais claro de fazer isso é tostring(10) (veja Conversão).
Em outras versões do Lua

No Lua 5.1 e no LuaJIT (usados no Neovim, no LÖVE e no OpenResty), não existe a separação entre inteiro e float, e o 10 / 2 é escrito sem o .0. No lab, a mesma linha deu:

$ lua -e 'print("Metade: " .. 10 / 2)'
Metade: 5.0
$ lua5.4 -e 'print("Metade: " .. 10 / 2)'
Metade: 5.0
$ lua5.1 -e 'print("Metade: " .. 10 / 2)'
Metade: 5
$ luajit -e 'print("Metade: " .. 10 / 2)'
Metade: 5

Mais diferenças em Lua 5.1, LuaJIT, 5.4 e 5.5.

Cuidado: 1..2, tudo colado, é erro

Com números escritos direto no código, os espaços em volta do .. fazem diferença. Veja o que acontece sem eles:

print(1..2)

$ lua colado.lua
lua: colado.lua:1: malformed number near '1..2'

"Número malformado perto de 1..2". Quando o Lua lê um número, ele aceita um ponto no meio (1.5). Ao ver 1., ele acha que vem um número com casas decimais, encontra outro ponto e não entende mais nada: para ele, 1..2 é um número escrito errado, não "1, junta, 2". É um erro de sintaxe: o programa nem começa a rodar. Basta um espaço depois do número para resolver. No modo interativo:

$ lua
Lua 5.5.0  Copyright (C) 1994-2025 Lua.org, PUC-Rio
> 1 .. 2
12
> 1..2
stdin:1: malformed number near '1..2'
> os.exit()

E se só um dos lados tiver espaço? 1 ..2 funciona (o espaço depois do 1 já separa), mas 1.. 2 não:

$ lua -e 'print(1 ..2)'
12
$ lua -e 'print(1.. 2)'
lua: (command line):1: malformed number near '1..'

Com variáveis não há esse problema (x..2 funciona, porque x não é um número escrito), mas o costume de pôr um espaço de cada lado evita a dúvida.

4. O .. cria um texto novo

Lembra das etiquetas que continuam na cartela? No Lua, um texto nunca muda depois de criado (os programadores dizem que strings são imutáveis; a aula Strings volta a esse assunto). O .. não altera nenhum dos lados: ele fabrica um texto novo. Se você não guardar esse texto novo em algum lugar, ele se perde.

Tanto que, sozinha numa linha, uma concatenação nem é aceita:

local recado = "Comprar pão"
recado .. " e leite"

$ lua imutavel.lua
lua: imutavel.lua:2: syntax error near '..'

"Erro de sintaxe perto de ..". O Lua não deixa você escrever uma linha que calcula um valor e o joga fora. Para o recado mudar, é preciso guardar o resultado de volta na variável, com o =:

local recado = "Comprar pão"
local _ = recado .. " e leite"
print(recado)
recado = recado .. " e leite"
print(recado)
recado = recado .. ", café"
print(recado)

$ lua imutavel2.lua
Comprar pão
Comprar pão e leite
Comprar pão e leite, café
local _ = recado .. " e leite"
Faz a concatenação e guarda numa variável chamada _ (um sublinhado: o nome que os programadores de Lua usam para "não vou usar isto"). O recado não foi tocado, e o primeiro print prova: ainda é Comprar pão.
recado = recado .. " e leite"
Lê-se da direita para a esquerda: o Lua monta "Comprar pão" .. " e leite", e só então guarda o texto novo em recado, no lugar do antigo.
recado = recado .. ", café"
O mesmo truque, de novo: cada vez, o recado fica mais comprido. É assim que se vai "acrescentando" texto no Lua.
Muitos pedaços? Use table.concat

Para juntar muitos pedaços (centenas de linhas de um relatório, por exemplo), repetir texto = texto .. pedaco é lento, porque cada vez o Lua fabrica um texto novo, cada vez maior. O jeito recomendado é guardar os pedaços numa lista e juntar tudo de uma vez com table.concat, que aparece no fim desta aula e tem aula própria: table.concat.

5. .. junto com contas

Quando uma linha mistura .. com +, -, * ou /, o Lua faz as contas primeiro e concatena depois. Olhe com atenção a segunda linha:

print("Total: " .. 2 + 3)
print("2" .. "3" + 1)
print("A" .. "B" .. "C")

$ lua soma_texto.lua
Total: 5
24
ABC
  • "Total: " .. 2 + 3: primeiro 2 + 3 = 5, depois "Total: " .. 5. Ótimo, era o que queríamos.
  • "2" .. "3" + 1: o + vem primeiro, então o Lua faz "3" + 1. O texto "3" parece um número, e o Lua o converte para somar: dá 4. Só depois vem "2" .. 4 = 24. Quem esperava "23" + 1 = 24 acertou por sorte; quem esperava 231 errou.
  • "A" .. "B" .. "C": sem contas, tudo é colado em ordem.

Na dúvida, use parênteses: "Total: " .. (2 + 3) deixa claro o que vem primeiro. A ordem completa de todos os operadores está em Precedência dos Operadores.

6. .. não é +

Quem já viu outra linguagem de programação (JavaScript, Python, Java) costuma juntar textos com +. No Lua, o + é só para somar, e o .. é só para juntar. Olhe o que cada um faz com "10" e 5:

print("10" + 5)
print("10" .. 5)

$ lua mais2.lua
15
105

Com +, o Lua tentou somar: converteu o texto "10" em número e deu 15. Com .., ele juntou: 10 encostado em 5 = 105. E se o texto não for um número, o + dá erro (veja Quando dá errado).

Formas diferentes de fazer a mesma coisa

O .. não é o único jeito de mostrar vários valores juntos. Este programa escreve a mesma informação de cinco formas:

local nome, idade = "Ana", 30
print("Nome: " .. nome .. ", idade: " .. idade)
print(string.format("Nome: %s, idade: %d", nome, idade))
print("Nome:", nome, "idade:", idade)
io.write("Nome: ", nome, ", idade: ", idade, "\n")
print(table.concat({"pão", "leite", "café"}, ", "))

$ lua formas.lua
Nome: Ana, idade: 30
Nome: Ana, idade: 30
Nome:	Ana	idade:	30
Nome: Ana, idade: 30
pão, leite, café
print("Nome: " .. nome .. …)
A concatenação: você controla cada espaço e cada vírgula.
string.format("Nome: %s, idade: %d", …)
Um molde: o %s e o %d são lacunas preenchidas, em ordem, pelos valores depois da vírgula. É o melhor jeito quando há números para formatar (duas casas decimais, por exemplo). Aula própria: string.format.
print("Nome:", nome, …)
Com vírgulas, o print recebe vários valores e os separa com uma tabulação (TAB), aquele espaço largo. Bom para olhar valores rapidamente, ruim para uma frase bonita.
io.write("Nome: ", nome, …, "\n")
O io.write também aceita vários valores, mas não põe nada entre eles e não pula linha sozinho (por isso o "\n" no fim; veja io.write() e Caracteres de Escape). Na prática, ele "concatena" na hora de escrever.
table.concat({…}, ", ")
Junta todos os itens de uma lista, com o separador que você escolher no meio (", "). Aula própria: table.concat.

Quando dá errado

O .. só aceita textos e números. Qualquer outra coisa de um dos lados (nil, true/false, uma tabela) faz o programa parar com um erro. Os erros abaixo acontecem com o programa rodando, na linha do ...

Concatenou uma variável que não existe (nil)

Este é, de longe, o erro mais comum com ... A Ana esqueceu de criar a variável sobrenome:

local nome = "Ana"
print("Olá, " .. nome .. " " .. sobrenome)

$ lua nil1.lua
lua: nil1.lua:2: attempt to concatenate a nil value (global 'sobrenome')
stack traceback:
	nil1.lua:2: in main chunk
	[C]: in ?
$ echo $?
1

Linha por linha:

lua: nil1.lua:2:
Quem reclama é o lua; o problema está no arquivo nil1.lua, na linha 2.
attempt to concatenate a nil value
"Tentativa de concatenar um valor nil". Um dos pedaços do .. era nil, o "nada" do Lua (veja O Valor nil). Variável que nunca recebeu valor vale nil.
(global 'sobrenome')
O Lua diz qual pedaço era nil: a variável sobrenome. Ele a chama de global porque ela não foi declarada com local (um nome que nunca foi criado é procurado entre as globais; veja local × Global).
stack traceback: …
O "rastro" de onde o programa estava: na linha 2 do programa principal (main chunk), que foi chamado pelo próprio lua ([C]: in ?). Em programas pequenos, a primeira linha do erro já basta. A aula Lendo uma Mensagem de Erro detalha.
echo $? → 1
O código de saída: 1 quer dizer "terminou com erro".

O Lua muda o fim da mensagem conforme o tipo de variável. Com uma variável local criada sem valor, sai (local 'sobrenome'); com um campo de tabela que não existe, sai (field 'sobrenome'):

local sobrenome
print("Ana " .. sobrenome)

$ lua nil3.lua
lua: nil3.lua:2: attempt to concatenate a nil value (local 'sobrenome')
stack traceback:
	nil3.lua:2: in main chunk
	[C]: in ?
local cliente = {nome = "Ana"}
print(cliente.nome .. " " .. cliente.sobrenome)

$ lua nil2.lua
lua: nil2.lua:2: attempt to concatenate a nil value (field 'sobrenome')
stack traceback:
	nil2.lua:2: in main chunk
	[C]: in ?

Como consertar: confira o nome da variável (um erro de digitação, como sobrenme, também dá nil) e se ela recebeu valor antes daquela linha. Se ela pode mesmo ficar sem valor, troque o nil por um texto com or: (sobrenome or ""). Os parênteses são obrigatórios; o porquê está em and, or e not.

Concatenou true ou false 
local pago = true
print("Pago: " .. pago)

$ lua bool.lua
lua: bool.lua:2: attempt to concatenate a boolean value (local 'pago')
stack traceback:
	bool.lua:2: in main chunk
	[C]: in ?

"Tentativa de concatenar um valor booleano". O .. transforma números em texto sozinho, mas não transforma true/false (veja Booleanos). Como consertar: converta com tostring. O mesmo vale para o nil, se você quiser ver a palavra nil escrita:

local pago = true
print("Pago: " .. tostring(pago))
local sobrenome = nil
print("Sobrenome: " .. (sobrenome or "(não informado)"))
print("Sobrenome: " .. tostring(sobrenome))

$ lua bool2.lua
Pago: true
Sobrenome: (não informado)
Sobrenome: nil
Concatenou uma tabela 
local compras = {"pão", "leite"}
print("Lista: " .. compras)

$ lua tabela.lua
lua: tabela.lua:2: attempt to concatenate a table value (local 'compras')
stack traceback:
	tabela.lua:2: in main chunk
	[C]: in ?

Uma tabela (veja Tabelas) é uma caixa com vários valores dentro; o Lua não sabe como "colar" uma caixa inteira num texto. Como consertar: junte os itens com table.concat(compras, ", ") e concatene o resultado, que é um texto: "Lista: " .. table.concat(compras, ", ").

Usou + para juntar textos 
local nome = "Ana"
print("Olá, " + nome)

$ lua mais.lua
lua: mais.lua:2: attempt to add a 'string' with a 'string'
stack traceback:
	[C]: in metamethod 'add'
	mais.lua:2: in main chunk
	[C]: in ?

"Tentativa de somar uma string com uma string". O + tentou fazer uma conta e não conseguiu transformar "Olá, " nem "Ana" em números. A linha [C]: in metamethod 'add' no rastro é o mecanismo interno do Lua que tentou a soma com textos (o nome "metamétodo" vai aparecer bem mais adiante, em Metatabelas; por enquanto, pode ignorar). Como consertar: troque o + por ...

Escreveu 1..2 sem espaço 
$ lua colado.lua
lua: colado.lua:1: malformed number near '1..2'

Como você viu na seção 3: com número escrito direto no código, o ponto do .. se confunde com o ponto decimal. Repare que esse erro não tem stack traceback: é um erro de sintaxe, encontrado antes de o programa começar. Como consertar: 1 .. 2.

Missão: este programa para com attempt to concatenate a nil value (local 'sobrenome'), porque a cliente não informou o sobrenome. Rode para ver o erro e conserte a linha do print para o programa mostrar o nome mesmo sem sobrenome (dica: (sobrenome or "")).

local nome = "Ana"
local sobrenome
print("Cliente: " .. nome .. " " .. sobrenome)

local nome = "Ana"
local sobrenome
print("Cliente: " .. nome .. " " .. (sobrenome or ""))

Missão final: a linha do recibo

Missão: na padaria, a Ana quer imprimir a linha do recibo no formato 6 x pão = R$ 4.5. Use .. para montar a linha com as variáveis quantidade, item e o total (quantidade * preco). Cuidado com os espaços!

Resumo

  • .. (dois pontos) junta textos, um encostado no outro. Isso se chama concatenação. O resultado é sempre uma string.
  • O .. não põe espaço: o espaço tem de estar dentro das aspas ("Olá, ") ou ser um pedaço próprio (" ").
  • Números viram texto sozinhos ("Total: " .. 30). Com número escrito no código, ponha espaço: 1 .. 2 dá 12, e 1..2 é malformed number.
  • O .. cria um texto novo e não muda o original. Para "acrescentar", guarde de volta: recado = recado .. " e leite".
  • As contas vêm antes do ..: "Total: " .. 2 + 3 dá Total: 5. Na dúvida, use parênteses.
  • nil, true/false e tabelas no .. param o programa com attempt to concatenate a … value. Use tostring(v), (v or "") ou table.concat.
  • Para juntar textos, é ..; o + é só para somar.
