Lua table.concat: Juntando Itens

Você já viu que print(compras) não mostra os itens da lista, só table: 0x… (veja Tabelas), e que "Lista: " .. compras dá erro. Para transformar uma lista inteira num texto, como pão, leite, café, o Lua tem a função table.concat. O nome vem de concatenar, "juntar em sequência", a mesma ideia do .., só que para todos os itens de uma lista de uma vez, com o separador que você escolher entre eles.

Você vai aprender
  • table.concat(lista) e table.concat(lista, separador).
  • Juntar só uma parte: table.concat(lista, sep, i, j).
  • Listas de números (funciona) e listas com true, tabelas ou nil (não funciona).
  • O "e" antes do último item: pão, leite e café.
  • Como mostrar uma lista de fichas: monte antes uma lista de textos.
  • Por que table.concat é melhor que .. dentro de um laço.
  • Os erros reais: invalid value (table) at index 2 in table for 'concat', o item nil que some sem aviso, a lista nil.

Todos os programas desta aula rodaram no Lua 5.5 da máquina da Ana (usuária ana, computador notebook), com lua arquivo.lua.

A ideia: etiquetas num barbante

A Ana escreveu cada item da lista de compras numa etiqueta. Agora quer pendurar todas num barbante, em ordem, para pôr na geladeira. Entre uma etiqueta e outra, ela dá um nó. O table.concat é esse barbante: ele pega as etiquetas (os itens da lista, do 1 até o último) e as junta num texto só, pondo o separador (o nó) entre elas. Não antes da primeira, não depois da última: só entre.

1. O primeiro table.concat

local compras = {"pão", "leite", "café"}
print(table.concat(compras))
print(table.concat(compras, ", "))
print(table.concat(compras, " | "))
print(table.concat(compras, "\n"))

Sem separador, os itens ficam grudados: pãoleitecafé. O separador padrão é o texto vazio "".
table.concat(compras, ", ")
O 2º argumento é o separador: aqui, vírgula e espaço. Repare que não sobrou vírgula no fim.
" | "
Qualquer texto serve de separador.
"\n"
O "Enter" (veja Caracteres de Escape): um item por linha, num print só.

O table.concat devolve um texto novo e não muda a lista. Você pode mostrar esse texto, guardar numa variável (local linha = table.concat(compras, ", ")) ou juntar com outros textos usando ...

Depois do separador, dá para dizer de qual posição até qual juntar:

print(table.concat(fila, ", ", 3, 3))
print("[" .. table.concat(fila, ", ", 4, 2) .. "]")

3. Listas de números

O table.concat aceita textos e números. Os números viram texto do mesmo jeito que o print os mostra:

local notas = {7, 8.5, 10, 6.0}
print(table.concat(notas, " - "))
local tabuada = {}
for i = 1, 10 do
  tabuada[i] = 3 * i
end
print("Tabuada do 3: " .. table.concat(tabuada, " "))

$ lua numeros_concat.lua
7 - 8.5 - 10 - 6.0
Tabuada do 3: 3 6 9 12 15 18 21 24 27 30

O 6.0 continuou 6.0: ele foi escrito como float, e o Lua mostra o .0 dos floats (veja Números). Para controlar as casas decimais, formate cada número antes com string.format e junte os textos.

Uma linha de planilha

Com o separador ";", uma lista vira uma linha de arquivo CSV, que as planilhas abrem (veja Escrevendo Arquivos):

local aluno = {"Ana", 8, 9.5, 7}
print(table.concat(aluno, ";"))

$ lua csv.lua
Ana;8;9.5;7

4. O "e" antes do último

Em português, a gente diz "pão, leite e café". Com as posições i e j, dá para juntar todos menos o último com vírgula, e pôr o último com " e ":

local function juntar(lista)
  if #lista == 0 then
    return "nada"
  elseif #lista == 1 then
    return lista[1]
  end
  return table.concat(lista, ", ", 1, #lista - 1) .. " e " .. lista[#lista]
end
print("Comprei " .. juntar({"pão", "leite", "café"}) .. ".")
print("Comprei " .. juntar({"pão", "leite"}) .. ".")
print("Comprei " .. juntar({"pão"}) .. ".")
print("Comprei " .. juntar({}) .. ".")

$ lua e_final.lua
Comprei pão, leite e café.
Comprei pão e leite.
Comprei pão.
Comprei nada.
table.concat(lista, ", ", 1, #lista - 1)
Todos os itens, do primeiro ao penúltimo, separados por vírgula: pão, leite.
.. " e " .. lista[#lista]
Mais o " e " e o último item (veja Listas): pão, leite e café.
os dois if
Os casos especiais: com um item só, não há "e"; com zero, não há item nenhum. Sem eles, juntar({}) tentaria juntar lista[0], que é nil, e daria erro.

5. Uma lista de fichas

O table.concat só junta textos e números. Uma lista de fichas (tabelas) ele não sabe juntar (veja Quando dá errado). A saída é montar antes uma lista de textos, um por ficha, e juntar essa lista:

local produtos = {
  {nome = "Pão", preco = 0.75},
  {nome = "Leite", preco = 5.49},
  {nome = "Café", preco = 18.90},
}
local nomes = {}
for _, p in ipairs(produtos) do
  table.insert(nomes, p.nome .. " (R$ " .. string.format("%.2f", p.preco) .. ")")
end
print("Vitrine: " .. table.concat(nomes, ", "))

$ lua fichas_concat.lua
Vitrine: Pão (R$ 0.75), Leite (R$ 5.49), Café (R$ 18.90)

Esse é um padrão que aparece muito: um laço com ipairs monta os pedaços com table.insert, e um table.concat no fim junta tudo.

Formas diferentes de fazer a mesma coisa

Sem o table.concat, juntar a lista pede um laço com .. e um cuidado para não sobrar vírgula no fim:

local compras = {"pão", "leite", "café"}
local texto = ""
for i, item in ipairs(compras) do
  texto = texto .. item
  if i < #compras then
    texto = texto .. ", "
  end
end
print(texto)
print(table.concat(compras, ", "))

$ lua laco_vs.lua
pão, leite, café
pão, leite, café

O resultado é igual, mas o table.concat ganha em duas coisas. É uma linha só, sem o if da vírgula. E é mais rápido com listas grandes: cada texto = texto .. item cria um texto novo, copiando tudo o que já estava lá; com milhares de itens, são milhares de cópias cada vez maiores. O table.concat vai enchendo um espaço de trabalho (um buffer) e cria o texto final uma vez só. Por isso, quando um programa vai montando um texto grande aos poucos (um relatório, um arquivo), o jeito do Lua é: junte os pedaços numa lista e, no fim, um table.concat.

"Valor inválido (booleano) na posição 2." O concat não transforma true em texto sozinho (o print transforma; o concat, não). Como consertar: converta cada item com tostring antes:

local respostas = {"sim", true, "não"}
local textos = {}
for i, r in ipairs(respostas) do
  textos[i] = tostring(r)
end
print(table.concat(textos, ", "))

Missão final: a lista de convidados

Missão: a Ana vai fazer um aniversário. Complete a linha do texto para sair Convidados: Ana, Bia, Caio e Davi.: junte do primeiro ao penúltimo com ", " (use o i e o j do table.concat) e acrescente " e " e o último.

local convidados = {"Ana", "Bia", "Caio", "Davi"}
local texto = table.concat(convidados, ", ")
print("Convidados: " .. texto .. ".")

local convidados = {"Ana", "Bia", "Caio", "Davi"}
local texto = table.concat(convidados, ", ", 1, #convidados - 1) .. " e " .. convidados[#convidados]
print("Convidados: " .. texto .. ".")

Sem mexer, o programa mostra Convidados: Ana, Bia, Caio, Davi., com vírgula no lugar do "e".

Resumo

  • table.concat(lista, separador) junta os itens de lista[1] até lista[#lista] num texto só, com o separador entre eles. Sem separador, gruda tudo.
  • table.concat(lista, sep, i, j) junta só das posições i a j; com i > j ou lista vazia, devolve "".
  • Os itens têm de ser textos ou números. Tabela, true/false ou nil no meio dão invalid value (…) at index N in table for 'concat'.
  • Um nil no meio pode também fazer itens sumirem sem erro, porque o # da lista com buraco não é confiável.
  • Para fichas, monte antes uma lista de textos. Para montar textos grandes, junte os pedaços numa lista e use table.concat no fim: é mais simples e mais rápido que .. num laço.
