Lua Laços Aninhados

Um laço repete um bloco de código. E se dentro desse bloco houver outro laço? Aí, a cada volta do laço de fora, o laço de dentro roda inteiro, do começo ao fim. Isso se chama laços aninhados (um dentro do outro, como ninhos). É assim que se faz a tabuada inteira, se percorre cada nota de cada aluno, se desenha uma grade ou se testam todas as combinações de lanche e bebida.

Você vai aprender
  • Como escrever um for dentro de outro e em que ordem as voltas acontecem.
  • Quantas vezes o laço de dentro roda (a conta "de fora × de dentro").
  • A tabuada, um retângulo e um triângulo de asteriscos, e um relógio de 15 em 15 minutos.
  • Como calcular a média de cada aluno, e onde zerar o acumulador.
  • Combinações (todo lanche com toda bebida) e duplas sem repetir.
  • Por que o break só sai do laço de dentro, e três formas de sair de todos: a variável "bandeira", o goto e o return.
  • Os erros reais: o mesmo nome nos dois laços, o end que faltou e os índices trocados.

Todos os programas desta aula rodaram no Lua 5.5 da máquina da Ana (usuária ana, computador notebook), com lua arquivo.lua. Antes desta aula, vale ter visto for Numérico, break e goto e Rótulos.

A ideia: o relógio de ponteiros

Olhe um relógio. O ponteiro dos minutos dá uma volta inteira (de 0 a 59) e só então o ponteiro das horas anda um passo. Depois os minutos dão outra volta inteira, e as horas andam mais um. O ponteiro das horas é o laço de fora: ele anda devagar. O dos minutos é o laço de dentro: ele roda completo a cada passo do outro.

Este programa faz um relógio que só mostra os minutos de 15 em 15, das 8h às 9h45:

for hora = 8, 9 do
  for minuto = 0, 45, 15 do
    print(string.format("%02d:%02d", hora, minuto))
  end
end

$ lua relogio.lua
08:00
08:15
08:30
08:45
09:00
09:15
09:30
09:45

Para hora = 8, o minuto passou por 0, 15, 30 e 45. Só então a hora virou 9, e o minuto recomeçou do 0. (O %02d do string.format escreve o número com 2 dígitos, pondo um zero na frente: 8 vira 08.)

1. Um for dentro de outro: a tabuada

for i = 1, 3 do
  print("Tabuada do " .. i)
  for j = 1, 5 do
    print(i .. " x " .. j .. " = " .. i * j)
  end
end
print("fim")
for i = 1, 3 do
O laço de fora. O i é o número da tabuada: 1, depois 2, depois 3.
print("Tabuada do " .. i)
Está dentro do laço de fora, mas fora do de dentro: roda uma vez por tabuada (3 vezes ao todo).
for j = 1, 5 do
O laço de dentro, com outra variável, o j. Ele roda inteiro (j = 1, 2, 3, 4, 5) a cada volta do de fora. Os nomes i e j são uma tradição dos programadores para contadores; com nomes que dizem o que são (numero, vezes) também fica ótimo.
print(i .. " x " .. j …)
O corpo do laço de dentro: aqui os dois contadores estão disponíveis.
end (o primeiro)
Fecha o laço de dentro.
end (o segundo)
Fecha o laço de fora. A indentação (2 espaços a mais em cada nível) mostra de olho qual end fecha qual for.

2. A ordem das voltas, e quantas são

Este programa mostra o par (i,j) de cada volta do laço de dentro, sem pular linha (com io.write), e só pula linha quando o laço de dentro termina. Ele também conta as voltas:

local voltas = 0
for i = 1, 3 do
  for j = 1, 4 do
    io.write("(", i, ",", j, ") ")
    voltas = voltas + 1
  end
  print()
end
print("voltas do laço de dentro: " .. voltas)

$ lua ordem.lua
(1,1) (1,2) (1,3) (1,4)
(2,1) (2,2) (2,3) (2,4)
(3,1) (3,2) (3,3) (3,4)
voltas do laço de dentro: 12

Cada linha é uma volta do laço de fora; cada par, uma volta do de dentro. O print() sem nada só pula a linha. A conta é sempre a mesma: 3 voltas de fora × 4 voltas de dentro = 12. É uma multiplicação, e ela cresce rápido. Dois laços de 1 a 1000, um dentro do outro, dão um milhão de voltas:

local vezes = 0
for i = 1, 1000 do
  for j = 1, 1000 do
    vezes = vezes + 1
  end
end
print(vezes)

$ lua pequeno.lua
1000000

O Lua faz isso num piscar de olhos. Mas três laços de 1 a 1000 já seriam um bilhão de voltas: aí o programa demora. Antes de aninhar laços grandes, faça a conta.

3. Desenhando com asteriscos

Laços aninhados são ótimos para desenhar grades. O de fora cuida das linhas; o de dentro, das colunas de cada linha:

for linha = 1, 3 do
  for coluna = 1, 8 do
    io.write("*")
  end
  io.write("\n")
end

$ lua retangulo.lua
********
********
********

O io.write("*") escreve um asterisco sem pular linha; o io.write("\n") depois do laço de dentro pula a linha (o \n é o "Enter"; veja Caracteres de Escape).

O laço de dentro pode depender do de fora

O limite do laço de dentro não precisa ser um número fixo: pode ser a variável do laço de fora. Com for coluna = 1, linha, a linha 1 tem 1 asterisco, a linha 2 tem 2, e assim por diante:

for linha = 1, 5 do
  for coluna = 1, linha do
    io.write("*")
  end
  io.write("\n")
end

$ lua triangulo.lua
*
**
***
****
*****

Missão: transforme o retângulo num triângulo de 4 linhas (1, 2, 3 e 4 asteriscos). Dica: o laço de fora vai até 4, e o de dentro vai até linha.

for linha = 1, 3 do
  for coluna = 1, 8 do
    io.write("*")
  end
  io.write("\n")
end

for linha = 1, 4 do
  for coluna = 1, linha do
    io.write("*")
  end
  io.write("\n")
end

4. A média de cada aluno

A professora da Ana guarda as notas de cada aluno numa lista dentro de outra lista: notas[1] são as notas da Ana, notas[2] as da Bia… e notas[2][3] é a terceira nota da Bia. (As listas têm aula própria em Tabelas como Listas, e as listas dentro de listas em Tabelas Aninhadas; aqui basta ler notas[a][p] como "aluno a, prova p", e #lista como "quantos itens tem".)

local alunos = {"Ana", "Bia", "Caio"}
local notas = {
  {7, 8, 9},
  {5, 6, 10},
  {9, 9, 6},
}
for a = 1, #alunos do
  local soma = 0
  for p = 1, #notas[a] do
    soma = soma + notas[a][p]
  end
  print(alunos[a] .. ": média " .. soma / #notas[a])
end

$ lua turmas.lua
Ana: média 8.0
Bia: média 7.0
Caio: média 8.0

Repare onde está o local soma = 0: dentro do laço de fora, antes do de dentro. Assim cada aluno começa a sua soma do zero. O laço de dentro soma as provas; o print, depois dele, mostra a média daquele aluno. Na seção Quando dá errado você vê o que acontece com a soma no lugar errado.

5. Combinações e duplas

A lanchonete da esquina quer um cartaz com todos os combos possíveis de lanche e bebida. Todo lanche com toda bebida é um laço dentro do outro:

local lanches = {"misto", "coxinha"}
local bebidas = {"café", "suco", "água"}
local n = 0
for l = 1, #lanches do
  for b = 1, #bebidas do
    n = n + 1
    print(n .. ") " .. lanches[l] .. " + " .. bebidas[b])
  end
end

$ lua combos.lua
1) misto + café
2) misto + suco
3) misto + água
4) coxinha + café
5) coxinha + suco
6) coxinha + água

2 lanches × 3 bebidas = 6 combos. Agora, um campeonato de pingue-pongue: cada jogador enfrenta cada outro uma vez. "Ana x Bia" e "Bia x Ana" são o mesmo jogo, e ninguém joga contra si mesmo. O truque é o laço de dentro começar depois do de fora: j = i + 1.

local jogadores = {"Ana", "Bia", "Caio", "Davi"}
for i = 1, #jogadores do
  for j = i + 1, #jogadores do
    print(jogadores[i] .. " x " .. jogadores[j])
  end
end

$ lua duplas.lua
Ana x Bia
Ana x Caio
Ana x Davi
Bia x Caio
Bia x Davi
Caio x Davi

Quando i é 4 (Davi), o laço de dentro seria for j = 5, 4: o começo já passou do fim, e ele dá zero voltas. Por isso o Davi não aparece à esquerda, e mesmo assim jogou contra todos.

Experimente: ponha mais um jogador na lista ("Eva") e conte os jogos. Depois troque i + 1 por 1 e veja os jogos repetidos e o "Ana x Ana" aparecerem.

local jogadores = {"Ana", "Bia", "Caio", "Davi"}
for i = 1, #jogadores do
  for j = i + 1, #jogadores do
    print(jogadores[i] .. " x " .. jogadores[j])
  end
end

6. O break só sai do laço de dentro

A Ana procura um aluno chamado Davi. Há um Davi na turma 2 e outro na turma 3. Ela usa break quando acha:

local turmas = {
  {"Ana", "Bia", "Caio"},
  {"Davi", "Eva"},
  {"Davi", "Gil"},
}
for t = 1, #turmas do
  for a = 1, #turmas[t] do
    if turmas[t][a] == "Davi" then
      print("Achei um Davi na turma " .. t)
      break
    end
  end
  print("terminei a turma " .. t)
end

$ lua break_dentro.lua
terminei a turma 1
Achei um Davi na turma 2
terminei a turma 2
Achei um Davi na turma 3
terminei a turma 3

O break sai só do laço mais de dentro, aquele onde ele está. O laço das turmas continuou: mostrou "terminei a turma 2" e foi para a turma 3. Às vezes é isso mesmo que você quer (achar o primeiro Davi de cada turma). Mas se a ideia era parar a busca toda no primeiro Davi, há três jeitos.

Jeito 1: uma variável "bandeira"

Uma variável achou começa false e vira true quando acha. Depois do laço de dentro, o de fora confere a bandeira e dá o seu próprio break:

local turmas = {
  {"Ana", "Bia", "Caio"},
  {"Davi", "Eva"},
  {"Davi", "Gil"},
}
local achou = false
for t = 1, #turmas do
  for a = 1, #turmas[t] do
    if turmas[t][a] == "Davi" then
      print("Achei o Davi na turma " .. t)
      achou = true
      break
    end
  end
  if achou then
    break
  end
end
print("fim da busca")

$ lua bandeira.lua
Achei o Davi na turma 2
fim da busca

Jeito 2: goto para depois dos laços

O goto pode sair de quantos blocos for preciso de uma vez. Um rótulo depois dos dois laços, e pronto:

local turmas = {
  {"Ana", "Bia", "Caio"},
  {"Davi", "Eva"},
  {"Davi", "Gil"},
}
for t = 1, #turmas do
  for a = 1, #turmas[t] do
    if turmas[t][a] == "Davi" then
      print("Achei o Davi na turma " .. t)
      goto fim
    end
  end
end
::fim::
print("fim da busca")

$ lua gotofim.lua
Achei o Davi na turma 2
fim da busca

Jeito 3: pôr os laços numa função e usar return

O return sai da função inteira, com todos os laços que estiverem dentro dela. De quebra, a função pode devolver onde achou:

local turmas = {
  {"Ana", "Bia", "Caio"},
  {"Davi", "Eva"},
  {"Davi", "Gil"},
}
local function procurar(nome)
  for t = 1, #turmas do
    for a = 1, #turmas[t] do
      if turmas[t][a] == nome then
        return t, a
      end
    end
  end
  return nil
end
print(procurar("Davi"))
print(procurar("Gil"))
print(procurar("Zeca"))

$ lua funcao.lua
2	1
3	2
nil

O Davi está na turma 2, posição 1; o Gil, na turma 3, posição 2; o Zeca não foi achado, e a função chegou ao return nil do fim. (Devolver dois valores de uma vez é assunto de Vários Retornos.)

goto continue em cada nível

Cada laço pode ter o seu próprio ::continue::, mesmo um dentro do outro. Cada goto continue vai para o rótulo do laço onde ele está. Aqui, a turma vazia é pulada no laço de fora, e o nome em branco é pulado no de dentro:

local turmas = {
  {"Ana", "", "Caio"},
  {},
  {"Eva", "Gil"},
}
for t = 1, #turmas do
  if #turmas[t] == 0 then
    print("turma " .. t .. " vazia")
    goto continue
  end
  for a = 1, #turmas[t] do
    if turmas[t][a] == "" then
      goto continue
    end
    print("turma " .. t .. ": " .. turmas[t][a])
    ::continue::
  end
  ::continue::
end

$ lua continue_aninhado.lua
turma 1: Ana
turma 1: Caio
turma 2 vazia
turma 3: Eva
turma 3: Gil

Formas diferentes de fazer a mesma coisa

SituaçãoQual usar
Parar só o laço de dentro (ex.: o primeiro de cada turma)break
Parar tudo, com poucos laços e código simplesgoto fim com ::fim:: depois dos laços
Parar tudo e ainda saber depois se achouVariável bandeira (achou = true) + break nos dois laços

Todas as combinaçõesDe dentro começando em 1
Duplas sem repetirDe dentro começando em i + 1

Os laços aninhados não precisam ser dois for: um while pode ter um for dentro, ou o contrário. A regra é a mesma: a cada volta do de fora, o de dentro roda inteiro. E nada impede um terceiro nível (horas, minutos, segundos), mas acima de três a leitura fica difícil; nessa hora, uma função ajuda.

Quando dá errado

A soma ficou fora do laço de fora 
local alunos = {"Ana", "Bia", "Caio"}
local notas = {
  {7, 8, 9},
  {5, 6, 10},
  {9, 9, 6},
}
local soma = 0
for a = 1, #alunos do
  for p = 1, #notas[a] do
    soma = soma + notas[a][p]
  end
  print(alunos[a] .. ": média " .. soma / #notas[a])

$ lua soma_fora.lua
Ana: média 8.0
Bia: média 15.0
Caio: média 23.0

O Lua não reclama de nada, mas a Bia tirou 15 de média numa prova que vai até 10? O soma = 0 está antes dos dois laços: ele roda uma vez só. A soma da Bia começou com os 24 pontos da Ana (24 + 21 = 45; 45 / 3 = 15), e a do Caio, com os dois. Como consertar: zere o acumulador dentro do laço de fora, antes do de dentro. Também sem mensagem de erro. Cada for cria a sua própria variável, e o i de dentro esconde o de fora: lá dentro, i é sempre o de dentro, e o número da tabuada some. O de fora continua existindo e contando (por isso a lista se repete 3 vezes), só não dá para enxergá-lo. Este programa mostra os dois:

for i = 1, 2 do

Como consertar: um nome diferente para cada laço (i e j, ou linha e coluna).

Faltou um end 
for i = 1, 3 do
  for j = 1, 3 do
    print(i * j)
end

$ lua sem_end.lua
lua: sem_end.lua:5: 'end' expected (to close 'for' at line 1) near <eof>

"Era esperado um end (para fechar o for da linha 1) perto do fim do arquivo (<eof>, end of file)." Com dois laços, são dois end. O único end que existe fechou o laço de dentro (o mais recente), e o Lua chegou ao fim do arquivo com o da linha 1 ainda aberto. A linha 5 é a linha depois da última. Como consertar: mais um end. Com a indentação certa, dá para ver: cada end fica na mesma coluna do seu for.

Resumo

  • Laços aninhados são um laço dentro de outro. A cada volta do de fora, o de dentro roda inteiro, como os ponteiros do relógio.
  • O número de voltas é uma multiplicação (de fora × de dentro): cuidado com laços grandes.
  • Use um nome diferente para a variável de cada laço; com o mesmo nome, o de dentro esconde o de fora.
  • O limite do de dentro pode depender do de fora: 1, i faz triângulos; i + 1, n faz duplas sem repetir.
  • Acumulador "por item do de fora" (a soma de cada aluno) é zerado dentro do laço de fora.
  • O break só sai do laço de dentro. Para sair de todos: variável bandeira, goto para depois dos laços, ou uma função com return.
  • Cada for tem o seu end; a indentação de 2 espaços por nível mostra qual fecha qual.
